# Phase 3.3 Plan 05: Dependency uninstall and local override refusals Summary

**A named uninstall of a plugin no layer declares is now refused while a plugin of the target layer needs it (`(failed) {dependents remain}`), skipped while only plugins of the other layer need it (`(skipped) {dependents remain}`, warning), and carried out only when nothing needs it; a flagless enable or disable that the local layer's opposite `enabled` would undo at the next load is refused with `{disabled in local layer}` or `{enabled in local layer}`.**

## Accomplishments

- `domain/dependency-orphans.ts`: `declaredNeedersByLayer(target, index, layerOf)` walks holders backwards from the target with a visited set (seeded with the target). A holder a layer declares is a needer of that layer (`both` counts as `target`), and an undeclared holder is walked through. Both lists are sorted with `localeCompare` (two separate `sort` statements, because `sonarjs/no-misleading-array-reverse` rejects a sort in the return expression and the ES2022 lib has no `toSorted`). The header now lists the third question. `DeclaringLayers` is exported as the callback's return type.
- `uninstall.ts`: `decideRemoval` runs, in order, the LAYER-04 refusal, the LAYER-05 target-declaration drop, the D-06-06 / D-05-07 declarer read, and `checkDependencyNeeders`. `checkDependencyNeeders` returns early for an orchestrated call (no other layer read, WR-09) and for a target that a layer declares. Otherwise it builds `layerOf` from the two layer parses by own-key reads, throws `UninstallRefusedError("dependents remain", ...)` on target needers, and returns the skipped row on other-layer needers. The closure stores a skipped row in `kept.row` and returns before the cascade, `--prune`, and `tx.save()`. The comment cites LAYER-08 / D-MF-03 and the recorded divergence from Claude Code.
- `uninstall.messaging.ts`: `composeDependencyRefusalCause` (`Uninstall <needers> first, then <plugin>@<marketplace>.`) and `composeNeededElsewhereRow` (skipped, `dependents remain`, warning, no reload, the layer and file named). Both render needers through `renderDependentKeys` (T-06-02).
- `notify-reasons.ts`: the `dependents remain` comment names its three owners (EDEP-02 disable, LAYER-03 marketplace remove, LAYER-08 uninstall) and both row kinds.
- `enable-disable.ts`: `refuseOtherLayerDeclaration` calls the new `refuseLocalOverride` when the verdict is `both` and the target is the shared layer. It throws `EnableRefusedError` when the local entry's own `enabled` is the opposite of the request.
- Vocabulary: `disabled in local layer` and `enabled in local layer` are in `Reason`, `CommandPrivateReason`, `REASONS`, the schema (9 enum sites), the three pins, and the JSON guide.
