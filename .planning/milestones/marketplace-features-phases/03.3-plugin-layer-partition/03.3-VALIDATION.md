## Sampling Rate

- **After every task commit:** run the task's scenarios by name, its owner tests, and direct coverage for each source it changed; then `npm run test:cucumber` and `CI=1 npm run check:features` when it changed a scenario or step, `npm run test:modules` for neighbouring pairs, and `npm run test:integration` when it changed behavior. The commit hook runs `check:commit` (static checks, unpaired tests, staged-pair coverage) but no cucumber and no integration test.
- **After every plan wave:** `npm run check` on the combined tree (the orchestrator's post-merge gate; the plans run one after another, one per wave).
- **Before `/gsd-verify-work`:** plan 10's gate: `npm run check` green and the `fallow audit --base f4f38b82` verdict `pass`.
- **Max feedback latency:** ~10 seconds (one scenario plus the feature gate).
