<objective>
Partition `update` and `reinstall` by layer (LAYER-04, D-01, D-15): a named form refuses a plugin
only the other layer declares, acts on a dependency (D-14), and stops on an unreadable layer before
anything moves; a nameless form with `--local` covers only the local layer's plugins. The FIX-03
pre-staging refusal both verbs carried goes with its helper, because the D-01 check replaces it.

Purpose: these are the last two named verbs of ROADMAP SC1. The post-success write-back stays in
place until plan 07, which deletes it on its own; nothing in this plan depends on it, and it writes
nothing for a plugin its target layer already declares.
Output: `namedPluginLayerRefusal`, the refusals in both verbs, the local-layer target filter, a new
reinstall feature, and four scenarios.
</objective>
