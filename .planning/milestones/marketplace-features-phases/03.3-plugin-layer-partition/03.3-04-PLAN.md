<objective>
Let a scope's two layers declare the same plugin while it stays installed once (LAYER-05, D-02):
an install into one layer while the other declares an installed plugin only adds the declaration
(D-03, with D-19 for a plugin not installed), and an uninstall from one layer while the other
declares it only drops that declaration (D-04, D-16). Prove through a real Pi that the field merge
keeps a shared `enabled: false` when the local layer declares the plugin too (LAYER-09).

Purpose: these are the two no-op rows of ROADMAP SC2, and the install no-op is the natural setup
step for every later scenario that needs a plugin in both layers.
Output: four enrolled tokens, the install no-op arm, the uninstall no-op arm with its row type and
composer, the target-layer-only uninstall delete, a new configuration feature, and five scenarios.
</objective>
