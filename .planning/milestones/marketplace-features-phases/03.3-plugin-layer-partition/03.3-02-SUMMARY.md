**Plugin entries now merge field by field across a scope's two layers, local winning, and the install's precedence read (`resolveInstallDeclaredEnabled`) reads `enabled` the same way, so a local entry without `enabled` keeps the shared value in the merged view, the planner, and the install.**

## Accomplishments

- `mergeScopeConfigs`: the plugin loop reads the shared entry back from the `Map` and sets `{ entry: { ...shared, ...local }, source: "local" }`, the same form as the marketplace loop (`grep -c 'pluginEntries.get('` = 1).
