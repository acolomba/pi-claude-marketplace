<objective>
Retire the post-success write-back of `update` and `reinstall` (D-06, D-07): neither verb writes a
plugin declaration any more, so a dependency stays undeclared after a bare update, a named reinstall,
or the load-time backfill, and no layer gains a plugin key without its marketplace. Delete the
write-back family and the invalid-file rows it fed, with an explicit fallow dead-code check.

Purpose: the write-back was the last writer that could put a plugin key into a layer without its
marketplace, and the one that turned dependencies into declared plugins. Plan 06 already moved
both verbs' refusals onto the layer verdict, so this plan changes what happens after success only.
Output: the write-back removed from both verbs, the S5 invalid-file rows and their plumbing removed,
the write-back family deleted from `plugin/shared.ts`, and two scenarios.
</objective>
