# Phase 3.3 Plan 04: Both layers declare one installed plugin Summary

**An install into one layer of a plugin the other layer installed now only adds the declaration (`(skipped) {already installed in shared|local layer}`, info), an uninstall from one layer of a plugin both layers declare now only drops that declaration (`(skipped) {still installed in shared|local layer}`, warning, with the --local hint), and a plain uninstall writes its target layer only.**

## Accomplishments

- `install-flow.ts`: `declareInstalledPlugin` runs between the FIX-03 refusal and `promoteDependencyRecord`. It returns `undefined` unless the call is standalone, the record has `explicit` provenance, there is no `pinVersionOverride`, and `pluginLayerVerdict` answers `other-only`. Then it calls `writeAdoptingConfigEntries` with `pluginPatch: {}` (the LAYER-06 rule also declares the marketplace in the target layer) and returns `{ kind: "declared", record, reason }`. Nothing is saved. `declaredRowOutcome` renders one `skipped` row through `CASCADE_CONTEXT` and returns `{ status: "installed", version, resourcesChanged: false, declares* }`.
- `uninstall.ts`: `checkOtherLayerDeclaration` (renamed from `refuseOtherLayerDeclaration`) throws the D-01 refusal on `other-only` and answers the other layer on `both`. On `both`, the closure deletes the key from the target layer and returns before `readDeclarers`, the cascade, `--prune`, and `tx.save()`. After the lock, `emitKeptInstalled` renders the `composeKeptInstalledRow` row through `UNINSTALL_CONTEXT` and returns `converged`.
- The both-file sweep `sweepPluginFromConfigLayers`, its seam member `sweepConfigLayers`, and the `UninstallLocations` type are deleted. The new seam member `deleteLayerDeclaration` is bound to `deletePluginFromLayer`, and `deleteTargetDeclaration` calls it for the target layer of a standalone uninstall only (`grep -c 'sweepConfigLayers\|sweepPluginFromConfigLayers'` over extensions and tests = 0).
- `uninstall.messaging.ts`: `UninstallStatus` gains `skipped`, `UNINSTALL_CONTEXT` gains `skipped: { markers: false, contentReasons: true }`, and `composeKeptInstalledRow({ plugin, version?, otherLayer })` returns the warning row with the fixed hint cause and `needsReload: false`.
- `notification-types.ts`: `PluginUninstallSkippedMessage extends PluginSkippedMessage { readonly cause?: Error }` is enrolled in `PluginNotificationMessage`. The update variant's doc no longer claims to be the only skipped row with a cause.
- Vocabulary: `already installed in shared layer` and `already installed in local layer` are in `Reason`, `IDEMPOTENT_REASONS`, `REASONS`, the schema, the three pins, and the JSON guide. `still installed in shared layer` and `still installed in local layer` are in `Reason`, `CommandPrivateReason`, `REASONS`, the schema, the three pins, and the JSON guide.
