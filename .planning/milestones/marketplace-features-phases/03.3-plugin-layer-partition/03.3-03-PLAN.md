<objective>
Make install, enable, and disable pick their layer by the flag alone and refuse a named enable or
disable when only the other layer declares the plugin (LAYER-04, D-01). Then make every command
that writes a plugin declaration also declare the plugin's marketplace in that same layer, so
`install --local` under a shared marketplace leaves a self-consistent local layer (LAYER-06,
D-06).

Purpose: the declaring-layer rule (D-103-13/16) existed because a local entry used to replace the
shared one whole; with the field merge from plan 02 and the D-01 refusal, the flag alone decides,
as for the marketplace verbs in 3.2. The marketplace rule is what lets a later load treat a layer
that declares a plugin without its marketplace as a configuration error.
Output: the flag-only selector and its callers, the enable and disable refusal with two new
feature files, the per-layer CR-06 overwrite, the target-layer marketplace synthesis, and two
install scenarios.
</objective>
