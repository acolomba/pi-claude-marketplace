<objective>
Switch plugin entries to the field-by-field merge of a scope's two layers, local winning (LAYER-09,
D-08), in the same change as the install's precedence read (`resolveInstallDeclaredEnabled`), so
the merged view, the planner, and the install agree on what a local entry without `enabled` means.

Purpose: this lands before the flag-only selector (plan 03). Once a flagless command targets the
shared layer, a shared `enabled` value under a local entry without `enabled` must reach the merged
view; under the whole-entry merge it would be lost, and the selector's tests would have to pin a
broken DFEN-05 state. The real-Pi proof of the merge comes in plan 04, whose install no-op is the
scenario's setup, with a planted RED of this plan's merge.
Output: the field merge, the field-level precedence read, unit and convergence cases, and the
source comments that stated the whole-entry rule rewritten.
</objective>
