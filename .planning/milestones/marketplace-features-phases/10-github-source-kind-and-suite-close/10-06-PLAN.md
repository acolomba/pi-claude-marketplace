- The phase runs its plans one after another in this one worktree on
  `features/cucumber-behavioral-tests`; never run two executors at once. Stage explicit paths only
  (`git commit -F <message file> -- <every path of the commit>`). Never `git add -A` or `git add .`,
  never `--amend`, never `--no-verify`, never rebase, never `git stash`.
- Commit messages follow `.agents/skills/committing/SKILL.md` (Conventional Commits, title 5-72
  characters, body lines at most 80, no milestone, phase, plan, or wave anywhere; the Co-Authored-By
  line your session gives; message files in your session scratchpad).

  `npx prettier --write` on any changed `.ts` file); restage and repeat until clean. Run
  `git commit` in the foreground; never pipe it or a verdict command into `tail` or `grep`.
- Hermetic only: never read or write the real `~/.pi/agent`, `~/.gitconfig`, `~/.git-credentials`,
  or this repository's `.pi/`. The harness's secret-read guard rejects any shell command whose text

  one more thing (use `rg`). Record every finding as you find it: file, line, scenario, class, and

  fails after a review edit is a broken edit; revert the edit with `git checkout -- <path>`.

  description that starts with `[marketplace-features]`; never hand-edit `.planning/WINDOWS.md`.
