<objective>
Stop the first-run migration (MIG-01) from copying `--local` declarations into the scope's shared
`claude-plugins.json`, test-first, through the phase's tracer: a real Pi adds a marketplace with
`--local`, starts a new session, and the shared file still does not exist (FIX-02 SC1). Then pin
that `remove --local` stays removed across sessions (SC2), mirror the exclusion in `pending`
(D-01), and prove the plugin path with unit and integration cases (D-04).

Purpose: the migration runs on every load and, when the scope has no base file, writes the base
file from every `state.json` record without reading `claude-plugins.local.json`. The fix lives in
one pure projection that the writer and the `pending` mirror share, so the two cannot disagree
(D-01). The local file stays the only record of what is personal; `state.json` does not change
(D-01). Already-leaked entries are not repaired or flagged (D-03).
Output: the exclusion in `persistence/migrate-config.ts` with a `"local-invalid"` decline arm, the
`pending.ts` mirror, two read-only config steps, the SC1 and SC2 scenarios, and the unit,
integration, and reload proofs.
</objective>
