<objective>
Partition `marketplace autoupdate` and `noautoupdate` between a scope's two layers: a named flip
changes only its target layer and fails, with the D-04 reasons, when that layer does not declare
the marketplace (D-05); without `--scope` it flips the scopes it can and refuses only when none
could (D-09 Q8); a nameless flip sets the flag in every layer that declares each marketplace, or
in the local layer only with `--local` (D-06, D-09 Q9, Q10); idempotency reads the target layer's
own value (D-07). The entry synthesis disappears, and with it the unsynthesizable-source arm.

Purpose: LAYER-02 / SC2 for the two flip verbs, and the per-machine override the user described.
Output: the rewritten flip in `orchestrators/marketplace/autoupdate.ts`, the retired state-side
classifier, eight scenarios, and an integration file.
</objective>
