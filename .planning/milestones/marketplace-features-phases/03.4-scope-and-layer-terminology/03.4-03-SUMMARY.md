- **Issue:** The plan renames the two `const shared` locals in `mergeScopeConfigs` to `const base`. But `base` is already that function's parameter (`mergeScopeConfigs(base, local)`), so the local would shadow it inside the loop.
- **Fix:** The locals are `baseEntry`. They have the same meaning, and no `shared` name is left in the function.
- **Files modified:** extensions/pi-claude-marketplace/persistence/config-merge.ts
- **Commit:** 26688e8f

**2. The `--local` flag comment was rewrapped**
- The new comment wording made one line 83 characters long. I rewrapped the paragraph to 80 columns, so the unchanged "which selects the scope's state tree" clause moved to other lines.
