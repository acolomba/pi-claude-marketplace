## Sampling Rate

- **After every task commit:** run the task's leftover grep (it must print nothing), its scenarios by name, its owner tests, and the suites its verify block names; `npm run test:cucumber` and `CI=1 npm run check:features` when it changed a scenario, a step, or a user-visible string; `npm run test:integration` when it changed a string or an identifier an integration test pins. The commit hook runs `check:commit` (static checks, unpaired tests, staged-pair coverage) but no cucumber and no integration test.
- **After every plan wave:** `npm run check` on the combined tree (the orchestrator's post-merge gate; the plans run one after another, one per wave).
- **Before `/gsd-verify-work`:** plan 10's gate: leftover gates G1-G9 print nothing over the whole tree, `npm run check` is green, and the `fallow audit --base 1c3fc6c9` verdict is `pass`.
- **Max feedback latency:** ~10 seconds (one scenario, one owner test file, or one leftover grep).
