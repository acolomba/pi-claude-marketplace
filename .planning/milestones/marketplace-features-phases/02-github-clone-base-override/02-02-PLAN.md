<objective>
Bind every GitHub auth bundle to the override host, and route `marketplace add`, `marketplace update`,
and the `plugin update` marketplace sync through one GitHub auth helper. With the variable set, the
bundle is a stored credential for the override's `host[:port]` and no Device Flow runs; unset, every
bundle is exactly today's.

Purpose: GHB-02 requires the auth host to follow the same base as the wire URL, so the credential
lookup and isomorphic-git's `onAuth` host guard both see the host actually contacted. D-04 promises
Device Flow never runs for the override host. The research found the auth host spread over a
constant in `auth-host.ts`, an inline github.com template in `marketplace/update.ts`, and an eager
build in `plugin/update-flow.ts`; this plan folds them into one helper backed by the seam.
Output: the seam's host exports, `buildGitHubAuth`, the follow-the-override `hostFromCloneUrl` and
`buildCloneAuth`, three call sites switched, and an override case in each affected owner test.
</objective>
