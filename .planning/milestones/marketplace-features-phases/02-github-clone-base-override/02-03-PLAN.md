<objective>
Make an invalid `PI_CLAUDE_MARKETPLACE_GITHUB_BASE_URL` fail the whole command for the marketplace
verbs, `install`, `enable`, and `import`. Add one helper that rethrows the typed error from anywhere
in a caught error's cause chain, and call it first in every per-target catch those commands put on a
GitHub network path.

Purpose: D-08 settles GHB-03's "fails the command": the typed error is rethrown past per-target
catches, the way `marketplace add` already rethrows an unclassified error, with no new reason token.
Without it, `marketplace update` folds the error into `{network unreachable}`, orchestrated add into
`{unparseable}`, and install, enable, and import into failed rows that let the rest of the command run.
Output: `rethrowInvalidGitHubBaseUrl`, the rethrow at each listed catch, corrected never-rethrows
comments, and one case per command proving the whole command fails.
</objective>
