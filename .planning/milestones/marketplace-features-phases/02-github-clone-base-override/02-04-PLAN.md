<objective>
Finish D-08 for the remaining plugin commands that reach a GitHub network path: `reinstall`, `fetch`,
`info --fetch`, and `update`. Each per-target catch on those paths calls
`rethrowInvalidGitHubBaseUrl` first, so an invalid variable fails the whole command instead of
degrading to a row.

Purpose: GHB-03 for every command that reads the variable. Today `update`'s candidate resolution
folds the typed error into `(skipped) {no longer installable}`, `info --fetch` folds it into a
degraded row, and `reinstall` and `fetch` render failed rows and continue.
Output: seven rethrow call sites, corrected comments, one case per command, and one bare-info case
proving the read-only path never reads the variable.
</objective>
