<objective>
Close the two measured shortfalls that are plainly reachable through existing public
collaborators, so neither earns a pin row.

`D-08-03a` refused to classify `bridges/hooks/event-router.ts` by analogy and demanded
per-site measurement. `D-08-A04` reports the answer: all four uncovered sites (552-554,
586-588, 614-616, 871-873) are the SAME construct — `if (!generationIsCurrent()) { return; }`
— and all four are reachable through `createHooksHydration(runtime, ...)` and
`registerHooksBridge(pi, ...)`, because `HooksRuntime` is already an injected public
collaborator declaring `currentGeneration` and `advanceGeneration`. Measured with three
purposeful tests, the module reads `branches 114/114, functions 43/43, lines 967/967`.
"It was a split casualty" is a cause, not a classification, and it authorizes no pin.

`orchestrators/plugin/update-preflight.ts` is short by one exported predicate,
`isUpdatePreflightOutcome`, which the owner test's 18 cases never call even though
`update-flow.ts` consumes it in production. Two cases over values the owner test already
produces close it.

The carried hazard is test design, not reachability. A decorator that advances the generation
on the Nth `currentGeneration()` call works today at indices 3, 4, and 10 and breaks the first
time an `await` is added or removed anywhere in the hydration path. Each case must key its
advance on a named, semantically adjacent trigger and assert the consequence.

Purpose: remove two rows from the candidate pin set by covering reachable arms, per
`D-08-09a`.
Output: `bridges/hooks/event-router.ts` and `orchestrators/plugin/update-preflight.ts` both
reading complete, with no builtin patched and no test-only seam added.
</objective>
