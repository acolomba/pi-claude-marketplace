<objective>
Remove three dense-index guards whose arms no input can reach, by rewriting each loop to
typed iteration — so the three modules leave the accepted-shortfall set entirely instead of
being pinned.

`ER-F05` established the rewrite for `edge/args.ts`, `ER-F19` and `EHR-F16` for
`edge/handlers/shared.ts`, and `D-08-A03` adds `edge/handlers/plugin/pending.ts` as a third
guard of the same class that `D-08-09` does not name. All three were built, typechecked, and
re-measured complete in this tree under `strict` plus `noUncheckedIndexedAccess`, with no `!`
and no `as`. This reopens the ratified `D-116-01a` "compiler-forced" disposition for these
three modules only; every other module keeps it untouched.

The hazard is specific and measured: `edge/handlers/shared.ts`'s `i += 2` encodes lookahead,
not iteration. A conversion that drops the skip lets `--scope --local` set `local = true`,
which it does not do today, and the owner test stays green while flag parsing changes. Both
preservation cases are written before the loop is touched.

Purpose: an honest reading reached by removing unreachable code, which `D-08-09a` prefers
over pinning.
Output: three modules reading complete under the direct gate, and two cases pinning the
lookahead behavior the rewrites must preserve.
</objective>
