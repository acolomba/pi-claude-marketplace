## Trust boundaries

| Boundary                                   | Description                                                                                                 |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Extension root -> shared update callback   | A wrong closure or changed signature can split runtime/cache identity across direct and cascade operations. |
| Durable update -> route/cache finalization | Ordering determines whether routes and completion rows describe the committed plugin.                       |
| Target loop -> shared cache                | Broad invalidation can erase unrelated scope or marketplace state.                                          |
