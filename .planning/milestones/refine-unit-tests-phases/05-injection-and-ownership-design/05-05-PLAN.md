## Trust Boundaries

| Boundary                                               | Description                                                                                                      |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Persisted config/state to lifecycle transaction        | Malformed or stale records influence destructive install, replacement, or removal decisions.                     |
| Required transaction port to filesystem/state mutation | A controlled schedule operation must not bypass validation, containment, lock ownership, or result construction. |
| Prepared/staged paths to replace and rollback          | Derived paths cross destructive boundaries and require exact ordering and containment.                           |
| Committed mutation to cleanup/notification             | Cleanup eligibility and user-visible outcomes depend on whether persistence committed or rolled back.            |
