- Use the executed dependency summaries for final runtime and enable/disable transaction identifiers.

- Runtime route mutation follows the existing state commit and partial-cascade semantics; it is not a generic cache clear.
- A routing diagnostic after commit reports the exact warning/failure contract and does not roll durable state backward unless current semantics require it.
- Completion-cache invalidation is separate work in later plans. applyReconcile and bootstrapClaudePlugin remain unchanged full-observation controls.
- Preserve Phase 6 machinery, the exact Fallow comment, and excluded stage/PID/info/uninstall ownership.
