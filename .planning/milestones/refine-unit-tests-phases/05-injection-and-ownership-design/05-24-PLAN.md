## Trust boundaries

| Boundary                                     | Description                                                                                   |
| -------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Reinstall target -> destructive transaction  | Persisted records select preparation, replacement, rollback, finalization, and cleanup paths. |
| Optional selector -> required cache contract | An incomplete census can leave test-only or hidden fallback authority reachable.              |
| Durable finalization -> target invalidation  | Wrong eligibility or identity can expose stale or unrelated completion rows.                  |
| Apply/backfill -> real reinstall             | Substitution can hide transaction, scope, or notification defects.                            |

## STRIDE threat register

| Threat ID | Category                           | Component                          | Severity | Disposition | Mitigation plan                                                                                     |
| --------- | ---------------------------------- | ---------------------------------- | -------- | ----------- | --------------------------------------------------------------------------------------------------- |
| T-05-104  | Tampering / Elevation of privilege | reinstall transaction              | high     | mitigate    | Preserve validation, containment, required semantic operations, prepare-all, and rollback order.    |
| T-05-105  | Tampering                          | selector removal                   | high     | mitigate    | Record fresh callers, migrate every genuine use, and require the production cache with no fallback. |
| T-05-106  | Tampering / Information disclosure | invalidation eligibility/isolation | high     | mitigate    | Drop only finalized targets and prove exact same/peer/unrelated rows.                               |
| T-05-107  | Tampering / Repudiation            | apply/backfill composition         | high     | mitigate    | Keep real reinstall plus complete state/tree/row/error/silence/notification evidence.               |
| T-05-108  | Denial of service                  | refresh and cleanup failures       | medium   | mitigate    | Preserve deferred-warning and independent cleanup behavior after durable success.                   |
