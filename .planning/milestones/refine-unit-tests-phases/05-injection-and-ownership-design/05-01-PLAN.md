## Trust Boundaries

| Boundary                                         | Description                                                                                                                                                                             |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Recorded skill names -> managed skills directory | Persisted names influence recursive deletion targets and must remain name-validated, contained, and symlink-safe before the remover runs.                                               |
| Candidate path -> path-safety guard              | Untrusted or stale paths cross lexical, normalized containment, and component-inspection checks before filesystem work proceeds.                                                        |
| Required port -> Node filesystem                 | A substituted capability may control a fault or timing edge, but must not gain authority over validation, traversal decisions, output construction, or unrelated filesystem operations. |

| Threat ID | Category                           | Component                               | Severity | Disposition | Mitigation Plan                                                                                                                                                                                                   |
| --------- | ---------------------------------- | --------------------------------------- | -------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-05-01   | Tampering / Elevation of privilege | `unstagePluginSkills` recursive removal | high     | mitigate    | Keep `assertSafeName`, `assertPathInside`, and lstat-based existence checks in the consumer before the required remover; prove outside and symlink destinations retain exact bytes through real-tree owner cases. |
| T-05-02   | Tampering / Elevation of privilege | `createPathSafetyGuard` inspection      | high     | mitigate    | Limit `PathSafetyInspector` to lstat/readlink, retain lexical and normalized containment in the guard, and prove a fake cannot bypass rejection while the Node adapter refuses real symlinks.                     |
| T-05-03   | Tampering                          | production adapter composition          | medium   | mitigate    | Require factory arguments and compose each public production export from an explicit private Node adapter; TypeScript plus forwarding tests must fail if a port is omitted or bypassed.                           |
| T-05-04   | Denial of service / Repudiation    | ordered removal and component walk      | medium   | mitigate    | Preserve input/segment order, ENOENT fixed-point behavior, original thrown values, and observable partial filesystem state; assert results/state before collaborator call logs.                                   |
