## Trust boundaries

| Boundary                                 | Description                                                                              |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| Reinstall targets -> staged replacements | User and persisted targets select destructive prepare, replace, and rollback operations. |
| Durable replacement -> runtime routes    | A premature finalization can expose failed content or erase live routes.                 |
| Apply/backfill -> real reinstall         | A child substitute can hide transaction, cleanup, scope, or notification defects.        |
