## Trust boundaries

| Boundary                                | Description                                                                               |
| --------------------------------------- | ----------------------------------------------------------------------------------------- |
| Extension invocation -> owned graph     | Wrong construction or forwarding can leak state across independent loads.                 |
| Reload generation -> retained callbacks | Old callbacks can outlive registration and reach filesystem, child, state, or Pi effects. |
| Awaited callback -> current lifecycle   | Work can become stale during an await and must not mutate the new generation.             |
