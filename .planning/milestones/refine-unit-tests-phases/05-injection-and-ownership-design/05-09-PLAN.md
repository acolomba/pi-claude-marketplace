## Trust Boundaries

| Boundary                                     | Description                                                                             |
| -------------------------------------------- | --------------------------------------------------------------------------------------- |
| Extension invocation to runtime              | A wrong construction site can share routing and pending state across independent loads. |
| Persisted hooks state to runtime routes      | Stored paths and records become executable routes only after validation and hydration.  |
| Registration generation to retained callback | Old callback functions can outlive reload and must stop before every side effect.       |
