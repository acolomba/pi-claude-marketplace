## Trust Boundaries

| Boundary                               | Description                                                                                          |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Registered dispatch to spawned process | Plugin-controlled hooks start child processes whose output and timing cross asynchronous boundaries. |
| Child terminal event to Pi session     | A callback can complete after reload and must not affect the new lifecycle.                          |
| Persisted PID table to OS signal       | A recorded PID can belong to another process; marker verification and conservative skips protect it. |
| Runtime-scoped reload to live children | Shutdown must stop only children owned by that lifecycle.                                            |
