<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| corpus/assignment/JSON → validator | Untrusted repository text and structured records cross into executable tooling |
| stored paths → filesystem | Ledger references may attempt traversal or symlink escape |
| probes → evidence artifacts | Commands may disclose credentials, real paths, or destructive effects |
| JSON → generated Markdown | Manual or injected generated-view changes could mislead operators |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering/Information Disclosure | path resolution | high | mitigate | Normalize and containment-check repository-relative paths, reject absolute/dot-dot/symlink escape, and prove with planted fixtures. |
| T-01-02 | Spoofing/Tampering | corpus Markdown | high | mitigate | Parse as evidence data only; fixed schema and project instructions control execution; plant instruction-like content. |
| T-01-03 | Information Disclosure | probe results | high | mitigate | Hermetic roots, secret redaction, no network/credentials/real-state access without later explicit approval. |
| T-01-04 | Tampering | generated Markdown | high | mitigate | Render only from canonical JSON and byte-compare on validate. |
| T-01-05 | Denial of Service | incomplete/interrupted merge | medium | mitigate | Plan-owned shards, deterministic merge, and incomplete-state rejection prevent false completion. |
| T-01-SC | Tampering | package installs | high | mitigate | No package install is planned; built-in Node facilities only. |
</threat_model>
