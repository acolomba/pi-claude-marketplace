<objective>
Enroll the two closed sets that no architecture gate covers — `ClaudeHookEvent` and `Dependency` —
and correct the doc comment that claims a guarantee the compiler does not give.

Purpose: research ran the compiler on a reduced case and `tsc --noEmit --strict` exited 0 with a
union member absent from a `satisfies readonly T[]` tuple. So the `hook-events.ts` claim that
adding a value "without the matching `ClaudeHookEvent` edit (or vice versa) breaks the typecheck"
is half false: a member added to the union and never registered in `BUCKET_A_EVENTS` compiles
clean and silently never routes. That is the optional-field silent-omission class this milestone
has hit repeatedly, and it is the mechanically detectable content of `SCN-F025`.

Output: a compile-time reverse proof in the production module, a corrected doc block, a length
tripwire, and a `Dependency` enrollment built on runtime surface that already exists.
</objective>
