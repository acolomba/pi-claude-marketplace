<objective>
Complete `tests/architecture/gate-targets.ts` so that every production path any architecture gate
addresses lives in one module as a full literal repo-relative string, and gate the registry itself
on resolution, non-emptiness, and non-composition.

Purpose: `D-07-05` exists because a literal-match stale-path scan cannot see a composed reference,
and two gates were measured still addressing retired ledger modules through `path.join`. Seeding
the complete registry in one plan lets waves 3 through 7 import rather than write, which is what
keeps the registry serialized without serializing the phase.

Output: a complete registry and `tests/architecture/gate-targets.test.ts` carrying the resolution,
non-emptiness, duplicate, and non-composition clauses. The self-hosting meta-gate clause
(`D-07-06`) lands later, in `07-16-PLAN.md`, once every gate has been migrated.
</objective>
