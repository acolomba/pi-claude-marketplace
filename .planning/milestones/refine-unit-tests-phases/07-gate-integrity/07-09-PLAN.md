<objective>
Close the two delegated-contract gaps in the hooks bridge suites: a production table copied into a
test as its own oracle, and optional collaborators that every case passes `undefined`.

Purpose: `GGAT-04` requires that closed-set and delegated-contract gates exercise their real
production consumers. A test that restates a production table proves the two copies agree at the
moment someone typed them, and nothing after that. An optional parameter that is only ever
`undefined` is untested surface wearing a type annotation — and this milestone has repeatedly found
that a member added to a closed set compiles clean at every derivation site.

Output: expectations derived from what the production table makes observable, and at least one real
value through every optional collaborator, with the supplied and omitted paths distinguished.
</objective>
