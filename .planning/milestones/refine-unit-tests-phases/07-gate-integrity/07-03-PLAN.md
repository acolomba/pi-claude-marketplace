<objective>
Make the changed-pair gate's base selection deterministic, auditable, and fail-closed, and prove
all three in the negative harness that already runs inside `npm run check`.

Purpose: `gitLines` currently discards stderr, ignores the exit status, and collapses every
failure class into `[]`. Measured consequence: on a checkout with no `origin/main`, the entire
`mergeBase...HEAD` diff branch is skipped silently, `changedPaths()` returns `[]` on a clean tree,
and the gate prints "No changed source-test pairs." and exits 0. A broken selector and a docs-only
commit are byte-identical outcomes today. `D-07-16` puts the behaviour change and its proofs here;
Phase 8 wires the already-correct gate into pre-commit and CI.

Output: an ordered, printed, fail-closed base selection with a root parameter, and three fixture
repositories in the negative harness that plant the head of the chain, the tail of the chain, and
the resolved-but-empty case.
</objective>
