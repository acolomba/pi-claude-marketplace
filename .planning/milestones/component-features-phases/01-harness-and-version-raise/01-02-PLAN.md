Add a section "Profile Pis and the scripted model" to `world-and-stand-ins.md`, written as rules in the file's style:
1. The run's shared Pi keeps no model and no companions. A scenario that needs either starts a profile Pi through a `Given`, through the world's profile method; the profile Pi runs in the run's sandbox, becomes the Pi the steps talk to, and is stopped with its process group in the scenario's release (D-CF1-15). It loads the real extension, the scripted model, the registry probe, and the companions a step names, resolved from each companion's `pi.extensions` entry in the optional peer cache and checked against the declared floor; it runs with `TMPDIR` inside the sandbox home.
2. Project trust (D-CF1-07): the profile Pi trusts the sandbox project through a persisted entry in `<agent dir>/trust.json`, never `--approve` or `defaultProjectTrust`. Pi trusts a project that holds no trust-requiring resource whatever `trust.json` says, so an untrusted scenario also writes `<project>/.pi/settings.json`, and the trusted scenario beside it holds the same file. Project MCP server approval is a separate `Given` that writes pi-mcp-adapter's user-level `projectServers` setting; it is never part of the default.
3. The scripted model (D-CF1-17): Pi's faux provider, loaded as a Pi extension from `features/lib/scripted-model/`. It reads the scenario's script from a file in the sandbox home and counts its own call log to know the next step, so a child agent's Pi reads the same script; the script, the log, and the counter reset with the sandbox. It records every call whole (messages, tools, system prompt). There is no fallback reply: a call past the script fails the turn, and steps left unused fail the scenario. A feature file writes the whole script as literals; a `Then` reads the call log, never the script.
4. The model-turn `When`: it sends the prompt and, unless Pi reports the `handled` disposition, waits for `agent_settled` with `aborted: false` under a named deadline; it keeps every record the turn produced (RPC events, tool events, custom entries, notifies, extension errors) and every line the stand-ins logged during the turn. No fixed sleep. A `Then` that reads the turn marks it compared, and the world fails a passed scenario whose last turn no step compared. Pi queues a prompt sent during a turn as a follow-up, so a step never sends a second prompt before the first settles.
5. Stand-ins (D-CF1-17): the registry probe is a Pi extension under `features/lib/pi-registry-probe/` that reports Pi's tools (all and active) and commands as a custom entry; the hook recorder (`features/lib/hook-recorder.ts`) runs as a hook command and logs each run's event, stdin, arguments, and `CLAUDE_*` environment; the MCP stub (`features/lib/mcp-stub-server.ts`) is a dependency-free stdio JSON-RPC server that logs every request, writes a pid file, and exits when its stdin closes. All of them are `.ts` files under `features/lib/` and never under `features/support/`, which cucumber imports into every worker. A Pi extension under `features/lib/` carries `// fallow-ignore-next-line unused-export -- Pi's --extension loader reads this default.` above its default export.
6. Records are never filtered or deduplicated: since pi-mcp-adapter 6.0, a call through the `mcp` proxy runs the real tool as a nested Pi tool call, so a step lists both the `mcp` event and the real tool's event.
7. The reset asserts a clean baseline: after the profile Pi stops, every pid the stand-ins recorded is dead, and the script has no unused step; the next scenario's `Before()` empties the sandbox.
8. CI (D-CF1-16): the behavioral job runs as two path shards, lifecycle (`features/marketplace`, `features/plugin`) and components (the six function directories); `npm run check:features` dry-runs every scenario, so sharding hides no unused step.
9. A note for scenario authors of skills and commands: an argument word that starts with `!` reaches the model as `\!` (Claude Code's `xM`, D-CF1-01), so a scenario that types such an argument states the backslash; it is upstream parity, not a defect.
