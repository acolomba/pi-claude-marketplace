<objective>
A project command whose install this user did not make, or whose staged file
changed after it, runs nothing (the check half of D-CF3-07).

Decision implemented: D-CF3-07 (the invocation runs a project-scope command
only when Pi trusts the project and the user's ledger lists its generated name
with the SHA-256 of the staged file as it is now; otherwise it aborts with a
message in D-CF2-13's shape). D-CF2-13's current shape names the `reinstall`
command, because the project's `state.json` already records the plugin and
`install` would refuse it; the abort follows that shape.

Purpose: a repository that commits `.pi/pi-claude-marketplace/` cannot make
its staged commands run their `!` commands on a machine whose user never
installed the plugin into that project, and a pull that edits a staged command
cannot change what runs.

Output: the check in `orchestrators/command-invocation.ts` and the invocation
scenarios of `features/slash-command/project-provenance.feature`.
</objective>
