<objective>
Command frontmatter fields behave as Claude Code 2.1.316 defines them or are
reported as recorded divergences (CMD-03).

Decisions implemented: D-CF3-09 (the dropped-fields warning, one line per
command, none for a command whose frontmatter does not parse; pins D-CF1-05),
D-CF3-01 (a command stays a prompt template only the user invokes; the model's
system prompt does not list it), D-CF3-02 (`user-invocable: false` keeps the
command listed and runnable), and D-CF3-10 (`argument-hint` reaches Pi's
terminal menu, the only place Pi shows it).

Purpose: a plugin author who sets `model` or `effort` on a command learns at
install that Pi drops it, and the other frontmatter rules are pinned through
what Pi lists, what the model receives, and what the terminal shows.

Output: the dropped-fields line in `bridges/commands/staged-command.ts`, its
collection in `stage.ts`, `features/slash-command/frontmatter.feature`, and the
terminal-menu steps.
