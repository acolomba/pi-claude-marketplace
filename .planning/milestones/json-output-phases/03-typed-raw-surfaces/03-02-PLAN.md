> **Flagged assumption (RAWS-02, unclassified probe, unresolved):** diagnostic
> lines keep caller order and duplicates. An empty-string element is kept and
> renders as an empty line. A single line renders as the header, one blank line,
> and the line. Only a zero-length array is a no-op, and the header never
> renders alone. Today's bytes match this, and the task tests pin each case.

Prohibition recall for RAWS-02 and RAWS-05 considered these candidates:

- a dropped diagnostic
- a hidden cap warning
- a trimmed or sanitized rewake summary
- a changed cap number
- a header rendered without lines
- severity drift
- a rewake summary given a plugin prefix
- path disclosure in diagnostic lines
- a run object handed to hooks
- a new pluginId field

Severity drift, the cap number, and the run and pluginId items are routine or
decided (D-07, D-08, Phase 1 D-07). Path disclosure is canon information
exposure: the producers keep their redaction and `/gsd-secure-phase` owns it,
so it is not minted. Two kept items, transparency (no silent suppression,
D-88-01) and author fidelity (no rewriting), are the descriptor-less
prohibitions above.
