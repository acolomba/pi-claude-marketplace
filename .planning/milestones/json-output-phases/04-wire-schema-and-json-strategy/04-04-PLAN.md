## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Thrown message to model | Git, HTTP, and filesystem errors can carry URLs with userinfo or tokens. |
| Stored source to info output | A url-source marketplace record can hold userinfo the user typed. |
| Model to text and JSON | Both strategies read the redacted model; JSON entries persist in the session file. |
