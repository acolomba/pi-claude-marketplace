Give each of the 25 open WINDOWS.md entries a fixed or waived disposition with an auditable reason, so the /gsd-ship broken-windows gate reads zero open (SC-1), then run the phase gate on the final tree (SC-5). Dispositions: waive 32-34 and 41-58 as moot (D-01, D-02), waive 84 to its WOUT-01 carrier (D-03), fix 85 (D-04), waive 88 as accepted design (D-05), fix 89 now that the resolver-order fix is on the branch (D-06).

The ledger changes only through the windows verbs, never by hand. 08-RESEARCH.md measured three hazards in those verbs. An unquoted reason is silently cut to its first word, and the entry then cannot be re-waived. zsh treats an unquoted [json-output] as a glob. A half-finished batch refuses to run again from the top. So all 25 verbs go through one retry-safe Node script that passes each reason as a single argv element, and that script first runs against a copy of the ledger.

This phase has no REQUIREMENTS.md IDs (closeout phase); this plan serves ROADMAP Phase 8 success criteria SC-1 and SC-5 and holds the phase gate.

Purpose: the milestone can ship without a broken-windows block, and every disposition says why.
Output: one WINDOWS.md commit, and the phase gate evidence in 08-04-SUMMARY.md.

Where commands run: from the root of the main checkout (branch features/json), never from an executor worktree. gsd-tools is gitignored and absent from worktrees, and the ledger must have one writer.
</objective>
