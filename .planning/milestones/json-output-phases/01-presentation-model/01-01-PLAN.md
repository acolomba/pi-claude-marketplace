Per D-01, create `scripts/notify-corpus.hook.mjs`, an `--import` preload that imports
`registerHooks` from `node:module` (never `module.register`, which Node 26 runtime-deprecates as
DEP0205). It reads the output directory from the env var `NOTIFY_CORPUS_OUT` and does nothing at
all when that variable is unset. It records only when `process.argv[1]` ends with `.test.ts`, so
forked children such as `tests/integration/concurrent-install-child.ts` never record. It defines
`globalThis.__corpusNotify = (ui, ...args) => { ...; return ui.notify(...args); }`: before
delegating, it appends one JSON line `{ file, message, severity, argc }` to
`<NOTIFY_CORPUS_OUT>/<process.pid>.jsonl` with `appendFileSync` (file = `process.argv[1]` relative
to `process.cwd()` with `/` separators; severity = `args[1] ?? null`; argc = `args.length`). Its
`load` hook calls `nextLoad`, and for URLs that contain `/extensions/pi-claude-marketplace/` and end
in `.ts` it replaces `/\b([A-Za-z_$][\w$]*)\.ui\.notify\(/g` with `globalThis.__corpusNotify($1.ui, `
in the returned source. The receiver expression is evaluated once, and `this` stays `ui`, so strict
`ctx.ui ... .times(n)` mocks keep passing.

Create `scripts/notify-corpus.mjs`, following the analog's structure: `node:` built-ins only, a
header block that explains the tool and names its `.negative.mjs` companion, pure exported helpers,
and a guarded `main`. Export these helpers:
- `normalizeMessage(text, roots)`: replaces each root with its placeholder in descending order of
  root length, so a nested root (a worktree under the temp dir, a temp dir under home) is matched
  by its most specific placeholder. The temp root (`os.tmpdir()`) replaces the whole path token up
  to whitespace, `'`, `"`, or `)` with `<TMPPATH>`. `process.cwd()` and `os.homedir()` replace only
  the prefix, with `<CWD>` and `<HOME>`. Then UUIDs become `<UUID>`, and `(\.json)\.\d{4,}` becomes
  `$1.<N>`.
- `serializeCorpus(entries)`: sorts by file, then by the JSON of `[message, severity, argc]`. It
  writes one `JSON.stringify` line per entry and escapes every non-ASCII UTF-16 unit as `\uXXXX`,
  so the file survives the pre-commit texthooks and needs no Prettier formatting (Pitfall C). It
  ends the file with a newline.
- `parseCorpus(text)`.
- `diffCorpus(baseline, capture)`: groups entries by file into a multiset (`Map` of key -> count)
  and returns `{ missing: [{ file, message, severity, argc, count }], extra: [same shape],
  totals: { baseline, capture } }`. Per D-02, missing means the baseline count exceeds the capture
  count for that file and key.

Implement the CLI verbs:
- `capture --out <file> [--files <path> ...]`: creates a `mkdtemp` directory, spawns
  `process.execPath` with `--import <absolute hook path> --test <paths>` and
  `env: { ...process.env, NOTIFY_CORPUS_OUT: dir }`, `stdio: "inherit"`. It exits non-zero when the
  test run exits non-zero, because a failing suite yields an incomplete corpus. Then it merges every
  `*.jsonl` in the directory, normalizes each message, serializes to `--out`, and removes the temp
  directory in `finally`.
- `diff <baseline> <capture>`: prints every missing entry on stderr as
  `missing in <file>: <message excerpt> (argc <n>, severity <s>) x<count>`, and every extra entry on
  stdout for review. It exits 1 when anything is missing.

This task wires only `--files`; Task 2 adds suite discovery, the count floor, and the `check` and
`baseline` verbs.
