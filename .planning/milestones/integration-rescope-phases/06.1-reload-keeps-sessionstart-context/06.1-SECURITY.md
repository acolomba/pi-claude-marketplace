# Phase 06.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Plugin hook output → session and model | A SessionStart hook's `additionalContext` is written into the Pi session when the hooks finish, or steered into a running agent after a compaction | Hook text, capped at 10,000 characters (D-PG5-14) |
| Saved session file → bridge | A resume or a fork reads the held context keys from the conversation Pi loaded | Message text and untyped `details` |
| One Pi session → the next | A new session must not get the earlier session's context, and a resume or fork must not get it twice | None (the runtime keeps no SessionStart state) |
| Hooks bridge → Pi event loop | The send and the projection read run inside `session_start` and `session_compact` | Thrown errors (NFR-2) |
| Deliberate breaks → committed tree | The breaks changed product files for one run each | Source text; must never be committed |
