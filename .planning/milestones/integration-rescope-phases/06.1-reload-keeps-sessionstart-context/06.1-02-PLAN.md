## Trust Boundaries

| Boundary | Description |
| --- | --- |
| the saved session file to the bridge | A resume or a fork reads the conversation Pi loaded from the user's session file, including `details` values that an earlier run, another tool, or a hand edit wrote. |
| plugin hook output to the session and the model | A plugin's SessionStart hook decides the values the bridge now compares and writes into `details`. |
