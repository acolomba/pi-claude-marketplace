<objective>
Close the gap HKRL-03 that review WR-02 found: since HKRL-01 the SessionStart(`compact`) context
goes out at once with `{ triggerTurn: false }`, and Pi holds such a message to the turn end while
a run is active. Two compaction paths then miss the next model call: a threshold compaction in
the middle of a run (Pi compacts between a tool turn and the next call) and the retry after an
overflow compaction. Claude Code 2.1.330 puts the compaction's SessionStart rows after the summary
and the kept messages of the very next request (`z9`, `Nje`; `06.1-UPSTREAM-EVIDENCE-FORK-COMPACT.md`).
The user chose to fix it now (CONTEXT [Review scope, user decision 2026-11-23]): the bridge steers
the context into the run (`deliverAs: "steer"`) when Pi retries after an overflow or compacts
between two turns, and keeps `{ triggerTurn: false }` everywhere else, because a steer after the
run ended starts an extra model call (research break Bd).

Test first in two slices. Task 1 (the tracer) steers on an overflow retry, with the single-call
model step and the manual and overflow scenarios. Task 2 adds the run phase that `turn_start`,
`turn_end`, and `agent_end` keep, with the tool-row `context tokens` of the scripted model and
the mid-run and full-reply scenarios. Task 3 updates the docs and the decision row, runs breaks
Bd, Bf, Bg, and Bi on the final tree, and runs the full checks.

Purpose: HKRL-03 and ROADMAP Phase 06.1 success criterion 5; review WR-02; the AGENTS.md rule that
a user-visible change ships with a scenario that fails without it; the milestone rule "Upstream
parity". HKRL-01 and HKRL-02 must stay true.

Output: three commits (the overflow tracer, the run phase, the docs) and `06.1-03-SUMMARY.md` with
the red proofs, the checks, and the parent lines.
</objective>
