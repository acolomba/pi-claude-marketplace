**The driver** (CONTEXT [Print driver]; RESEARCH "Summary" and "Code Examples"). Pi's print mode
gives an extension a notify that does nothing, prints an error that a command throws on stderr as
`Extension error (command:claude:plugin): <message>`, and exits 0 (Pi 1.5.1,
`dist/core/extensions/runner.js:136`, `dist/core/agent-session.js:1793-1803`,
`dist/modes/print-mode.js`; measured).

- L1, `features/lib/pi-one-shot.ts` (NEW): `OneShotLaunch` (the sandbox, git environment,
  `TMPDIR` environment, and extensions of a one-shot Pi), `OneShotOutput` (`exitCode`, `stdout`,
  `stderr`), and `runOneShotPi(launch, mode, command, onRelease, timeoutMs)`. Json mode passes the
  scripted model's extension and the launch's extensions with `--mode json` and the command; print
  mode passes the terminal form with no `--mode`, then `-p` and the command. The process start,
  the group kill handed to `onRelease` before the wait, the deadline, and the error text move
  unchanged from `pi-json-mode.ts`, the error naming its mode. A separate print driver failed
  `fallow dupes` with a 27-line clone of the json one (`dup:077716d6`, RESEARCH "Don't Hand-Roll"),
  so the code moves and is not copied (D-BG-601).
- L2, `features/lib/pi-json-mode.ts`: `runJsonModeCommand` calls `runOneShotPi(launch, "json",
  ...)` and keeps its exit-code check, its custom-entry parsing, and its payload checks;
  `JsonModeLaunch` becomes an alias of `OneShotLaunch`.
- L3, `features/support/world.ts`: `OneShotPiLaunch` gains `extensions`; `oneShotPiLaunch()`
  returns `git: this.tuiEnvironment ?? piEnvironment` and `extensions: this.tuiExtensions`, the two
  fields that `keepTerminalSessionLocal` sets for a profile Pi that runs without the GitHub base
  override, after it refuses one that does not load the GitHub redirect (`world.ts:1099-1117`); its
  doc comment says so. A public field `printModeRun: OneShotOutput | undefined` keeps the last
  print-mode run for the `Then` steps. A one-shot Pi with the routed environment but without the
  redirect would reach GitHub's real address; the launch now carries both or neither (RESEARCH,
  "The print driver's routed launch"). No routed scenario uses json mode today.
