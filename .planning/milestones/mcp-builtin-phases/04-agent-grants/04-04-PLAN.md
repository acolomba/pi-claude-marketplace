<objective>
Fill the frozen agent grants step so that, after a switch between MCP implementations, the next session start rewrites exactly the generated agent files whose grant form changed, atomically, under the scope's state lock, with no user action (MGRT-01 switch side, D-MB-03), and so that a pi-subagents background child rewrites nothing (MGRT-02, D-MB-12). The file format work lives in two new agents-bridge modules; the step decides when, which scopes, and the lock.

Purpose: an agent's grant must name the server the active implementation serves; a switch is installing or removing pi-mcp-adapter, which runs no plugin command, so only the load can fix the files. Agents installed before this release get the same rewrite through a textual translation (CONTEXT "Legacy rows", revised; P4-DC-06).
Output: `bridges/agents/grant-rewrite.ts`, `bridges/agents/legacy-grant-form.ts`, their barrel exports, the filled `orchestrators/mcp/agent-grants-step.ts`, and their unit pairs.
</objective>
