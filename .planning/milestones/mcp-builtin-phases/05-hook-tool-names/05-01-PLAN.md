Make plugin hooks see Pi's built-in MCP tools under Claude Code's names (MHK-01): the server segment as Pi registered it, with `-` kept, and only the tool segment in Pi's folded form. Under the built-in profile today its matchers never fire, because Pi folds the server name. This plan is the MHK-01 core that 05-02 (proxy rule) and 05-03 (fold scenario, notice scenario, docs) build on.
Output: two new modules with their unit pairs, the dispatch and `if` threading, and the shared `@mcp` scenario with its profile-aware step.
