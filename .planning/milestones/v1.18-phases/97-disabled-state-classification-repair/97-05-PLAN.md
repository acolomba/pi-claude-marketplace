<objective>
Make `update` leave a disabled partially-installed record alone. The ENBL-05
collapse routes the record into the existing disabled short-circuit; the
short-circuit's own record write then needs one edit, because it hard-codes full
availability while copying the unsupported list from the resolution — producing a
self-contradictory record.

Purpose: without the derive, the first `update --partial` over a disabled partial
writes a record claiming full availability alongside a non-empty unsupported list,
and the row for that same record flips between disabled and partially-installed on
subsequent reads.

Output: a derived availability discriminant in the refresh, plus two tests
exercising `--partial` — which is the only invocation that reaches the
short-circuit at all.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| resolver result → persisted `compatibility` block | The update path rewrites a record's availability discriminant. A value that disagrees with the accompanying unsupported list is a state lie every downstream classifier reads. |
| `update` → staging directories | The three-phase update stages into the extension root and commits by atomic rename. The short-circuit must return before any staging begins. |

Update is git-source-network-capable on cache miss, but every fixture here is a path-source
marketplace resolved from disk, and the short-circuit returns before any prepare phase. No new
input surface.
