<objective>
Route the MCP config notices for `update` and `reinstall`, the two verbs that re-stage MCP servers outside the install ledger.

Purpose: AFILE-04 / D-02-09. Update commits MCP through `commitPreparedMcp` in its hand-rolled phase 3a, and reinstall through `replacePreparedMcp`. Both read `handles.mcp.result`, which now carries `notices` (plan 02-04). Their warnings today reach a standalone user only through the discovery half (`splitStagingWarnings` treats mcp as hygiene), so the notice needs its own carrier on each outcome and one seam call where the rows render.

Output: notice carriers on the update and reinstall outcomes, the surfacing calls in `update-flow.ts` and `reinstall-flow.ts`, owner tests, and one commit.
</objective>
