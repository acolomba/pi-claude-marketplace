<objective>
Refuse, before any write, every server key that collides with another after Claude's normalization or after Pi's `-`/`_` fold, within one plugin, across plugins and against user servers.

Purpose: ANAME-03 (D-03-12, D-03-13). The adapter keys servers by one name, and Pi gives keys that differ only by `-` versus `_` one deferred-tool namespace (`mcp__` plus the key with `-` folded), so either clash makes one server shadow another. Claude Code keeps `-`, so the folded refusal is a Pi-only divergence (license: Pi capability gap), documented by plan 03-09.

Output: `McpServerKeyCollisionError`, `foldedMcpServerKey`, the folded collision walk, one commit.
</objective>
