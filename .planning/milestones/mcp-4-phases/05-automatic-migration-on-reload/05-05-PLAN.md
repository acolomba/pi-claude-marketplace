<objective>
Remove what the installed plugin no longer provides, keep the record truthful, and prove the write order under faults.

Purpose: the removal half of AMIG-01 (D-05-04, D-05-06, D-05-07, the disabled-record default) and AMIG-02's fault-injection proof (D-05-16). After plan 05-04 every owner either moves or is left in place with a reason; an owner whose source declares fewer servers, blocks one, is malformed, or is disabled is still skipped. This plan removes those entries in the same `mcp.json` write, records the D-05-06 partial state before the trigger disappears, lists every removal in the notice, and proves with an injected recorder and a real filesystem refusal that every crash point converges.

Output: the removal arms, the removed and unfinished rows, the catalog block, the fault-injection unit and integration cases, one commit.
</objective>
