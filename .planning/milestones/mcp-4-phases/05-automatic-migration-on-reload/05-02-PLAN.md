<objective>
Install a plugin MCP server whose only gap is a Claude-side tool restriction, and warn that the restriction is not enforced.

Purpose: D-05-05, the operator rule that amends D-03-10 and D-03-20: a server that would not work as in Claude Code is not installed; a server that works and only loses a Claude-side restriction is installed with a warning. `tools[].permission_policy` and a non-empty `toolPermissions` move from the blocking `{unsupported mcp}` set to a warning. The warning travels by the structured-notice route (`StageMcpCommitResult.notices`), so install, update, reinstall, enable, import, reconcile and the reload migration all report it, and a migrated plugin matches a fresh install (AMIG-01). The migration notice built in plan 05-01 renders it through the shared section builder (AMIG-03, D-05-15).

Output: the amended domain table, the stage notice, the dispatch section, the catalog and compatibility-doc amendments, paired unit tests at 100% direct coverage, an end-to-end install case, a migration case, one commit.
</objective>
