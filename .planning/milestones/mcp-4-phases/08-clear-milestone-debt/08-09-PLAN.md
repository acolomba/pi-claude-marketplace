<objective>
Lay the foundation for OWNKEY-01: one own-key helper every zone may import, a `__proto__` name rule
at the two places a name becomes a state key, and `marketplace add` moved onto both.

Purpose: DEBT-04 (D-08-07). Name-indexed state lookups read inherited `Object.prototype` members,
and a bracket write with `__proto__` reparents the map and drops the record. The operator ruled:
only `__proto__` is rejected by name validation; `constructor`, `toString` and the rest stay valid
and work because every read checks own keys. This plan delivers the helper and the rule; plans
08-15 to 08-18 move the remaining read and write sites onto the helper, and 08-19 proves the sweep end to end.

Output: two commits, one new source-test pair.
</objective>
