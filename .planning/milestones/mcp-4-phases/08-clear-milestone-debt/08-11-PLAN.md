<objective>
Give the install ledger and enable an explicit staging environment, defaulting to Pi's process
environment at the operation's entry point.

Purpose: DEBT-04 (D-08-06, closes P4 IN-02 with plan 08-12 and 08-13). Staging today reads
`process.env` implicitly, so orchestrator tests rely on a global sentinel. D-08-06 threads a
`ClaudeEnv` through the install ledger into `prepareStageMcpServers`, defaulting to `process.env` at
the entry point the way `orchestrators/plugin/info.ts` does. This plan covers install, the reload's
dependency install, the install cascade and enable; 08-12 covers update, reinstall and the migration;
08-13 makes the bridge's `env` required.

Note on the house rule: skills/typescript-unit-testing §Design prefers binding a live boundary in the
composition module over a default parameter. D-08-06 is a locked decision that names the info.ts
default-parameter form, so this plan follows it; the composition module (operations.ts) stays
unchanged and every lower layer takes `env` as a required value.

Output: two commits.
</objective>
