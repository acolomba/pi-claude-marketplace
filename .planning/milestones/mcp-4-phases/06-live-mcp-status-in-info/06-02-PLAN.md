<objective>
Settle the one case where a snapshot entry belongs to only one of two rows: the same plugin installed in both scopes (D-06-09).

Purpose: both scopes' `mcp-adapter.json` then hold the same key, pi-mcp-adapter loads the project file last, and its snapshot has one entry. Output: the tenth `McpServerStatus` member, the shadow rule in `withMcpServerStatus`, the read-only project-record lookup in `info.ts`, a byte-locked both-scopes catalog state with its prose, the enrollment bump, owner tests, and one commit.
