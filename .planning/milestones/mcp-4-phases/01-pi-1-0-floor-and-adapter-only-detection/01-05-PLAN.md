<objective>
Make the MCP soft-dependency probe count pi-mcp-adapter itself and nothing else.

Purpose: ADET-02 (amended by D-01-05) counts the adapter by its `mcp-adapter` command or a
`pi-mcp-adapter` source. A bare `mcp` tool no longer counts; today a foreign `mcp` tool suppresses
the warning, and that false positive was reproduced live. ADET-01 requires built-in-only and
"neither" sessions to keep the marker, proven by the D-01-06 mock matrix. This plan proves it in
the unit layer plus two e2e mock-Pi cases. Plan 01-06 runs all six states through the e2e mock
matrix and updates the PRD rules (D-01-20). Plan 01-07 adds the info line, and plan 01-08 the
real-Pi proof. This plan also renames `ToolInventory` to `PiInventory` (D-01-14 IN-02).

`pi-api.ts:100-124` contract pins do not move. Plan 01-01 already moved them once.


Pi lists an extension command under its invocation name. When two extensions register the same
name, the names become `mcp-adapter:1`, `mcp-adapter:2` (runner.js resolveRegisteredCommands;
observed live). Before `bindCore`, both `getAllTools` and `getCommands` throw.
