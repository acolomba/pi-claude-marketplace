<objective>
Make a stdio server whose `command` or `args` start with a home marker follow the house partial-install pattern, because no encoding keeps such a value literal through pi-mcp-adapter.

Purpose: AVAR-03 as amended by D-04-06 and D-04-15. The adapter runs `expandHomePath` after interpolation on `command` and every `args` element, so a split token cannot protect a leading `~` (04-CONTEXT `<compat_evidence>`, probe `{env:E}~/x` gives `<home>/x`). Claude Code passes `~/x` through literally. Instead of writing a value the adapter would change, the resolver blocks the server with the existing `{unsupported mcp}` aggregate reason: a normal install refuses with the `--partial` hint, `--partial` leaves the server out, and `info` names the server, the field and the token. The check is static and conservative (D-04-15); the resolver never reads the environment.

Output: two new `McpUnsupportedFeature` members wired into `classifyMcpServer`, the matching resolver-type literals, classifier, resolver, info and end-to-end tests, the catalog prose, one commit.
</objective>
