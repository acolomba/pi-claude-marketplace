- remote field (url, headers): denied when `remoteSink.has(Ue) || ZEe(Ue) || eRe(Ue, value)`; a denied reference is always `""` (a `:-` default is ignored); it is listed as blanked, and warned about, only when it was set.
- plain field (command, args, env): denied when `plain.has(Ue)` (the live NDe env keys collapse into the `NDe` name pattern); denied and set gives `""` (listed, no warning); denied and unset gives the default, or the literal `${NAME}` plus missing.
- not denied: set gives the value (we keep `${NAME}`); unset with a default gives the default; unset without one stays literal and is missing (we keep `${NAME}` for the adapter).
