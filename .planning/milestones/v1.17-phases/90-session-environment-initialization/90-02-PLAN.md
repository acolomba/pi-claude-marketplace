<objective>
Close gap G-90-3 (the sole Phase 90 UAT gap): a plugin shipping a `bin/` directory must install by default (Claude Code 2.1.212 parity — its `bin/` is already honored at runtime by the PENV-01 PATH ledger shipped in 90-01), and an install-failure reason token must name the actual axis of the problem instead of mislabeling a component-kind drop as `{unsupported source}`.

Two coupled halves (from the UAT diagnosis + `.planning/debug/bin-unsupported-classification.md`):

1. **Stale classification (D-90-06).** `domain/resolver.ts` still lists `bin` in `UNSUPPORTED_COMPONENT_KINDS` with a `bin/`-dir convention probe, so a bin-shipping plugin resolves `partially-available` and the default install gate blocks it with the `--partial` hint. Since PENV-01 the runtime appends `<resolvedSource>/bin` for every enabled installed record, so "unsupported" no longer reflects reality. Reclassify `bin` OUT of the unsupported set (mirroring the HOOK-01 precedent that moved `hooks`) so the plugin resolves `installable`. `bin/` needs no staging — its PATH injection is derived from install state, not from a materialized artifact.

2. **Reason-token collapse (D-90-05).** `shared/probe-classifiers.ts::kindToReason` maps only `lspServers -> lsp` and `hooks -> unsupported hooks`; every OTHER kind (`monitors`, `themes`, `outputStyles`, `channels`, `userConfig`, `settings`) collapses to the generic `unsupported source` token, mislabeling a component-kind drop as a source problem. Add a single closed-set REASONS member `unsupported component` and retarget the per-kind fallback to it. The read-only surfaces (`list`/`info`) and the install-failure surface all source per-kind markers through the same `narrowUnsupportedKinds` seam, so one change to `kindToReason` fixes all three byte-identically (SURF-01).

Purpose: brings the resolver's component-support classification and its user-facing reason vocabulary into truthful agreement with the PENV-01 runtime behavior already shipped.
Output: resolver reclassification + a new `unsupported component` reason token with every render/test/catalog/PRD surface reconciled in lockstep.
</objective>
