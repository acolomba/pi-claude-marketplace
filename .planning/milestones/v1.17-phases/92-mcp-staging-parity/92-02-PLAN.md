<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin-declared env → stdio spawn env | Injected CLAUDE_* defaults and plugin-declared env keys merge into the entry's `env` written to `mcp.json`; declared keys win. |
| re-stage source servers → mcp.json | update/reinstall re-run substitution on freshly-resolved roots; a stale prior-root path must not survive. |
| scope arm → CLAUDE_PROJECT_DIR | Project scope bakes cwd; user scope must not leak a project path (documented absence). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-92-05 | Tampering | injection targeting (url-type) | medium | mitigate | Injection is gated on `typeof entry.command === "string"`; url/http/sse entries never gain a synthesized env — asserted in Task 1. |
| T-92-06 | Information Disclosure | user-scope CLAUDE_PROJECT_DIR | medium | mitigate | User scope omits the `CLAUDE_PROJECT_DIR` map key entirely; the token passes through and no env key is injected — asserted in Task 2, preventing a wrong/leaked project path in a user-scope config. |
| T-92-07 | Tampering | stale-path re-derivation | high | mitigate | Re-stage substitutes the resolver's SOURCE servers (placeholders intact), never a read-back of mcp.json; ours entries are dropped and replaced — asserted by the no-stale-substring test in Task 3. |
| T-92-08 | Tampering | theirs isolation on re-stage | high | mitigate | The `theirs` partition is merged verbatim; substitution/injection never reach foreign entries — asserted deep-equal in Task 3. |
| T-92-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs in scope — test-only plan against Plan 01's engine (pure in-repo TypeScript). No Package Legitimacy Gate applies. |
