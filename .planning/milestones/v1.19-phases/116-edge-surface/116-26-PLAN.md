the one branch that cannot be reached from outside the module.

Purpose: `edge/handlers/shared.ts` is one of the three modules that hold the only real logic in the
edge tier (D-116-07). Its single export, `extractLocalFlag`, is imported by seven handlers, and
D-116-05 applied one layer down says the proof lives here rather than being restated nineteen times.
It sits at 12/14 branches and 78/85 lines: `shared.ts:71-75` is the pass-through branch, reachable
by supplying a pass-through list, and `shared.ts:53-55` is the `if (tok === undefined) break;` guard,
which cannot be entered because the token list is a dense array the loop only indexes in range.

Wave 3 exists so the three helper contracts are settled before any handler owner writes a delegation
assertion against them. Run this plan first within the wave: the other two helpers reach the same
usage-error channel and reuse the boundary sizing this plan establishes.

`shared.ts:53-55` cannot be entered at runtime — it exists only because `noUncheckedIndexedAccess`
(`tsconfig.json:12`) types every index read as possibly undefined, and removing it needs a non-null
assertion or a type assertion, both barred throughout `extensions/`. This pair therefore lands at
**functions complete, uncovered lines exactly `54-55`, and exactly one uncovered branch** under
D-116-01a. The absolute branch and line numbers are not pinned here: V8 collapses a branch range
whose count does not diverge from its parent, so the denominator tracks suite strength, and this
pair's post-rewrite numbers have never been measured. The executor measures them and records them in
the summary as an observation.

Output: one exhaustive owner for `edge/handlers/shared.ts`, and a documented, argued shortfall. No
production change.

- No flags: `local` is `false` and the residual is the input tokens rejoined with single spaces.
- Scope-target flag present: `local` is `true` and the token is **removed** from the residual. Drive
  it leading, trailing, and between positionals through a row table; every row asserts the identical
  whole value, which is the position-independence proof.
- Two scope-target tokens: both are removed and `local` is still `true`.
- A `--scope` pair is consumed by the scanner but **survives in the residual**, because the
  downstream parser consumes it: assert the residual still carries both tokens.
- The scanner does not validate the `--scope` value: an unrecognised value still returns a result
  rather than `undefined`, and emits nothing. This is where the responsibility split lives — the
  value is rejected one layer down, and this owner proves the scanner passes it through.
- `--scope` immediately followed by the scope-target flag: the pair consumption treats the next token
  as the value, so `local` stays `false` while the residual filter still drops the token. Assert the
  whole value; this is a genuine and easily-lost behavior.

  set `local`. Drive the list from `passThroughFlagNames` for the verb that uses it, so a catalog
