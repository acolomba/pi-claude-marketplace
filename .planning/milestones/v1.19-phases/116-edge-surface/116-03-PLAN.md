Rewrite `tests/edge/completions/data.test.ts` in the G6 shape: one top-level `describe()` per
exported entrypoint, no nesting. Use `tests/shared/completion-cache.test.ts` for the grouping shape
over a large data surface and `tests/orchestrators/edge-deps.test.ts` for the hermetic scope.

**Harness.** Copy the hermetic scope: two `mkdtemp` roots per case, the home and agent-directory
environment variables saved with an own-property check and restored in a `t.after()` registered
**before** the act with the agent-directory variable deleted rather than overwritten, and a
context-owned replacement of the global network entry point that throws on any call and exposes its
call count. No `finally` block. Assert the call count is zero in every case; never match an error
message.

**The resolver double.** The module declares its own resolver interface as an injected parameter, so
build a typed fake per case — a plain object checked with `satisfies` against the imported interface,
with arrow properties rather than methods so destructuring does not trip the unbound-method rule.
Give it seeded state and manifest data per case. Where a case is about a failure propagating, have
the fake throw the exact error class the module discriminates on, taken from the cache module rather
than restated. Do not hand-roll a mock graph that simulates the filesystem; do not use a strict
interaction mock where the module's result is the promise.

Cover, one `describe()` per export, each with whole-value assertions against hand-authored literals:

- `buildItem`: the returned label and value for an empty already-typed prefix, a non-empty one, with
  and without the trailing space. Four rows. The value is the whole replacement text, so assert the
  complete string.
- `splitCompletionInput`: empty input, one partial token, finished tokens plus a partial, finished
  tokens plus a trailing space yielding an empty partial, and repeated interior spaces.
- `extractPositionals`: a token list with and without the flag pair, and with the flag pair in
  several positions, all yielding the same positional list.
- `extractScope`: each accepted value, an absent flag, and a flag with an unrecognised value. Take
  the accepted scope values from the shared scope declaration rather than a hand-written pair
  literal, because `tests/architecture/scope-order-drift.test.ts` forbids a hand-rolled scope-order
  literal.
- `getMarketplaceCompletions` and `getMarketplaceNamesAcrossScopes`: names visible in one scope only,
  in both scopes (deduplicated), in neither, and the ordering of the union. Prove the deduplication
  with the same name seeded in both scopes. Prove that a read failure in **either** scope propagates
  rather than yielding a partial list — seed the failure in the first scope in one case and the
  second in another, so a short-circuit is visible.
- `getPluginToMarketplacesMap`: one case per completion mode, each seeding candidates whose status
  makes them eligible for that mode and at least one whose status does not, so the returned map
  discriminates. Then the partial option, proven to narrow the install and update sets and to leave
  every other mode's set unchanged. Then the target-scope option and its default.
- `getPluginRefCompletions`: the plugin half with a plugin unique to one marketplace, yielding a
  fully-qualified value with a trailing space; the plugin half with a plugin in two marketplaces,
  yielding a separator-terminated value **without** a trailing space; the marketplace half for a
  named plugin; the bare marketplace form both when the mode allows it and when it does not, the
  second yielding an empty list.

**Ordering and stability.** Compare every candidate list as one whole array in the order the module
produced it. Do not sort before comparing and do not compare as a set. Add one case where two
candidates compare equal on the field the module orders by, and assert they come back in their
declaration order — that is the stability proof.

**Comparison form.** State in a case title that candidate matching is a case-sensitive prefix
comparison with no case folding and no Unicode normalization, and prove it: a partial token that
differs from a seeded candidate only in letter case must **not** match, while the exact-case partial
does.
