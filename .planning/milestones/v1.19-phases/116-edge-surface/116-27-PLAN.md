<objective>
Rewrite the owner for the read-only tool surface, and discharge the phase's entire exhaustiveness
obligation, which is locked to this plan alone.

Purpose: `edge/handlers/tools.ts` is 518 lines with four exports and sits at 86/106 branches and
503/518 lines. It is also the only module in the tier with switches over a **closed union**. The
preceding phase proved with a compiler repro that a switch is exhaustiveness-checked only when its
return type excludes undefined; four gates elsewhere in the codebase had been deleted against a
guarantee TypeScript never made.

Three of this module's four switches return a non-nullable value and therefore do carry the
guarantee. The fourth — the version reader — returns a union that includes undefined, so a deleted
arm compiles clean. That is the same class of hole D-116-14 was written about, one function away
from three sound ones, and it is this plan's job to prove all four cases empirically rather than
assume them.

A compiler repro run during planning corrects the premise for the fourth switch. `noImplicitReturns`
(`tsconfig.json:11`) makes the end of a `default`-less switch reachable once an arm is deleted, so a
missing arm there raises **TS7030**, not nothing. All four switches are gated; only the diagnostic
differs.

That also rules out deleting the version reader's unreachable arms: deletion raises TS7030, and both
shapes that compile — a trailing `return`, or a `default` — trade the uncovered branch for an
uncovered line, with the `default` shape additionally silencing the gate. The ratified answer is to
change the **type** instead. `pluginVersion` takes the full plugin message union, but the payload it
is fed already carries a narrower list-surface row union; giving the parameter that type leaves the
pending arms nothing to match, so they come out on their own and the switch stays exhaustive over
what remains.

This is the sole plan in the phase permitted to change a file under `extensions/`.

Output: one exhaustive, hermetic, offline-proven owner, four recorded plants, a narrowed parameter
type, and 100 percent direct coverage.
</objective>
