<objective>
Make the import barrel a real production surface and give it its first owner.

Purpose: `orchestrators/import/index.ts` has zero production importers today. Production
reaches `importClaudeSettings` straight from `execute.ts`, and the only file in the repository
importing the barrel is another pair's owner test. A dead-code probe reports the barrel as an
unused file and, because an unreachable file stops having its individual exports evaluated,
reports all eight of its suppressions as stale at the same time. Pruning alone does not fix
that — a one-line unreachable barrel is still unreachable. D-115-01 resolves it by giving the
barrel a genuine production consumer and deleting every suppression, which is the only outcome
that stays clean under both the current fallow setting and the production-only run the operator
intends to enable later.

Output: a pruned, reachable barrel; a one-line handler repoint; and a new owner test whose
type-level export-set proof makes re-adding a pruned symbol a compile error.
</objective>
