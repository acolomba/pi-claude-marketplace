installed here, so a clean `git commit` is not evidence hooks passed. Never `--all-files`, never

Order matters for the rename gate: it reads the STAGED diff, so stage this task's literal paths FIRST, then run the verify block, then commit. Running it before staging reports no rename and the gate fails for the wrong reason.
