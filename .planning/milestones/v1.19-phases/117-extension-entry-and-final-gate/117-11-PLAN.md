<objective>
Turn the all-pair run from a terminal scrollback into a retained, self-checking result — and measure
it honestly.

Purpose: COV-05 asks for one complete direct coverage record for each of the 204 inventory rows, and
says aggregate coverage is not a substitute. Today the run holds neither half of that. It writes one
verdict line per pair to standard output and deletes the per-pair coverage file in a finally block, so
there is no result to inspect; and it never asserts that it visited every row, so a mapping that
silently skipped one would pass.

Three measured facts shape what this plan can honestly claim. Seven of the 204 modules emit no
JavaScript at all and take an escape that passes them unconditionally with no coverage record — there
is nothing to be complete about, so D-117-20 reads COV-05 as 197 numeric records plus 7 named
exceptions. No Node 24 exists on this machine, so D-117-19 says label the runtime beside the number
and let CI, which pins 24, carry the criterion's wording. And merging two suites' coverage on the
entry pair was measured to HIDE an uncovered branch, which is why the headline claim comes from the
per-pair runs and never from the merged report.

It runs after every move because it measures the final tree; a run against a half-moved tree measures
a tree that will not exist.

Output: a self-checking all-pair run, a retained result naming all 204 rows, and three decisions on
the record — the COV-05 reading, the runtime label, and concurrency.
</objective>
