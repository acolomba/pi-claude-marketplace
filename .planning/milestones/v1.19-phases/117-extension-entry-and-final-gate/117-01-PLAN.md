both scripts those are exactly the glob arguments handed to the runner and nothing else in either

extracted pattern with `globSync` from `node:fs`, union the results, normalise separators to posix,
and sort.

walk `tests/` with a recursive `readdirSync` carrying file types, keep entries whose name ends in the
test-file suffix, drop the two roots that have their own npm scripts (`e2e` and `integration`),

scripts under `scripts/` already use, and it is deliberately not a glob.

Assert the two arrays are equal as one whole value with a deep strict comparison, once per script. Do
not assert a count — a count is satisfied by two sets of the same size with different membership.

blank-line separated. The suite registers independent top-level cases with no shared mutable state, no
marker that suppresses a case, and no wildcard matcher. It reads the filesystem only: it starts no
process, opens no socket and writes nothing.
