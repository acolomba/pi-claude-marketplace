## Scope and pattern authority

Phase 113 owns the directly callable helpers, classifiers, planners, probes, type
contracts, and command-specific presenter contexts consumed by Phases 114 and 115. The
paired source is the behavior authority. Existing tests and supplemental suites are only
behavior inventories until their assertions are placed in the mirrored owner.

All runtime cases need separate lowercase `// arrange`, `// act`, and `// assert`
sections. Each case must construct a complete input and an independently authored complete
expected value. A case-local factory may allocate fresh state, paths, or collaborator
controls, but it must not derive the expected result. Type-only contracts stay at module
scope with positive `satisfies` assignments and targeted negative `@ts-expect-error`
assignments.

The direct owner calls every public function or render-map arm. It does not rely on a
lifecycle caller, catalog fixture, or notification integration to execute the pair. Read-
only owners use real temporary files plus fail-fast collaborator fakes. They do not call
live git, network, credentials, subprocess, or Pi services.

## Planner checklist

- Give every plan exactly one production source-test pair; supplemental pruning is attached
  to the pair whose direct owner absorbs the assertion.
- Put prerequisites in `depends_on` according to the intra-phase dependency table, not
  numeric filename order.
- Require direct import of the paired source in every mirrored owner. The current import
  tests' `import/index.ts` barrel imports are noncompliant even when coverage is green.
- Require 100 percent direct branches, functions, and lines. For erased type-only modules,
  require the direct-coverage tool's `type-only` result plus compile-time tests.
- Do not add test-only exports, readers, resets, modes, or cache-busting imports. For an
  unreachable defensive branch, obtain live CodeGraph caller/type proof before considering
  dead-code removal.
- For message producers, test both the complete structured producer value (when the module
  owns one) and every exact rendered row owned by its context. Do not retest shared summary,
  tally, description, or trailer algorithms.
- Preserve caller/input/scope/lifecycle order when it carries behavior; alphabetize only
  inventories and presentation-only collections. Document intentionally unsorted expected
  arrays.
- Run each owner alone, direct coverage for the pair, retained supplemental tests, typecheck,
  targeted lint/format, no-skip/no-coverage-ignore scans, and the no-orchestrator-network
  architecture gate.
