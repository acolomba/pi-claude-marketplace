## Trust Boundaries
| Boundary | Description |
|---|---|
| GitOps request → local/remote repository | Ref, branch, URL, and filesystem values affect repository state. |
| auth/HTTP callbacks → remote transport | Credentials and request data cross an external boundary in production. |
| temporary repository → host filesystem | Test repositories must remain contained and cleaned. |
| fake participant → shared contract | A fake can drift while tests self-confirm. |
## STRIDE Threat Register (ASVS L1)
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-108-22-01 | Tampering | ref/checkout/force-update operations | high | mitigate | Complete shared contract plus local real repositories and exact ref assertions. |
| T-108-22-02 | Information Disclosure | auth callbacks/credentials | high | mitigate | Synthetic guarded credential fake, exact callbacks, no logging/keychain/remote fallback. |
| T-108-22-03 | Spoofing | Git HTTP transport | high | mitigate | Per-case injected request method, poisoned unplanned remotes, and no loopback/live network. |
| T-108-22-04 | Tampering | temp repository paths | high | mitigate | Explicit case-owned roots, local repository factory, containment, and recursive cleanup. |
| T-108-22-05 | Tampering | fake/production contract | high | mitigate | Same registrar plus exact one-failure force-update defect. |
| T-108-22-06 | Denial of Service | global HTTP/auth mocks | high | mitigate | Fresh responses and case-local restoration prevent leaked handles/state. |
