<objective>
Make the load print `pending`'s block (APL-03, D-05, D-06, D-18). `pending.ts` exports the
composer that builds its report, `composePendingReport({ cwd, scopes })`; `pendingReconcile`
and the load both call it. On a mismatch the load emits that block once, with the apply
trailer and no reload hint; a matching state emits nothing. The load stops reporting its
own invalid-config, layer-gap and source-mismatch rows, because the block carries them.
Its per-session warnings (`{not in manifest}`, the unreadable declarer), read failures
and routing failures keep their own `reconcile-applied-cascade` payload (D-18).

Purpose: UAT-02 aside, the load is where a user first sees that their configs and records
disagree. One composer guarantees the load and `pending` cannot drift (D-06).

Output: the shared composer, the load's block, the scenarios that now see it, and the
catalog and JSON reference.
</objective>
