<objective>
Finish `apply`'s report and its dependency step (APL-01, D-08, D-22). `shouldEmitReloadHint`
stops excluding `reconcile-applied-cascade` by kind and reads its rows' stamped
`needsReload`, as every other cascade does (RLD-02), so `apply` ends with
`/reload to pick up changes` exactly when it changed something. The `reason` option that
let only a `/reload` event install missing dependencies (D-09-13) retires: `apply` always
runs the MISS-01 dependency install, and the MCP move treats a planned dependency
install like any planned install.

Purpose: the kind exclusion existed because the reconcile ran on `/reload` and a reload
hint after it would have been false (RECON-04). `apply` is a command; the running session
has not loaded what it changed. The reason gate kept startup loads offline; the load no
longer installs anything (plan 29-02), so the gate has no job.

Output: the summary rule, the retired option, the catalog's reconcile section with the
trailer, and the apply scenarios that now read `needs reload | true`.
</objective>
