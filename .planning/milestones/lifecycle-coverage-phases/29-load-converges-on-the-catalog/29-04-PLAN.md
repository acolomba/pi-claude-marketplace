<objective>
Make `apply` report an empty pass and give both empty advisories their final wording
(D-08, D-14, D-16). `ReconcilePendingEmptyMessage` gains a required `command` member,
`"pending"` or `"apply"`; the grammar renders `Pending: /claude:plugin apply has nothing to
change.` or `Apply: nothing to change.`. `apply.ts`, whose only production caller is now
the `apply` verb (plan 29-02 moved the load out), emits the advisory where it used to
return silently.

Purpose: APL-01 criterion 1 says "apply with nothing pending reports so and writes
nothing". Today an empty apply emits nothing, and in JSON mode the command run then
answers `Command returned without an outcome.`. Reusing the `reconcile-pending-empty`
kind keeps one meaning on the wire ("no pending reconcile change") and needs no new kind.

Output: the discriminated message, both texts, the apply producer, a `/claude:plugin
apply` catalog section with its empty state, the JSON reference, and one apply scenario.
</objective>
