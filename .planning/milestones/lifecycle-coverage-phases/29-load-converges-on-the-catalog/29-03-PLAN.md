<objective>
Make `pending` advise `/claude:plugin apply` (APL-04, D-05, D-14). A pending list that
holds at least one change `apply` would make ends with the trailer block
`/claude:plugin apply to make these changes`, the apply counterpart of the existing
`/reload to pick up changes`, and its JSON cascade payload carries `needsApply: true`.

Purpose: `pending` used to describe "the next reload"; after this phase the next reload
changes nothing, so `pending` must name the command that does. The trailer is a
composed, fixed literal (no identifier interpolation), placed by the grammar from an
envelope fact, exactly like the reload trailer. Plan 29-08 reuses the same block at load.

Output: the envelope fact through types, resolve, grammar, JSON and the wire schema; the
pending producer that sets it; the pending catalog states and the JSON reference; the
pending scenarios that state the new field.
</objective>
