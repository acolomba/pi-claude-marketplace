| Boundary | Description |

| cucumber worker -> lock holder child | A per-scenario child process that holds a file lock under a sandbox scope root |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-15 | Denial of service | state-lock-holder child (a lock or process that outlives the scenario) | high | mitigate | The Given registers the release before asserting; the release ends stdin, requires exit code 0 within a grace period, kills a hung child and fails, and asserts the lock file is gone; proper-lockfile also releases on process exit; the planted check proves a stuck release fails the scenario |
| T-01-16 | Tampering | lock holder and obstruction paths (a lock or a directory under the real `~/.pi/agent`) | high | mitigate | Both paths are built from `this.scopeRoot(scope)`, which resolves only to the sandbox agent dir or the sandbox project; Pi and the helper never see the real HOME |
