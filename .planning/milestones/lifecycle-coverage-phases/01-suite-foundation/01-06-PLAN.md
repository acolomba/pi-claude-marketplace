<objective>
Generalize the loopback git host from one owner and arms that last until reset to any owner and arms
a scenario can lift, then serve the official marketplace from it. The arming steps take a repository
through a `{git repository}` parameter type named by the marketplace it serves (the plugin form comes
with the git plugin repositories in 01-10); every arm is released by the world; a new step lifts an
arm mid-scenario. Generalize `Given the user has run` to multi-payload setup, which bootstrap needs.
Seeds: a marketplace add retried after a 404 (Phase 15's `failed-add.feature`) and a second bootstrap
(Phase 14's `bootstrap.feature`).

Purpose: retry scenarios need a host that can stop failing (INS-06, FLR-03); bootstrap and import need
the official marketplace (BOO-01, IMP-01).
Output: owner-aware host with `disarm`, the parameter type, rewritten git host steps, the official
marketplace fixture and step, the generalized setup step, two seeds, and the skill text.
</objective>

|----------|-------------|
