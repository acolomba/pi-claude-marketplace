# Quick Task 260909-h38

Make three cross-process concurrency tests deterministic with a FIFO state.json barrier.

## Problem

Three tests spawn a second process and then assert one particular winner of a real
filesystem race. They pass locally and lose the race on loaded GitHub runners.

1. `tests/orchestrators/plugin/uninstall.test.ts` -- "WR-06 uninstall orchestrated mode --
   marketplace removed after resolution converges without mutation"
2. `tests/orchestrators/plugin/reinstall.test.ts` -- "a marketplace removed between scope
   resolution and enumeration reports not added"
3. `tests/integration/load-reconcile-race.test.ts` -- RECON-06 two-process race

(1) and (2) arm an `fs.watch` monitor on the extension root, wait for a
`state.json.<hash>` temp file (a `write-file-atomic` internal), and then swap the
on-disk state. Nothing orders that swap against the orchestrator's NEXT read, so the
assertion depends on winning an unsynchronised race. (2) additionally steals the temp
file mid-write to force the IL-3 migration-save `console.warn`, which is a race against
`write-file-atomic`'s own rename.

(3) asserts that after two concurrent `applyReconcile` children, state.json holds exactly
one marketplace record and one plugin record. The apply pass runs with NO outer lock
(CR-01) and every step soft-fails into a structured row, so "at least one racer converges"
is not a guarantee the production design makes. Observed on CI as an ENOENT on state.json.

## Approach

Replace the temp-file-theft monitors with a FIFO-backed `state.json`. A POSIX FIFO makes
the ordering an OS-enforced happens-before instead of a timing bet: `readFile` on a FIFO
blocks until a writer opens and closes, and each open pairs exactly one reader with one
writer. The server process serves payload[0] to the resolution read and payload[1] to the
locked re-read, so the second read provably observes the removed marketplace.

For RECON-06, stop asserting an invariant the design does not provide; assert the
invariants it does (no corruption, no orphan staging, no boundary throws) and add an
uncontended follow-up reconcile that must converge.
