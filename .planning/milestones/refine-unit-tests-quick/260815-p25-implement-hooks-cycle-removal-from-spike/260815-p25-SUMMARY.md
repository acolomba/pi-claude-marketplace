# Quick Task 260815-p25: Hooks Cycle Removal Summary

Extracted the hooks bridge's shared module state into a new
`bridges/hooks/routing-state.ts` leaf, took the 8-cycle `bridges/hooks/` knot
to 0, and widened `npm run fallow` to `--circular-deps --re-export-cycles` in
the same commit so a green local `npm run check` now implies a green
pull-request gate.

## What Shipped

**Task 1 -- the leaf module.** `routing-state.ts` holds `RoutingEntry`,
`CacheEntry`, `PendingSessionStartContext`, the `parsedConfigCache` and
`routingTable` Maps, the private `liveEpoch` and `pendingSessionStartContext`
cells, and seven accessors. The Maps are `const` and cross the module boundary
untouched; the two reassigned cells stay private behind `bumpEpoch`,
`resetEpoch`, `appendPendingSessionStartContext`,
`pendingSessionStartContextEntries` and `clearPendingSessionStartContext`,
because ESM imported bindings are read-only.

The spike's copy was adapted rather than pasted: its experiment-provenance
header was replaced with a header stating the module's purpose and the
invariant that keeps the cycle gone (imports only `domain/`, `shared/`, and
same-zone `if-field/`), and the per-field documentation the candidate diff was
about to delete from `event-router.ts` was carried across onto the same
declarations, preserving the D-60-01, D-60-04, MATCH-03 and D-61-02 anchors.

**Task 2 -- the diff and the orphaned comments.** The spike's
`full-candidate.diff` applied cleanly (7 files, +39/-97). Eight stranded block
comments were then removed from `event-router.ts` -- the six the plan named
plus two section banners the plan did not enumerate (see Deviations). The
`event-router.ts` file header was corrected: it claimed to own three pieces of
module state that had just moved.

**Task 3 -- docs.** `ARCHITECTURE.md`'s "Circular imports" bullet no longer
describes the knot as present, names `routing-state.ts` in the `bridges/`
Contains line, and records the ESLint-glob question as an explicit follow-up.
`BACKLOG.md` marks FLOW-02 CLOSED with a dated one-line resolution and files
FLOW-03 for the glob-widening question.

## Deviations from Plan

**1. [Rule 3 - Blocking] The candidate diff broke `import-x/order` in all five importers.**

- **Found during:** Task 2, first `npm run check` run.
- **Issue:** The diff swaps module specifiers in place. `routing-state` sorts
  later than the neighbours `event-router` sorted before, so ESLint failed with
  5 `import-x/order` errors (in `async-rewake/registry.ts`, `dispatch-exec.ts`,
  `dispatch.ts`, `event-adapters.ts`, `settle.ts`). The spike's recorded
  "npm run check green" did not reproduce.
- **Fix:** `npx eslint --fix` on exactly those five files. Purely mechanical --
  each import line moved to its alphabetical slot; no symbol or specifier
  changed. Still +1/-1 per file.
- **Commit:** cee12150

**2. [Rule 1 - Stale doc] Two section banners beyond the plan's list of six were stranded.**

- **Found during:** Task 2.
- **Issue:** The plan enumerated six orphaned comment blocks. Deleting them
  left the `// Types` banner with no type declaration beneath it (the only
  remaining interface, `HydratedScope`, sits 380 lines away under its own
  context) and the `// Routing-table reader (consumed by dispatch.ts)` banner
  with nothing beneath it at all.
- **Fix:** Deleted both. The plan's done criterion -- "no block comment whose
  subject was moved out" -- covers them. The banner above
  `beforeAgentStartHandlerFor` was left alone as the plan directed.
- **Commit:** cee12150

**3. [Rule 1 - Stale doc] `event-router.ts`'s file header claimed ownership of the moved state.**

- **Found during:** Task 2.
- **Issue:** The header opened "Owns three pieces of module-level state" and
  then documented `liveEpoch`, `parsedConfigCache` and `routingTable` -- false
  once the cells moved. The candidate diff did not touch it.
- **Fix:** Reworded the opening clause to say the module populates and drives
  the three cells while they live in `routing-state.ts`. The three rationale
  paragraphs (D-59-02, D-59-03, DISP-02, DISP-04) were kept verbatim.
- **Commit:** cee12150

**4. [Scope] Prettier reflowed one import in `event-router.ts`.**

- **Found during:** Task 2 `format:check`.
- **Issue:** The diff removed two specifiers from the
  `domain/components/hooks.ts` import, so the remaining three fit on one line.
- **Fix:** `npx prettier --write` on that file. One line changed.
- **Commit:** cee12150

**5. [Process] The commit excludes GSD planning artifacts.**

The plan's Task 3 said "one commit carrying everything." The executing
orchestrator reserves `.planning/quick/**` (PLAN.md, SUMMARY.md) and `STATE.md`
for its own docs commit, so those are staged out of `cee12150`.
