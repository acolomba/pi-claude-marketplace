## Interface and ownership decisions

CodeGraph found two production consumers of resolveDependencyClosure: runInstallCascade and resolveEnableCascade. Enable deliberately passes an empty traversal installedKeys set so it can traverse already-installed disabled records. Installing new plugins is outside enable's behavior. Therefore the shared closure receives an optional, explicit installPolicy; the install cascade itself requires rootAllowedMarketplaces and always supplies that policy. An omitted policy is for the existing non-installing enable traversal only, not a permissive install default.

DependencyInstallPolicy has readonly allowedMarketplaces: ReadonlySet<string> and readonly recordedKeys: ReadonlySet<string>. ResolveDependencyClosureOptions gains readonly installPolicy?: DependencyInstallPolicy. WalkContext gains the parsed rootMarketplace. InstallCascadeOptions gains required readonly rootAllowedMarketplaces: ReadonlySet<string>. Existing installedKeys remains the traversal-stop set; policy.recordedKeys is the complete target-scope install inventory. The two sets have different jobs.

This separation follows D-11-02 and the published dependency document's explicit "A disabled plugin still counts as installed." Direct install still reads through and re-enables a disabled record, checking its newly missing descendants under the root policy. Reload still treats it as a wall per D-09-04. Version validation remains independent of the allowlist exemption.

The failure arm contains ok:false, reason:"cross-marketplace", key, requiredBy, marketplace, and rootMarketplace. That last field is the authority to name in the remedy, not necessarily the immediate declarer's marketplace.

Finish both tasks before committing this coupled failure-union/caller/test contract. Plan 11-05 expands the graph, installed-record, and composer cases after this plan leaves existing gates coherent. Narrow reads of the large install-flow test file to its existing direct-cascade and missing-dependency sections. Preserve all user-owned local changes.
