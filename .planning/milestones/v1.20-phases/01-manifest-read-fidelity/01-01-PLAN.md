<objective>
Give a plugin's manifest one agreed set of locations, in one agreed order, read by
every reader that looks for it.

Today two independent call sites each build `<pluginRoot>/.claude-plugin/plugin.json`
by hand, so a plugin whose manifest sits at the bare `<pluginRoot>/plugin.json` is
never opened at all — and a fallback added to one site and not the other would make
the two disagree about where a plugin's manifest is.

Purpose: MANF-01 is the read that every later requirement in this milestone stands on.
A declaration nobody can read is a declaration nobody can resolve.

Output: a new `domain/manifest-path.ts` leaf exporting the ordered candidate list, both
readers rewired to it, and one behavioral gate that plants a real bare-manifest tree on
disk and proves both readers honor it.
</objective>
