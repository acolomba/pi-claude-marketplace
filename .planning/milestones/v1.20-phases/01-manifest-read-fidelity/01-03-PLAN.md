<objective>
Make one directory on disk produce one component path, and one enumeration.

`addComponentPath` dedups by the author's raw relative-path string, so `"./skills/"` and
`"skills"` are two distinct keys and the convention probe adds the second one additively.
Reading a bare manifest is what makes those two spellings meet: without a normalized key,
the manifest-read fix turns into a net output regression on exactly the plugins it exists
to rescue.

Purpose: this is the other half of one change. The ROADMAP records MANF-01 and MANF-03 as
a single change for this reason, and names two witnesses by warning count.

Output: a canonical stored component path, and a skills bridge that recognizes when two
component paths have reached the same physical directory.

**This plan closes a regression window opened by plan 01-01.** Until it lands, the tree
carries the bare-manifest read WITHOUT the normalization that keeps it from double-counting
skill directories. No phase boundary may ship 01-01 without 01-03.

**The phase tracer lives in plan 01-01.** This is an expansion plan; its tasks build out
from the proven manifest-read slice.
</objective>
