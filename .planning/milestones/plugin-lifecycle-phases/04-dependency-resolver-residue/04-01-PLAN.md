unchanged. `previewInstall` runs the same check, so an install plan's root and fresh
dependencies refuse before a move lands too.

path from the bridge through the update swap and the install preview, and it runs
alone in wave 1 because it creates new build inputs (see Wave note).

barrel case, the split `assertUpdateNamesFree`, the `previewInstall` check, and
their owner tests. Two commits.
