<objective>
Make the update intent mark tell two marks of the same millisecond apart
(GLK-06, D-PL7-08) with a strictly increasing `updatedAt` stamp, written by
both the mark and the finalize in `update-swap.ts`.

Purpose: ST-9 compares the record's `updatedAt` a run read against the one
under the lock. Two wall-clock stamps of one millisecond are equal, so a rival
run that read the record before this run's mark can pass ST-9 and overwrite it.
Output: `nextUpdateStamp` in `update-swap.ts`, used at both write sites, plus
unit cases that fail without it and the frozen-clock stamp literals the new
rule moves.
</objective>
