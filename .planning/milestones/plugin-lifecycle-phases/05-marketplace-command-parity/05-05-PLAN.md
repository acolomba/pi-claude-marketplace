Update the module's @fileoverview to say the host also serves catalog files for hosted marketplaces.

Architecture cases in `test/architecture/https-git-host-server.test.ts` (real HTTPS requests with the host's CA, as the existing cases make): a served file answers 200 with its exact bytes and the log reads `GET /acme/tools/marketplace.json 200`; serving the path again replaces the bytes; an `arm("tools", { kind: "status", status: 404 })` on a directory that serves only files is accepted and the file then answers 404; `reset()` empties `snapshot().files` and the file no longer answers 200; a git repository on the same host still answers its `info/refs` request.
