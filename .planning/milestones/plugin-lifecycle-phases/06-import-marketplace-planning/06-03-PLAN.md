## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Tampering | unreferenced `extraKnownMarketplaces` keys such as `__proto__` or `constructor` | medium | mitigate | The new pass walks own keys only (`Object.keys`), and every downstream map write and read already goes through `setOwn` and `ownValue` (`desiredConfigFor`, the planner). |
| T-06-07 | Elevation of privilege | an unreferenced git-source entry now clones over the network | low | accept | Claude Code registers every entry (E1). NFR-5 allows network for a git-source marketplace add. The add is reported as an `(added)` row and declared in the config, so it is visible and reversible with `marketplace remove`. |
| T-06-08 | Tampering | aliasing a settings name to the wrong recorded marketplace | high | mitigate | Only the planner's one-to-one claims are followed, read from plan.ts's own `buildMarketplaceClaims` (D-PL6-10). An ambiguous or multiply claimed source is a planner mismatch, checked before any add, and blocks its plugins (D-PL6-09). |
