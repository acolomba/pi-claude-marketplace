<objective>
Teach `marketplace add` to tell its own leftover clone from a foreign tree, and prove the retry works
end to end — the defect PR #153 actually reported.

Purpose: `addGitClonedInGuard` step 4 throws `StaleSourceCloneError` whenever `sources/<name>/`
exists, with no way to distinguish a leftover clone of the SAME source from a directory the extension
never created. A crash inside the WR-07 window, or a state rebuild, therefore demands a manual
`rm -rf` before every attempt. Recognition compares the leftover's `origin` against
`canonicalCloneUrl(source)` — the identity, which is `.git`-insensitive and, after D-2-05, a fixed
point — and a recognized leftover is removed so the existing atomic rename can proceed (D-3-01,
D-3-02).

Output: a `listRemotes` wrapper in `platform/git.ts` that does its own filesystem probe and returns a
four-arm discriminated value, an eighth `GitOps` member wired through `DEFAULT_GIT_OPS`, the
`.git`-stripping leaf exported from `domain/source.ts`, `add.ts` step 4 turned into an explicit
recognize-remove-rename branch with the MA-14 leak folded into the single existing wrap, and every
arm of the new platform wrapper proven against real git fixtures on disk.
</objective>
