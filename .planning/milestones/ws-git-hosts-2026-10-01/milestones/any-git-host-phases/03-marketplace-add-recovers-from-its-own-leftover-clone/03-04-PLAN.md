<objective>
Close the one verification gap, SC2 / MA-13 (review finding CR-01). A leftover whose `.git/config`
declares an `origin` remote section with no `url` key must refuse with the MA-6 `{stale clone}` row in
both standalone and orchestrated modes. Today it crashes `marketplace add` with a raw `TypeError` in
standalone mode and is mislabelled `unparseable` in orchestrated mode.

Purpose: that shape is what the WR-07 crash window leaves behind when isomorphic-git's whole-file config
rewrite is interrupted, so it sits on the exact retry path this phase exists to make recoverable.
`platform/git.ts::listRemotes` declares its `origin` arm as carrying `url: string`, yet returns
`url: undefined` for that shape, because isomorphic-git's own `url: string` declaration does not hold at
runtime. `add.ts::recognizeLeftover` trusts the declared type and crashes inside `stripGitSuffix`. The
fix makes the declared contract true at the one module that talks to isomorphic-git (D-3-03): an
`origin` section that records no url identifies no remote and reports `no-origin`, which
`recognizeLeftover` already refuses. D-3-01's identity comparison, the `GitOps` seam, the fake and
`add.ts` are unchanged. D-3-02's remove-then-rename runs only on a recognized match, which a url-less
section can never be. D-3-04's cascade fix, executed in 03-03, is not touched.

Output: a type-checked guard and its documentation in `platform/git.ts`, and real-adapter proofs at
both tiers. The platform suite covers both truncation shapes plus the empty-url boundary; `addMarketplace`
is proven end to end in both modes. GATE-01 is then re-established by one fresh whole-gate run on the
final committed tree, because the evidence SC4 rested on is stale twice over: the `origin/main` merge at
`f301135e` changed eight source files after the verifier measured an empty diff, and this plan changes
three more.
</objective>

export interface ListRemotesOptions {
  dir: string;
}
export type ListRemotesResult =
  | { readonly kind: "origin"; readonly url: string }
  | { readonly kind: "no-origin" }
  | { readonly kind: "not-a-repo" }
  | { readonly kind: "unreadable" };

export async function listRemotes(opts: ListRemotesOptions): Promise<ListRemotesResult> {
  try {
    await fs.promises.readFile(path.join(opts.dir, ".git", "config"));
  } catch (err) {
    const code = (err as NodeJS.ErrnoException).code;
    if (code === "ENOENT" || code === "ENOTDIR") {
      return { kind: "not-a-repo" };
    }
    return { kind: "unreadable" };
  }
  const remotes = await git.listRemotes({ fs, dir: opts.dir });
  const origin = remotes.find((r) => r.remote === "origin");
  return origin === undefined ? { kind: "no-origin" } : { kind: "origin", url: origin.url };
}
