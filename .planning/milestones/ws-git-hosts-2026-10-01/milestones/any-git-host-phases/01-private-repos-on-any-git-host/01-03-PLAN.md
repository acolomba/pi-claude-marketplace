<objective>
Realign the plugin and edge-handler surfaces to the contract plan 01 established, then close the
phase's whole gate surface.

measured 31-test blast radius. Plans 01 and 02 fixed 11 of those and left the tree deliberately red
on 20 across seven files. Those 20 are not incidental breakage — each one is an assertion that the
extension does NOT consult the credential helper on an unregistered host, which is precisely the
defect this phase exists to remove. Inverting them is how GAUTH-03 gets asserted on the plugin and
handler surfaces.

Output: 20 realigned cases, one re-anchored docstring, and a green `npm run check` at the phase
boundary.
