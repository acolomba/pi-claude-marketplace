<objective>
Admit the `UserPromptExpansion` event: keep a plugin's group under it at install, report it as supported, and give every table keyed by the event set its answer.

Purpose: the bridge counts `UserPromptExpansion` as unsupported, so `claude-security`'s guard on its own command is dropped at install and the plugin needs `--partial` for it. The event set is closed and compile-forced: one new member fails the build in every table until each answers, so the admission is one commit.
Output: the event in the closed sets of the domain and the bridge, the parse of a matcher on a command name, the translator with its paired test, the route-time parse, and two scenarios that prove the admission at `info` and at install. No handler dispatches the event yet: plan 06-10 adds the `input` handler and plan 06-12 the resolver and the dispatch scenarios.
</objective>
