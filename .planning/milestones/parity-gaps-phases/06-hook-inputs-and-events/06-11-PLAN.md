<objective>
Send `effort` to the hooks of the tool events and of `Stop` and `StopFailure` when Pi's thinking level is one of Claude Code's effort levels.

Purpose: Claude Code gives a hook the session's effort level on the events that run with a tool-use context. Pi has thinking levels, which the bridge already maps for `${CLAUDE_EFFORT}` in skill and command bodies, but a hook receives none.
Output: the level rule in the domain, the level on the translation context, the field in five translators, a scripted model that can reason for the scenarios that need a level, and the scenarios for a level inside and outside Claude's set.
</objective>
