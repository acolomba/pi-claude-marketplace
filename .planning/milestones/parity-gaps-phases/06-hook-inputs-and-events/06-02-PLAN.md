<objective>
Send `tool_use_id` to the hooks of the three tool events, so a hook can tie the `PreToolUse` run of a call to its result run.

Purpose: `security-guidance` and `code-modernization` read `tool_use_id`, the first as a sentinel that shows its reminder once per call. The bridge sends no id today. This is the phase's tracer: one field travels from Pi's event through the translator to a hook's stdin and into a scenario, with the placeholder that every later field of this phase reuses.
Output: the field in the three tool translators, an id for each pair of a multi-pair edit, the `{tool use <n>}` token in a library both whole-payload steps call, one new scenario, and the `tool use id` column in every table that holds a tool event.
</objective>
