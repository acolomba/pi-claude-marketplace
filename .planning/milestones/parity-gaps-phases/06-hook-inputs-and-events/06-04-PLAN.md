<objective>
Send `duration_ms` to the hooks that run after a tool call: how long the tool ran, without the time of the `PreToolUse` hooks.

Purpose: Claude Code sends the execution time on `PostToolUse` and `PostToolUseFailure`. Pi measures it, but tells extensions only after their `tool_result` handlers ran, so the bridge times the call itself.
Output: per-call marks in the hooks runtime, the mark and the read in the two tool handlers, a small module that carries dispatch facts on the event the hooks read, the field in the two result translators, the `{milliseconds}` token, and the `duration ms` column in every table that holds a result row.
</objective>
