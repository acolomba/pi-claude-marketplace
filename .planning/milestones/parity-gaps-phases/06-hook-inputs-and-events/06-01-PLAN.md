<assumption_delta_decision>
- **Scan:** `detected: true` on three surface cues in the roadmap section: "also" (`UserPromptSubmit` also gets `session_title`), "second" (a second call has another `tool_use_id`), and "custom_instructions". None of the three makes a singular noun plural.
- **Genuine split found on re-reading the scope:** the session id. Until now one session id served every use: the stdin `session_id`, the hook's `CLAUDE_CODE_SESSION_ID`, the `CLAUDE_ENV_FILE` name, the journal owner of a child, and the identity guard. D-PG6-01 makes the id a hook reads in a pi-subagents child the root main session's, and D-PG6-03 keeps every internal key on the child's own id. So there are now two: the hook-facing session and the own session.
- **Noun that is now primary:** the hook-facing session (`sessionId` and `transcriptPath` of the translation context), which every translator and the hook environment read.
- **Decision:** add alongside. `sessionId` and `transcriptPath` keep their names and stay the fields the translators read; in a child whose identity is known they hold the root's values. A new `ownSessionId` is added beside them for the internal keys, on the context type that only the dispatch layer reads. Nothing is promoted or renamed, so no translator changes for decision 26 except the two result-event identity guards.
- **Rationale:** renaming `sessionId` would touch ten translators and their tests for no change in what they send, and a single id would merge the state of two children of one parent (06-RESEARCH.md, "Anti-Patterns to Avoid").
- **Invariant test (accepted):** the owner cases of plan 06-09 that two children of one parent get different `CLAUDE_ENV_FILE` names and different journal owners while their hooks read one `session_id`, and the type split that keeps `ownSessionId` off the type a translator receives. A later change that keys internal state on the hook-facing id turns those cases red.
- **Not a split:** `tool_use_id` for the pairs of one edit (plan 06-02) is one id per pair by D-PG6-05, a suffix on the call's id, not a second id space.
