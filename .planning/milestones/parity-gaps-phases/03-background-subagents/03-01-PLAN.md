## Trust Boundaries

| Boundary | Description |
|---|---|
| Session/runtime to shared filesystem | Child ownership must not grant authority over the parent table or sibling journals. |
| Stored PID metadata to OS signals | Files may be malformed, stale, replaced or describe reused PIDs. |
| Project contents to hook execution | Child classification retains Pi's project trust decision. |
| Companion structured options to identity | Only the generated prefix has authority; body/task/display text does not. |
| Session runtime to hook stdin | A snapshot belongs to one current Pi session and one runtime. |
| Metadata diagnostics to logs | Failure must not expose prompt or credential contents. |
