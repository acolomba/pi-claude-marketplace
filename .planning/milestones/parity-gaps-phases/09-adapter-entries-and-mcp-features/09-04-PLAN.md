Keep four more fields that a user writes on a plugin server's adapter entry across an update
and a reinstall, and show in a scenario that a user's `lifecycle` and `openUi` beat the
defaults of plan 09-03.

cases; this plan adds the scenario that D-PG9-11 asks for.

Output: the widened carried set with its owner cases, one generic Given for a user's own
fields, and three `@adapter-only` scenarios in the lifecycle feature.
