## Trust Boundaries

| Boundary | Description | Data crossing |
| --- | --- | --- |
| Plugin Stop hook to the run loop | A hook's output decides whether Pi calls the model again in the same run | Block reasons, context, `continue` |
| Plugin hook text to the model | Stop feedback and the saved-output wrapper reach the model as hidden messages | Feedback parts, `<persisted-output>` wrapper and preview |
| The bridge and other extensions at `agent_before_settle` | Pi merges each handler's result, and a returned field replaces that field | `entries`, `continue` |
| Hook stderr, stop reasons and Node error text to the user's terminal | A third-party hook controls the notice text; a start error can name an absolute path | Failure, missing-script and stop notices |
| Hook stderr to a blocking decision | On `Stop` and `UserPromptSubmit`, stderr now decides whether an exit 2 blocks | Exit code, stdout, stderr |

| A plugin's background process to the user's machine | A plain `async` hook runs as long as its process runs; an old load's child can exit after a reload | Process lifetime, PID table, late exits |
| The compatibility page and suppression markers to readers and gates | A reader relies on the page; a stale marker hides the next real clone | Residual statements, `fallow-ignore` markers |

Documented residuals outside the register:

- Pre-write containment window (05-04-SUMMARY flagged assumption). The `assertPathInside` lstat walk runs before `atomicWriteText` creates the folder, and before `write-file-atomic` writes its temporary file and renames it. A link swapped in between is not caught. This is the same window as the PID-table writer and the guard's TOCTOU note (shared/path-containment.ts:98-102). The sweep has the same gap between its check (hook-output-files.ts:63) and `opendir` (64). Only a process that runs as the user can make the swap, and a hook already runs as the user.
- The background-lane file name is predictable to the hook. The id is the dispatch id, which the hook's own environment carries as `PI_CLAUDE_MARKETPLACE_REWAKE_DISPATCH` (async-rewake/registry.ts:110, 883). A planted link at the leaf is refused by the leaf lstat (test/shared/path-safety.test.ts:229-233, the final-segment case). A planted regular file or hard link is replaced by the rename, and its target is not written. No `saveHookOutput` owner case pins a leaf link; the synchronous lane draws a fresh UUID that the hook never sees.
- A plain `async` hook outside Linux: accepted as AR-05-06.
- Saved hook output under `<dataRoot>/_shared/hook-output/` and the 30-day sweep. The sweep removes only regular files named `hook-<id>-<source>.txt` whose modification time is more than 30 days old; links and sub-folders stay. An untrusted project is not swept, so its old files stay until Pi trusts the project again; it runs no hooks meanwhile, so it gets no new files. The page says each load "removes the files in the folder that are older than 30 days" and does not name the regular-file, name and trust limits (docs/hooks-compatibility.md:400). The factory load also sweeps the project-scope folder under the home directory (event-router.ts:1132-1146, with `cwd: homedir()` at index.ts:153) without a trust check, as the earlier reap there does; it removes only its own name pattern inside its own data root. The 30-day retention is pending maintainer review (D-PG5-15).
- Advisory: the missing-script notice quotes the interpreter's stderr unredacted. That stderr usually names the absolute script path, and the notice is not cut at 200 characters. T-05-08 excludes hook stderr by design, and Claude Code shows the same text. In JSON and RPC mode the text is appended as a `hook-notice` entry.
- Advisory, present before this phase: `terminalSafeHookNotice` strips VT escapes and Cc controls, but not Unicode format characters (Cf), such as the bidi overrides U+202A to U+202E and U+2066 to U+2069. A hook can change how its own notice reads, after the bridge's label prefix. T-05-06's claim about control characters holds for Cc.
- Advisory: the tag neutralization covers the preview only (T-05-16). The path line holds `dataRoot`, which for a project scope includes the project directory. A project path that spells `</persisted-output>` across folder names would reach the model as written. The user chooses the working directory, so this case is unlikely.
- Advisory: after the claim at `close` cancels the ladder, the save of an over-limit string runs with no timer (dispatch-exec.ts:481-489). A slow disk holds the event until the write ends. This is by design (05-04 decision).

No unregistered threat flags: all six SUMMARY Threat Flags sections say None. The pre-write window that 05-04-SUMMARY flags maps to T-05-12.
