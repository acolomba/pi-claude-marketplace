<objective>
Stop a missing hook script from blocking, show a `Stop` hook's failure, and show a hook's `stopReason` to the user.

Purpose: A `Stop` or `UserPromptSubmit` hook whose script file is gone exits 2, and today that blocks the stop or the prompt for ever. Claude Code 2.1.323 treats it as a non-blocking error and tells the user to reinstall. It also shows the `stopReason` of a `continue: false`, which the bridge only debug-logs.
Output: the rule in the wire protocol and in the `onFailure` predicate, the missing-script notice, the Stop notices, the three stop notices, five scenarios, and the token `{em dash}` in the hook notice steps.
</objective>
