<objective>
Give PostToolUse hooks the full Claude Code name of a shortened tool from the adapter's own
result details, stop a cut name from being taken for a proxy call, and pin in scenarios the
cells where the hooks still see the shortened name.

Purpose: PG-MCP-02, D-PG1-08, and the orchestrator's resolution 4. Plan 01-07 recovers the
full name when a hook spells it. Three things remain. First, pi-mcp-adapter 7.0.1 puts the
server key and the original tool name in the details of a successful result, so a PostToolUse
hook can always get the full name. Second, a name cut inside the server segment has no `__`
after `mcp__`, which is the shape of the adapter's namespace proxy; a tool whose input holds
a string `tool` would run no hook at all. Third, on PreToolUse and PostToolUseFailure nothing
tells the bridge the original name unless a hook spells it; D-PG1-08 asks that this be
recorded as a pi-mcp-adapter capability gap, and the project's parity rule asks that the
scenario name it.

Output: the exported join, the details candidate, the proxy rule, their unit cases, and three
`@adapter-only` scenarios.
</objective>

pi-mcp-adapter 7.0.1, the join (`types.ts`):
```ts
export function joinToolName(toolName: string, serverName: string, prefix: ToolPrefix): string {
  const p = getServerPrefix(serverName, prefix);          // "mcp" mode: `mcp__${serverName}`
  const sanitized = toolName.replace(/\./g, "_");
  if (p && sanitized.startsWith(`${p}_`) && sanitized.length > p.length + 1) return sanitized;
  return p ? `${p}_${sanitized}` : sanitized;
}
```

Why a cut-shaped name is never a proxy call (read from pi-mcp-adapter 7.0.1): the proxy tool
is named `mcp`. A namespace proxy `mcp__<namespace>` exists only for a proxy-only server
(`namespace-tools.ts`, `isMcpServerDirectlyRegistered`), and every entry this extension writes
has `directTools: "search"` or `true`. A namespace longer than 59 characters gets the marker
`_mcpns_` and a 16-digit hash (`types.ts`, `formatServerNamespace`), so its name holds `__`
and never ends with `_` and exactly 8 hexadecimal digits. One case is left: a user's own
proxy-only server whose namespace proxy name has exactly 64 characters and ends with `_` and
8 hexadecimal digits by chance. Its outer call would then run the hooks as well as the nested
call. Record that case in the code comment; do not handle it.
