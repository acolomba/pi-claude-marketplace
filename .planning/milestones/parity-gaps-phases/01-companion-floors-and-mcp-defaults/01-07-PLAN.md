<objective>
Make a hook that names a plugin MCP tool by its full Claude Code name run for the tool that
pi-mcp-adapter 7.0.1 registered under a cut name, and give every hook of the event the full
name whenever a hook of the tool events spells it.

Purpose: PG-MCP-02, D-PG1-08. A PreToolUse hook is a policy control: a plugin's guard can
deny a tool. pi-mcp-adapter 7.0.1 registers a tool whose joined name is longer than 64
characters under a cut name, and Pi's tool events carry that name. Today a matcher that
spells the full name compares unequal, so the guard silently does not run. The bridge cannot
ask Pi for the original name (Pi's tool list does not carry it), but it can cut each full
name that a hook spells and compare the result with Pi's name. That comparison is exact: the
cut name ends with a hash of the whole full name.

Output: the exported fit rule, the adapter arms of the three hook name functions, one
recovery pass in the dispatch, their unit cases, and two `@adapter-only` scenarios. Plan
01-08 adds the full name from the adapter's result details, the proxy-shape rule, and the
scenarios that name the cells that stay shortened.
</objective>
