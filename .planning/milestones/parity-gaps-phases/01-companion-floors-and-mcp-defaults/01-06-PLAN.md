<objective>
Give a plugin MCP server that declares no usable `timeout` Claude Code's idle window in the
entry this extension writes for pi-mcp-adapter, without taking a value the user wrote.

Purpose: PG-MCP-01 under the adapter (D-PG1-11 to D-PG1-13). The entry builder is the only
place that sees the plugin's value, the user's carried value, and the marker together, so the
default is applied there, last. The marker must tell a default the extension wrote from a
value the user changed, so it records the default's value, not only the field's name. The
change adds a field and a marker member to every staged entry with no declared timeout, so
many tests and three scenarios pin new text.

Output: the marker member, the default and its rules in the entry builder, their unit cases,
one scenario for the written file, and the changed expectations of every unit test,
integration test, and scenario that pins a staged adapter entry.
</objective>
