pi-subagents 0.88.1 reader, node_modules/.cache/optional-peers/node_modules/pi-subagents/src/agents/frontmatter.js:
```text
normalizes only CRLF to LF, then splits on LF
key line:        /^([\w-]+):\s*(.*)$/   (`.` matches no CR, LF, U+2028, or U+2029, so a one-line value that holds one of them makes the whole key line fail to match)
quoted value:    a value that starts and ends with the same quote character loses that pair; no escape is processed
block headers:   exactly `|` or `|-` (literal) and `>` or `>-` (folded)
block content:   every later line whose indent is greater than the key's, and every exactly-empty line; a `#` line is content inside a block
block value:     the indent of the first content line is removed from each line that starts with it; lines are joined with LF
close fence:     indexOf("\n---", 3), so only a `---` at column 0 closes the frontmatter
```
`subagent get` prints `Description: <value>` raw, with its line breaks, then `Aliases:` (the bridge always writes aliases). `subagent list` flattens a description to one line.
