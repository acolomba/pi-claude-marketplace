<objective>
Move the frontmatter repair and the helpers it needs out of the skills bridge into a shared module, and give the repair a trigger parameter.

Purpose: PG-AGENT-05 reads agent frontmatter as YAML with the leniency skill frontmatter has. That leniency is the colon repair of the skills bridge, and fallow's zones forbid the agents bridge from importing the skills bridge. The agents bridge also needs a slightly wider trigger than skills, because `tools: *` is not YAML. So the repair moves to `shared/` and takes its trigger as a parameter. This plan changes no behavior a user sees: skills pass the colon rule and stay byte-identical.
Output: extensions/pi-claude-marketplace/shared/frontmatter-repair.ts with its owner test, and the skills modules importing from it.
</objective>

- **Scan:** `detected: true` for the phase, one pluralization cue in the roadmap section ("fallback", in the sentence that rejects a fallback to the line reader). Plan 07-02 records the decision for that cue. This plan holds a second transition of the same kind: a constant became a parameter.
