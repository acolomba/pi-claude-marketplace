<objective>
Map `Agent` and `Task` grants to pi-subagents' `subagent` tool, and always keep a source `model: inherit`.

Purpose: Today the agent tool table drops `Agent` and `Task`, so an agent whose source lets it delegate cannot start a subagent, and a source `model: inherit` writes no line, so pi-subagents' `subagents.defaultModel` wins over it. Claude Code grants delegation to such an agent, treats `Task` as an alias of `Agent`, ignores the type list inside a subagent, and ranks a frontmatter `inherit` above its own default subagent model. pi-subagents 0.88.1 authorizes nested delegation for an explicit list that holds `subagent` and reads `model: inherit` as the parent session's model.
Output: two entries in `TOOL_MAP` and a changed `mapModel` in extensions/pi-claude-marketplace/bridges/agents/convert.ts with their owner cases, five scenarios, two conformance cases against pi-subagents' own code, and the compatibility and README text. The agent with no `tools` field is plan 07-05.
</objective>
