<objective>
Read a source agent's frontmatter as YAML, with the repair of plan 07-01, and report an agent whose frontmatter cannot be parsed.

Purpose: The agents bridge reads frontmatter with its own line reader. It keeps quote marks, reads a comment as part of a value, and never fails, so a quoted description, a quoted name, and `tools: Read # note` all convert wrongly. Claude Code 2.1.323 reads agent frontmatter with a YAML parser, retries once after quoting the values YAML refuses, and loads the agent with no fields when the retry fails too. This plan copies that order with Pi's own parser.
Output: `readAgentFrontmatter` in extensions/pi-claude-marketplace/bridges/agents/frontmatter.ts with its owner cases, the name rule and the discovery note in extensions/pi-claude-marketplace/bridges/agents/discover.ts, four scenarios in features/agent/frontmatter.feature, and the compatibility and catalog text.
</objective>
