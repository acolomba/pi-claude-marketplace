<objective>
Give an agent with no `tools` field nested delegation, unless its source denies `Agent` or `Task`.

Purpose: In Claude Code an agent that omits `tools` has every tool, `Agent` included, and a deny of `Agent` or `Task` takes it away. Plan 07-04 mapped an explicit grant. An agent with no list has no line to carry the grant: pi-subagents gives such a child its default and ambient tools, and adds the `subagent` tool only when the agent file says `allowNestedSubagents: true`. Writing an explicit list instead would cut the tools the agent has today.
Output: the key in `GeneratedToolsFields` and in the emitter, the rule in the converter, the changed pins of every agent with no tools list, the nested-call and guard scenarios, two conformance cases, and the compatibility text with the depth difference.
</objective>
