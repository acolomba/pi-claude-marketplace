<objective>
Keep a plugin's workflow reference as its author wrote it: bare inside a tool call, with a slash as a command.

Purpose: The reference rewriter turns every `<plugin>:<name>` token that names a staged workflow into `/<workflow>`. The token pattern accepts a quote before the token, so `Workflow({ name: "demo:scan" })` reaches the model with a slash, and the engine's `workflow` tool refuses any name that holds one. Nine call sites in the two official workflow plugins have this shape.
Output: one arm of extensions/pi-claude-marketplace/domain/skill-tokens.ts with its owner cases, features/workflow/references.feature, the harness support for a run the model starts, and the corrected paragraph of docs/workflows-compatibility.md.
</objective>
