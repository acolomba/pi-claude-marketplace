<objective>
Show, on each alias suggestion of Pi's terminal menu, the description of the alias target and its
`argument-hint`.

Purpose: PG-SKILL-11 (it covers the PRD's CMD-10) under D-PG11-09. Claude Code's `/` menu lists a
name with its description and argument hint. Today an alias suggestion is `{ value, label }` only,
so a user who types `/demo:` sees bare names. The alias table already parses each staged file's
frontmatter once for its names; the description and the hint are in the same object, so they cost
no extra read. The text is built the way pi-tui builds a native row, so an alias row reads like
Pi's own.

Output: a required menu-text member on the alias target, the description on each suggestion, two
edited menu rows that are red before the change, and two new skill menu scenarios.
</objective>
