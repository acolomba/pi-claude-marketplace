<objective>
Make a bridged command answer to the name Claude Code gives it, `/<plugin>:<path>:<file>`,
whenever that name differs from its Pi name.

Purpose: PG-CMD-09 and decision 13 of the PRD, answered by D-PG11-01 (pending maintainer
review; it amends D-141-01). The Pi name keeps the CM-2 elision, so `demo/commands/demo-lint.md`
lists as `/demo:lint`; today the upstream name `/demo:demo-lint` reaches the model as plain
text. A skill in the same case keeps its Claude Code name as an alias, and the asymmetry has no
recorded reason. The elision loses the file name, so the name must be stored: the stager already
holds the plugin name and the source name, and the trusted record in the staged frontmatter is
where the alias reader can find it without reading the plugin source.

Output: one new domain function, one new record member written at staging, one new alias source,
one scenario outline that is red before the change, and the README text in both languages.
</objective>
