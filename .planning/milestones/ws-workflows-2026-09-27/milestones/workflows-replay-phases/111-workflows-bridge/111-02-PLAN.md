## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin manifest -> filesystem walk | a declared `workflows` component path is an untrusted string that is resolved against the plugin root and then walked |
| third-party script bytes -> extension memory and envelope | the body of an unaudited JavaScript file is read whole and carried forward verbatim |
| directory entry -> filesystem read | an entry name reported by `readdir` decides what gets opened |
| recorded name -> unlink target | a name read back from install state composes a path that is then removed |
