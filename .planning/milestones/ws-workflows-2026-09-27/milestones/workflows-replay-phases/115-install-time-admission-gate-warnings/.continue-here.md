## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Enumeration shorter than the set it names | Has occurred **five times** in this milestone: seven engine gates were nine; five `composeReasons` translation sites were six; two `piWithBothLoaded` definitions were four; seven closed-set amendment sites were eight; the marker-coverage gate's seven-entry literal was bound to nothing. Every one was found by removing something and watching what went red — never by listing. | advisory | Before writing any count into code, a test or a document, derive it by measurement against the tree or the engine source, and say where it came from. Treat every inherited figure as unverified. |
| A guard that is green because it checks nothing | Shipped twice: an exact-length `COMPONENT_KINDS` tuple that did NOT fail to typecheck when the set grew, and its replacement forcing construct, which was unconditionally `never`. Both passed code review. A third was caught in Phase 114 — the marker-coverage gate's case list was bound to nothing, so planting an eighth site printed `pass 1 / fail 0`. | advisory | Every new gate gets a negative control RUN before it is believed, and the failing transcript goes in the SUMMARY. `115-VALIDATION.md` specifies a four-direction control for this phase's totality construct; directions 3 and 4 are the ones that catch what actually shipped. |
| Agents committing over each other in one checkout | `workflow.use_worktrees` is `false`, so every executor and auditor runs against this single checkout. Twice this session an agent's `git commit` swept in files a concurrently-running agent had just staged. Nothing was lost either time (both were verified byte-identical), but one commit message described only half its contents. | advisory | Stage explicit paths, never `git add -A`. After any commit taken while another agent is active, run `git show --stat <sha>` and confirm it contains what its message claims. Prefer running agents sequentially when they touch adjacent artifacts. |
