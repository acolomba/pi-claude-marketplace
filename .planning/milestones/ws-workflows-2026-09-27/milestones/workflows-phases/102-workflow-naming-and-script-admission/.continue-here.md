## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Non-discriminating gate pin | A test meant to pin decision ORDER pinned nothing: all eight determinism fixtures carried a valid `meta.name`, so transposing the two steps flipped them together and the suite "detected" the change while proving nothing about which case was load-bearing. | advisory | Exactly ONE fixture may give both arms a claim on the same input, and the transposition must actually be run — flip the order, confirm that one case fails and the rest stay green, restore. A pin that survives the transposition is not pinning anything. |
| Trusting a review's coverage table | The plan-checker and the code review both reported clean coverage while a real hole remained; the review's own two blockers were found only by *running* the shipped module, and the fixer then found a third instance the review missed (the description read had the identical spread bug). | advisory | Verify claims against the artifact, not the claimant. Ask a reviewer to reproduce, and re-check the sibling code path any finding implies. |
| Trufflehog in a linked worktree | The `trufflehog` pre-commit hook is a git-mode scan; in a worktree `.git` is a file, so it aborts with `failed to read index file: ... .git/index: not a directory` on every commit. | advisory | Documented in `CLAUDE.md`: run `trufflehog filesystem <explicit paths> --results=verified,unknown --fail` first, then commit with `SKIP=trufflehog` alone. Never extend `SKIP=`, never `--no-verify`. |
| `pre-commit run --files` exceeding a 2-minute timeout | The npm lint/typecheck hooks pushed a scoped hook run past the default Bash timeout and it was killed mid-flight. | advisory | Give `pre-commit run` an explicit long timeout. A killed hook run is not a passing hook run. |
