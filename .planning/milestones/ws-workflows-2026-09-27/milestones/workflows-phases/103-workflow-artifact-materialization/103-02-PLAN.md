<objective>
Make a project-scope install land at the engine's project path, and hold the derivation that
produces that path against the engine byte-for-byte.

Purpose: the project key is a private internal of a package with fifty releases since May. Nothing
in our code or the engine's would notice a drift; a user would notice only as workflows that
install successfully and never appear. Hard-coded expectations are the alarm. The containment and
adjacency assertions are the other half: this is the first root outside `<scopeRoot>`, and the
staging directory's position is the whole reason the commit rename does not fail on a
project-scope install.

Output: the fourteen-case parity suite, the relocation-seam pins, the bundle's path and refusal
section, and the project-scope end-to-end proof including the absence of the deprecated location.
</objective>
