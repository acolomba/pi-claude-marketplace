## The call table

A prompt whose script makes N tool calls and then replies makes N+1 model calls, and each call repeats the conversation so far, so the table has (N+1)² rows: call 1 holds the `user` row; call k+1 holds the `user` row, then, for each of the first k tool calls in order, an `assistant` row (`tool call <tool> <arguments>`) and a `tool result` row. The reply text never appears. One call makes 4 rows, two calls 9, three calls 16. Write the arguments in the script with no spaces (for example `{"scope":"user"}`), because the `assistant` row repeats them as the script wrote them. Align the columns.
