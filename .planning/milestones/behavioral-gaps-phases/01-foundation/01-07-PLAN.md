## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cucumber worker to one-shot and terminal Pis | Each Pi gets the allowlisted environment and runs in the sandbox; a hung Pi must not outlive its step. |
| terminal output to assertions | A wrong screen model would let a scenario pass on stale rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-17 | Information disclosure | `runJsonModeCommand` | medium | mitigate | The environment comes from `rpcChildEnvironment` (allowlist plus the run's git keys and `TMPDIR`), the sandbox from `resolveRpcSandbox`, and stdin is closed, so no shell variable or input reaches Pi. |
| T-1-18 | Denial of service | json Pi, terminal Pi | medium | mitigate | The json driver kills its process group past a named deadline; the terminal Pi registers its stop as a release when it starts (`startTuiSession`). |
| T-1-19 | Tampering | `terminalScreen` | low | mitigate | Unit cases pin each control sequence the renderer writes, and the seeds' red proofs show a broken model fails them. |
| T-1-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package; there is nothing for the package-legitimacy gate to check. |
</threat_model>
