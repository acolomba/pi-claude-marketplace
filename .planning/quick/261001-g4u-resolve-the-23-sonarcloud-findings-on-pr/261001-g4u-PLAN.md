## Deviation from the brief: the tag probe also shares an object cache

The brief asks for `Promise.all` over the tag names, with tag order kept, undefined oids dropped,
and the memo and catch kept. This plan does all of that. It also passes one isomorphic-git object
cache per listing into every peel. That touches `platform/git.ts` and its test, which the brief
did not name. Reason, measured during planning: `resolveTagOid` passes no `cache` today. So each
peel loads the WHOLE packfile into memory and checksums it. Run concurrently, those copies are all
alive at once. Measurements on a 12 MB packfile, as wall time / peak RSS. The first two rows use
the real `resolveTagOid`. The third row uses a copy of it that passes the cache. Through the
whole probe, with the planned code loaded in place of the real modules and Task 1 step 5's exact
recipe (150 tags), the result was:
- HEAD: 12.0 s / 204 MB;
- this plan: 1.2 s / 144 MB.
At HEAD, the real probe took 32.0 s / 192 MB on the 400-tag repository.

| Strategy                                  | 150 tags        | 400 tags        |
| ----------------------------------------- | --------------- | --------------- |
| sequential loop (HEAD)                    | 12.5 s / 190 MB | 32.5 s / 201 MB |
| `Promise.all`, no cache (brief as written) | 10.2 s / 859 MB | 27.4 s / 870 MB |
| `Promise.all` + one shared cache (plan)   | 1.4 s / 141 MB  | 1.9 s / 183 MB  |

The tag list is every tag in the marketplace clone, which is remote content, so the cache-less form
lets a large marketplace inflate memory (threat T-g4u-01). The shared cache keeps the user's
`Promise.all` design and removes the regression. Report this deviation in the SUMMARY.

## Pin remap procedure (type-member contracts)

`scripts/check-unused-type-members.contracts.json` and `.exceptions.json` pin declarations as
`extensions/pi-claude-marketplace/<file>.ts:<line>:<col>`. When a pinned line moves, the gate fails.
It prints `Invalid contract: <pin> names no declaration in this program` and exits 2. Run Prettier
FIRST, then save this program to your scratchpad and run it from the checkout root as
`python3 <scratchpad>/remap-pins.py .`. It maps each pinned line through a difflib match between
`HEAD` and the working file. It changes line numbers only, never columns. It aborts if a pinned
line was itself edited.

```python
import difflib, re, subprocess, sys
root = sys.argv[1]
pat = re.compile(r"(extensions/pi-claude-marketplace/[A-Za-z0-9/._-]+\.ts):(\d+):(\d+)")
cache = {}
def mapping(rel):
    if rel not in cache:
        old = subprocess.run(["git", "-C", root, "show", f"HEAD:{rel}"], capture_output=True, text=True, check=True).stdout.split("\n")
        new = open(f"{root}/{rel}", encoding="utf-8").read().split("\n")
        m = {}
        for tag, i1, i2, j1, j2 in difflib.SequenceMatcher(None, old, new, autojunk=False).get_opcodes():
            if tag == "equal":
                for k in range(i2 - i1):
                    m[i1 + k + 1] = j1 + k + 1
        cache[rel] = (m, old == new)
    return cache[rel]
moved = []
def sub(mo):
    rel, line, col = mo.group(1), int(mo.group(2)), mo.group(3)
    m, same = mapping(rel)
    if same:
        return mo.group(0)
    if line not in m:
        sys.exit(f"pinned line {rel}:{line} was itself edited -- resolve by hand")
    if m[line] != line:
        moved.append(f"{rel}:{line}:{col} -> line {m[line]}")
    return f"{rel}:{m[line]}:{col}"
for name in ("contracts", "exceptions"):
    path = f"{root}/scripts/check-unused-type-members.{name}.json"
    text = open(path, encoding="utf-8").read()
    open(path, "w", encoding="utf-8").write(pat.sub(sub, text))
print("\n".join(sorted(set(moved))))
print(len(moved), "pin references moved")
```
