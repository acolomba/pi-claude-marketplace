The upstream rules (exact semantics in RESEARCH R-2 to R-8; port them exactly):
- **Look-alike (R-2):** the full test is Claude Code's `f4e`. The strong subset is `Ge`: any character outside U+0020..U+007E, or a match of the official pattern (`an` plus the `marketplace|plugins|official` arm). An exact reserved name in any case is never a look-alike. Sentence: `Marketplace name impersonates an official Anthropic/Claude marketplace`.
- **Grandfathering (R-2):** with a declared name D and a record name R, refuse when D equals R ignoring case and D is strong, and refuse when D differs from R and D is a look-alike. With no record name (a fresh add), refuse every look-alike.
- **Claude Code's own names (R-3):** keyed by the lowercased name, an own-key lookup (use a Map, so `constructor` is never a key). Sentence: ``Marketplace name "<lowercased name>" is reserved for <description>``, with no final period. The descriptions, verbatim:
  - inline -> `--plugin-dir session plugins`
  - builtin -> `built-in plugins`
  - skills-dir -> `plugins auto-loaded from .claude/skills/`
  - synced -> `plugins synced from your claude.ai account`
  - claude-plugin-test -> `plugins loaded by claude plugin test`
  - npm -> ``plugins installed from an npm registry (`<package>@npm`); remove this marketplace and add it again under another name``
  - pip -> `plugins installed from a Python package index (reserved; not yet available)`
  - uv -> `plugins installed from a Python package index through uv (reserved; not yet available)`
  - cargo -> `plugins installed from a Rust crate registry (reserved; not yet available)`
  - github -> ``plugins installed straight from a GitHub repository (`<owner>/<repo>@github`; reserved; not yet available)``
  - gh -> `plugins installed straight from a GitHub repository (reserved; not yet available)`
- **`claudeai-` prefix (R-4):** the name is folded first: NFKC, then the invisible-character removal (U+200C..U+200F, U+202A..U+202E, U+206A..U+206F, U+FEFF), then upper-then-lower case folding, then trailing dots and spaces stripped. The folded name starts with `claudeai-` either as it is, or after every character outside `[A-Za-z0-9_-]` becomes `-` and the result is lowercased. Sentence: ``Cannot add marketplace <JSON.stringify(name)>: names starting with "claudeai-" are reserved for marketplaces hosted on claude.ai.``. The `(claude plugin marketplace add --claudeai <name>)` remedy is dropped (D-PL5-28 (c)).
- **Another spelling (R-5):** `fo(x)` = every character outside `[A-Za-z0-9_-]` becomes `-`, then lowercase. A name N spells a reserved name n when any of `fo(N)`, `fo(NFKC N)`, or `fo` of NFKC N (with the invisible characters removed, upper-then-lower folded, and trailing dots and spaces stripped) equals n.
  - The reserved spelled name is `anthropic-plugin-directory` when N spells it and N, lowercased, is not exactly that name (D-PL5-28 (a)). Otherwise it is the first reserved name n, in set order, other than `anthropic-plugin-directory` and other than N lowercased, that N spells.
  - Sentence for a directory name (`anthropic-plugin-directory`, `claude-plugin-directory`): `"<N>" is a reserved marketplace name.`
  - Sentence otherwise, when N matches `^\w[\w.@-]*$` (ASCII word characters): `"<N>" is another spelling of "<n>", a reserved marketplace name.`
  - Sentence otherwise: `This marketplace's name is another spelling of "<n>", a reserved marketplace name. It is not exactly the reserved name it appears to be.`
- **Object.prototype member (R-6):** `Object.hasOwn(Object.prototype, name)`, skipped when the scope already records `name`. Sentence: `Cannot add marketplace "<name>": Claude Code reserves this name and cannot register a marketplace under it. The name is set by "name" in the marketplace's marketplace.json; ask its maintainer to change it.`
- **Recorded name, untrusted source (R-8):** when `reservedMarketplaceNameRefusal(recordName, source)` returns sentence S, the sentence is `Marketplace "<recordName>" is registered from an untrusted source: <S> To fix it, remove the marketplace and re-add it from the official source.`
- **Load-surface look-alike (R-2, plugin-list wording):** `Claude Code refuses the marketplace name "<recordName>": it looks like one of Anthropic's own`. When recordName holds a character outside U+0020..U+007E, use `Claude Code refuses this marketplace's name: it looks like one of Anthropic's own.` instead, so no unprintable name reaches a terminal (upstream sanitizes it the same way).
- **Add order (R-9):** look-alike and own names, then the exact set (D-PL5-01), then `claudeai-`, then spelling, then object member. The categories are disjoint, except that the look-alike must come before the spelling (`claude-plugins-official.` reads as impersonation).
- **TypeScript source:** write the invisible-character class with `\u` escape sequences, never literal characters. The pre-commit bidi-control fixer strips literal ones.
