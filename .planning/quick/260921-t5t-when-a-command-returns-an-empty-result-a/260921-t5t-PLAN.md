<objective>
Suppress the redundant success-count line when a command emits an explicit empty-state cascade.

Purpose: `(no marketplaces)` already states that a bulk command found no results. Appending
`0 successes` repeats that state and reads like a completed operation count. Keep structural
cardinality as the command-level contract, but require at least one rendered result before the
default success category can produce a tally.

Output: the central tally predicate, exact direct and command-level regressions, and synchronized
output-catalog examples. Populated bulk tallies and every single-item byte form remain unchanged.
</objective>
