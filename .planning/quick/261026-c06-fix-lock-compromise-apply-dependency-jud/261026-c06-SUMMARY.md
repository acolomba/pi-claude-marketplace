# Quick task 261026-c06 summary

- `with-state-guard.ts` (d54d4182): `onCompromised` records the compromise
  instead of throwing from the timer. `withStateGuard` and
  `LockedStateTransaction.save()` check it before they write `state.json`,
  and a body that finishes on a lost lock fails at release without calling
  release again. The typed error is `StateLockCompromisedError` (scope,
  lockPath, cause). No cucumber scenario: forcing a compromise needs Pi to
  hold the lock past proper-lockfile's 2-second refresh while the harness
  removes the lock, and the git host stand-in cannot stall a request, so the
  scenario would need a new stand-in and real waits. Unit cases cover it
  through a stubbed `lockfile.lock`.

  after its install step installs a plugin, not only after MISS-01, and
  `pending` mirrors it. A plugin whose new version needs a plugin a config
  declares now moves, where it was disabled with "Install ...".
- `install-cascade.ts` (82ef8cac): only enabled records are exempt from the
  root allowlist; a disabled foreign dependency fails as
  `{cross-marketplace}`.

  the dependency as root. The extension's install plan and MISS-01 already
  match these two rules, so the second trust item needed no code change.
