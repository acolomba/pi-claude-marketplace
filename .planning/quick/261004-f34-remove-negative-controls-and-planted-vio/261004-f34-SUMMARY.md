## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Fallow failed on exports that only the deleted controls imported**

- **Found during:** Task 1, first pre-commit run (exit 1)
- **Issue:** Plan choices 2 and 3 assumed that the production dead-code run excludes `scripts/`. It does not. Package.json script entries are entry points, and production mode resolves `includeEntryExports: true`. So 14 exports became `unused-export` findings once the controls were gone:
  - `check-changed.mjs`: `changedFiles`, `planChecks`, `runChecks`, `acquireFullLock`, `appendRunLog`
  - `test-coverage-direct.mjs`: `selectBase`, `changedPaths`, `pairsForChangedPaths`, `assertCompleteCoverage`, `enforcePairs`
  - `checkCorrespondingTests`, `checkWorkflowInstallScripts`, `verdictFor`
  - `test-reporter.mjs`'s `default`
- **Fix:** Removed `export` from the 13 functions. Each still has its in-file caller, and no code changed. For the reporter, Node's `--test-reporter` loader needs the default export, so it got one reasoned marker: `// fallow-ignore-next-line unused-export -- \`node --test --test-reporter\` loads this default.` This mirrors the existing marker on `extensions/pi-claude-marketplace/index.ts:48`. I tested `dynamicallyLoaded` and an inline `framework` plugin first, and neither credits the default.
- **Consequence:** The must-have artifact line "check-changed.mjs exports [changedFiles, planChecks, …]" no longer holds. The plan's Task 1 `<verify>` probe imports `planChecks`, so it cannot be re-run as written. The equivalent probe passed against a scratch re-export copy.
- **Tension with the plan:** The D-04 must-have says "no new … suppression", and this adds one fallow-ignore marker. The alternatives were an `ignoreExports` config entry, which is also a suppression, or an artificial read, which the gate doc forbids. The user may prefer another resolution.
- **Files modified:** `scripts/{check-changed,test-coverage-direct,check-corresponding-tests,check-workflow-install-scripts,test-coverage-direct.report,test-reporter}.mjs`
- **Commit:** 9ef75d4e
