## Choices made within the decisions

1. Untested scripts (D-01). With the control rule gone, a script with no `tests/scripts/<name>.test.ts` falls through to the broad check, like a toolchain input. That covers `check-changed.mjs`, `check-corresponding-tests.mjs`, `check-workflow-install-scripts.mjs`, `test-coverage-direct{,.pin,.report}.mjs`, `test-reporter.mjs`, and `check-unused-type-members.{analysis,exceptions}.mjs`. Consequence, accepted: a commit touching only `check-unused-type-members.analysis.mjs` runs no analyzer test until `npm run check`. Not taken: widening the analyzer rule to the whole `check-unused-type-members.*` family, which would be new selector behavior.
2. Script surface stays (D-01). Every exported function in the checker scripts still has an internal caller; only the deleted controls imported them. The exports, the root-injection parameters, and the type-member gate's `--overlay` option (covered by `tests/scripts/check-unused-type-members.test.ts`) stay. Only comments that describe the deleted controls change (TXT-3 to TXT-5).
3. Orphan rule (D-02, D-04). Delete every function, constant, type, parameter, option, import, and registry entry that no remaining code uses. Leave `export` on functions that remain in use, and leave parameters that remaining callers pass (for example `presentSeams(root, …)`, `registeredProductionPaths(root)`, `unwaivedHits(token, sources)`). The production-mode dead-code run excludes `tests/` and `scripts/`, so Fallow cannot find these orphans; the inventory names them.
4. Scanner options (D-02). `allowMissing` and `ScanReport.waived` had no caller outside the deleted scanner self-test; they go with `root`. A missing target still fails, with the WR-06 message, so every kept gate keeps its behavior.
5. Kept real-tree pins (D-02). Task 1's deletions break the type-member wiring pins, the registry resolution (GGAT-01), and the stale-citation walk unless the same commit updates them.
7. Guidelines (D-04). `docs/guidelines/typescript-unit-testing-guidelines.md` keeps its four manual steps for a new structural gate but forbids committing the plant or a replaying test. The adapter-contract negative controls stay, because their tests stay.
8. Out of scope: `skills/typescript-unit-testing-review/SKILL.md` line 16 still says the selector has a "full fallback" (stale since 261004-d9z, unrelated to controls): report it, do not edit. `.planning/PROJECT.md` and `.planning/BACKLOG.md` history entries about negative controls, `.planning/codebase/*.md`, CHANGELOG.md, and the version stay unchanged.
