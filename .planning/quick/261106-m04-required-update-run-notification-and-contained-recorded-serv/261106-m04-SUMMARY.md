## Merged call form for 261106-m02

```ts
recordedMcpServers(record, legacySource, createLegacyServersReader)
```

`legacySource` is the record's `LegacyServersSource` (`{ marketplaceName, marketplace, pluginName, locations }`). `builtin-registration-step.ts` calls it this way after its own `isPluginRootContained` pre-check:

```ts
const legacySource = { ...source, locations };
// ... pre-check ...
const recorded = await recordedMcpServers(source.record, legacySource, createLegacyServersReader);
```

Other production callers: `mcp-verdict-read.ts` passes `recordedMcpServers(record, source, legacyReaderFor)` (its module-private factory), and `mcp-migration.ts` passes an inline source plus `createLegacyServersReader`.
