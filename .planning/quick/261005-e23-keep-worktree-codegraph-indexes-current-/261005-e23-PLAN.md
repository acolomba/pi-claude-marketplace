# Keep worktree CodeGraph indexes current with a per-worktree daemon

<objective>

## Decisions (operator, 2026-10-05, locked)

- D-01: `scripts/init-worktree.sh` (SubagentStart): after the existing npm install and codegraph init steps, start the worktree daemon detached as `(CODEGRAPH_DAEMON_IDLE_TIMEOUT_MS=<ms> setsid codegraph serve --mcp --path "$top" </dev/null >/dev/null 2>&1 &)`, with a 4-hour idle timeout as the safety net. Do it only when codegraph is on PATH and `.codegraph/` exists. Hook stdout must stay empty.
- D-02: `scripts/codegraph-worktree-hook.sh` (PreToolUse on `mcp__codegraph__codegraph_explore`): remove the per-query index sync line and its comment. Then emit the existing `updatedInput` redirect. Keep all existing guards (toplevel differs from `$CLAUDE_PROJECT_DIR`; same git common dir).

Send SIGTERM only if it is an integer above 1 and its live command line contains `serve --mcp --path <worktree toplevel>`. Never kill a recycled or unrelated pid. Silent stdout, exit 0 always.

## Choices within the decisions

1. The hook starts a daemon only when the worktree has its own `.codegraph/` (fact 5). Without this test, a hook run in a worktree that has no index starts the enclosing checkout's daemon with the 4-hour timeout. D-02 says "start it the same way", and D-01's way includes the `.codegraph/` condition. The hook does not test `command -v codegraph`: a missing binary only makes the background start fail silently.
2. Liveness means a positive integer pid for which `kill -0` succeeds (D-02). The integer test comes first because `kill -0 0` succeeds (fact 7).
3. The stop script's identity check is D-03's "contains", with the end of the path anchored: it adds a space to the command line and requires ` serve --mcp --path <toplevel> `. A daemon for a path that only starts with this worktree's path never matches. It reads the command line with `ps -ww -o args=`, which D-03 allows, keeps the script free of NUL handling, and never truncates.
4. Exit 0 always (D-03): every step that can fail ends in `|| exit 0`, and `kill` ends in `|| true`. A SubagentStop hook that exits 2 keeps the subagent working.
5. `.claude/settings.json` gets the SubagentStop entry as the last key under `hooks`, with no matcher, timeout, or async, like SubagentStart.
6. No shared helper (D-04): the one-line start appears once in each of the two scripts.
7. 4 hours is `14400000` ms.
8. CHANGELOG.md stays as it is (D-04, fact 12): the sub-bullet says nothing about how the index stays current.
9. Comments: R1 and R2 each gain one two-line "why" comment, and R3 has one. No header comments.
10. One commit, in Task 1. Task 2 commits nothing unless it finds a bug. The commit type is `perf(init)`: queries no longer wait for a sync, and this repository already uses `perf(...)`.

[[ $BASE == /*/e23-contract.?????? || $BASE == /*/e23-e2e.?????? ]] || { echo "refusing: unexpected scratch path"; exit 1; }

# kill 0 or kill -1 would signal far more than a daemon, and a pid can be
# recycled, so signal only a live process whose own command line serves a path
# inside the scratch directory; a launcher that is still running can start a
# daemon again, so repeat until none is left
for _ in 1 2 3 4 5; do
    found=0
    while read -r pid args; do
        if [[ $pid =~ ^[1-9][0-9]*$ && $pid -gt 1 && "$args " == *" serve --mcp --path $BASE/"* ]]; then
            found=1
            echo "KILL $pid ${args##* }"
            kill "$pid" 2>/dev/null || true

        fi
    done < <(ps -eww -o pid=,args=)

    sleep 1
done
