# Fix plugin update marketplace sync auth

`/claude:plugin update` refreshes each GitHub-source marketplace clone once per
run (PUP-2, `makeSyncCloneOnce` in
`extensions/pi-claude-marketplace/orchestrators/plugin/update-flow.ts`). That
call passes no auth bundle to `refreshGitHubClone`, so `platform/git.ts`
registers no `onAuth` callback, and a private repository fails at once with
HTTP 401 and `{authentication required}`. `marketplace update` builds the
bundle with `buildAuthForHost` and works.

## Analysis

- `update-flow.ts:154` is the only `refreshGitHubClone` call without auth.
  Every other git fetch and clone in `orchestrators/` gets a bundle.
- `syncCloneOnce` runs only on the direct path (`updatePluginsWith`), where
  `opts.ctx` is required. The autoupdate cascade (`updateSinglePluginWith`)
  never calls it, so no stored-credential fallback is needed.
- Reinstall is not affected: it never refreshes the marketplace clone, and
  `probeReinstallClone` always builds its bundle with `buildCloneAuth`.
- Out of scope: `makeSyncCloneOnce` does not refresh `url`-source
  marketplaces at all. Report it separately.

## Tasks

### Task 1: Thread auth into the marketplace sync

- files: `extensions/pi-claude-marketplace/orchestrators/plugin/update-flow.ts`
- action: `makeSyncCloneOnce` takes the auth inputs (`ctx`, `credentialOps`,
  `deviceFlowHttp?`, `authMemo?`). For a `github` source it builds the bundle
  with `buildAuthForHost` on the host of
  `https://github.com/<owner>/<repo>.git` and passes it as the 5th argument of
  `refreshGitHubClone`. `updatePluginsWith` passes `opts.ctx`,
  `opts.credentialOps ?? DEFAULT_CREDENTIAL_OPS`, `opts.deviceFlowHttp`, and
  `opts.authMemo`.
- done: the sync fetch carries a `github.com` bundle that shares the run's
  `authMemo` and `credentialOps`.

### Task 2: Tests

- files: `tests/orchestrators/plugin/update-flow.test.ts`
- action: add two tests next to the PUP-2 and syncClone-fail tests:
  1. The sync fetch receives a `device-flow` bundle for `github.com` with the
     caller's `credentialOps`, and its `onAuthRequired` returns the memoized
     `authMemo` result.
  2. A sync fetch that throws an isomorphic-git `HttpError` 401 renders
     `{authentication required}` on the marketplace row.
- verify: `node --test tests/orchestrators/plugin/update-flow.test.ts`; test 1
  fails on the unfixed code.
