# Quick task 261025-vf1: an update resolves its new version's closure, and an install moves an out-of-range dependency (UPD-DEP-D1)

## Decision

UPD-DEP-D1, the user's option B (2026-10-25), extended to install (option 2
for an out-of-range dependency). An update is an install of a newer version:

- `update`, the bare and marketplace forms, and autoupdate run install's
  cascade (`runInstallCascade`, `rootRecorded`) over the new version before the
  swap: missing dependencies install, disabled ones are enabled;
- RESV-05 amended: an installed dependency outside the merged range moves
  first, through `update`'s own path, with the requester's ranges folded in
  place of its record's, so `{dependents constrain}` still protects it;
- every move is judged before the first runs (`judgeOnly` preflight); no
  satisfying version refuses with RESV-05's row and changes nothing;
- `apply`'s catalog moves keep the plan's MISS-01 / APPLY1-D1 handling, which
  `pending` previews; the converge runner settles nothing.
