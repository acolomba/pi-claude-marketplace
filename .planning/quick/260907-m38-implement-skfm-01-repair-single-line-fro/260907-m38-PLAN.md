## Locked scope — the repair class, verbatim

REPAIR a line only when ALL hold:
- it sits inside the frontmatter block (after the opening `---`, before the
  closing `---`);
- it starts at column 0 and has the shape `key: value` — key contains no
  whitespace, colon, or `#`, and is followed by a colon plus at least one space
  or tab;
- `keyValueEnd(lines, i, blockEnd) === i` (single-line value — no indented
  continuation);
- the trailing-trimmed value is non-empty, does not start with `"` or `'`
  (already quoted), does not start with `[` or `{` (flow collection), does not
  start with `|` or `>` (block-scalar header);
- the value contains a colon.

Everything else is copied byte-identically. Eligibility is decided PER LINE: an
ineligible line does not veto a sibling eligible line, because leaving a flow
sequence alone is the opposite of the asermax defect (which came from QUOTING
sequences, not from skipping them). If no line is eligible, return the input
string unchanged and let the caller degrade.

Do NOT normalize line endings. A CR-only or otherwise unsplittable document
falls through to the degrade untouched.
