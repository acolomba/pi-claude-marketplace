# Quick task 261106-m03: built-in `/reload` scenario in the terminal (P2-DC-100, BLT-01)

A new `@builtin-only` cucumber scenario installs a plugin with a stdio stub MCP server, runs `/reload`
in a Pi in the terminal, and has the scripted model find the plugin's tool through `tool_search` and
call it. The tool answers `echo:ping`. With an uncommitted scratch edit that stops both re-registration
paths on a reload, the scenario fails at its Then. Test-only: no commit touches `extensions/`.

Worktree base: `66b0afc` (`features/mcp-server` and `.agents/skills/cucumber` are unchanged from the
planning base `9a86602`, and the planning draft applied cleanly).
