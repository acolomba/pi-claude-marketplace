## Deviations

- The request said to drop the `(+N chars)` form. Claude Code keeps it with
  `…` in place of `...`, so this task keeps the count (upstream parity).
- Upstream's per-range 64 cut applies only to a range it quotes (an invalid or
  non-printable range). So an invalid declared range now shows in curly quotes,
  for example `“nope”`, on `{invalid version constraint}` and the held
  `could not be read` line.
- The texthooks `fix-smartquotes` hook turns curly quotes into straight ones in
  every file outside `.planning/`. Source and tests use `“`/`”`
  escapes. The output catalog sample for an unreadable range keeps `nope`
  without quotes, and its prose says the real row quotes it.
- Planned and executed inline, not through planner and executor agents.
