## Decisions (operator, 2026-10-05, locked)

- D-01: New `scripts/init-worktree.sh` (bash, `set -euo pipefail`), run by a synchronous SubagentStart hook. It reads the hook JSON on stdin and takes `cwd`. It exits 0 with no output unless `cwd` is inside a linked worktree of this repository other than the main checkout: `git -C "$cwd" rev-parse --show-toplevel` must differ from `$CLAUDE_PROJECT_DIR`, and the worktree's `git rev-parse --path-format=absolute --git-common-dir` must equal the same query run on `$CLAUDE_PROJECT_DIR`. Then, in the worktree, it runs `npm install` when the dependencies are missing (never the clean install, which deletes the build info that `.worktreeinclude` copied in), and `codegraph init --yes .` when `.codegraph/` is missing and `codegraph` is on `PATH`. Stdout stays empty; tool output goes to stderr. `scripts/init.sh` does not call it.
- D-02: New PreToolUse script `scripts/codegraph-worktree-hook.sh` with the same worktree test. In such a worktree it runs `codegraph sync "$top"` quietly (no stdout, failure tolerated). Then, when `tool_input.projectPath` is missing or equals `$CLAUDE_PROJECT_DIR`, it prints `{"hookSpecificOutput":{"hookEventName":"PreToolUse","updatedInput": <full tool_input plus projectPath: top>}}`. Otherwise it prints nothing. JSON handling uses node (jq is not a declared prerequisite).
- D-03: Register both hooks in the tracked `.claude/settings.json` and keep its `UserPromptSubmit` `codegraph prompt-hook`. SubagentStart is synchronous and runs `"$CLAUDE_PROJECT_DIR"/scripts/init-worktree.sh`. PreToolUse uses matcher `mcp__codegraph__codegraph_explore`. Do not touch `.claude/settings.local.json`.
- D-04: New tracked `.worktreeinclude` at the repository root with the single line `node_modules/.cache/typescript/tsconfig.tsbuildinfo`.
- D-05: Fix CONTRIBUTING.md, which names the clean install where `scripts/init.sh` runs `npm install`. Add one or two plain-English sentences saying that hooks set up Claude Code worktree subagents.
- D-06: Verification is an executable task: a throwaway repository outside the checkout, the real scripts and hook entries, `claude -p` with a CodeGraph stdio server, `--strict-mcp-config`, `--allowedTools=...` with `=` and the prompt on stdin, and two parallel `isolation: "worktree"` general-purpose subagents. Pass: each sees its dependencies at its first command, and each finds only its own new symbol. Also check the main-checkout negative case, run `bash -n` and shellcheck (if installed), remove the scratch repository, and kill only the CodeGraph daemons tied to the scratch path, never with a pattern that matches the killing shell.
- D-07: AGENTS.md commit rules (Conventional Commits, title 5-72 characters, body lines up to 80, `pre-commit run --files` before committing, no `--no-verify`, explicit paths, never `git add -A`). ## Choices within the decisions

1. D-01's install test reads `node_modules/.package-lock.json`, not the `node_modules/` directory (fact 2). This keeps D-01's intent (install when the dependencies are missing) and D-04's reason for `npm install`. The summary flags it for the operator.
2. D-01's toplevel test compares with `$CLAUDE_PROJECT_DIR` as written. The common-dir test resolves both sides through git, as D-01 says. A symlinked project path would make the main checkout look like a worktree; this machine has none, so the scripts add no third git call. The summary mentions it.
3. JSON goes through node only. Values reach node through stdin, argv, or the environment, never by splicing into the program text.
4. `codegraph sync --quiet "$top"` sends any output to stderr, and its failure is ignored (D-02).
5. SubagentStart has no matcher, no `timeout`, and no `async` (D-03). Every subagent type that works in a worktree needs the setup, and 600 s covers about 30 s of work.
6. Comments: each script has two short "why" comments and nothing else, with no header (D-07).
7. Task 2 strengthens the operator's pass wording. It checks the install marker instead of `test -d node_modules` (fact 3). It checks per-subagent body markers instead of bare symbol names, because the query text names both symbols. Stream-log counts prove that the model passed no `projectPath`, so the hook did the routing.
8. `BUILDINFO=present` is a pass condition. Claude Code 2.1.289 copies the file (fact 2), and the check keeps D-04 honest.
9. Three tasks. Task 1 commits the hooks after the deterministic contract passes. Task 2 is the Claude Code verification (D-06) and commits nothing unless it finds a bug. Task 3 commits the docs.

### R6: `tmp/c2w/e2e-cleanup.sh` (Task 2)

The guard refuses any path that is not a `mktemp` scratch directory, so an empty `base.txt` can never widen the match to every daemon or every process.

```bash
#!/usr/bin/env bash
set -euo pipefail

BASE=$(cat tmp/c2w/base.txt)
[[ $BASE == /*/c2w-e2e.?????? ]] || { echo "refusing: unexpected scratch path"; exit 1; }

# a registry pid can be malformed or recycled: kill 0 or kill -1 would signal
# far more than the daemon, so kill only a live process whose own command line
# names the scratch directory
node -e '
const fs = require("node:fs");
const path = require("node:path");
const dir = path.join(process.env.HOME, ".codegraph", "daemons");
for (const name of fs.existsSync(dir) ? fs.readdirSync(dir) : []) {
  const file = path.join(dir, name);
  const { root, pid } = JSON.parse(fs.readFileSync(file, "utf8"));
  if (typeof root === "string" && root.startsWith(process.argv[1] + "/")) {
    console.log(`${Number.isInteger(pid) && pid > 1 ? pid : "none"}\t${file}`);
  }
}
' "$BASE" | while IFS=$'\t' read -r pid file; do
    if [[ $pid =~ ^[1-9][0-9]*$ && $(tr '\0' ' ' 2>/dev/null < "/proc/$pid/cmdline") == *"$BASE"* ]]; then
        echo "KILL $pid"
        kill "$pid" || true
        timeout 10 tail --pid="$pid" -f /dev/null || true
    fi
    echo "UNREGISTER $file"
    rm -f -- "$file"
done

mapfile -t leftover < <(
    {
        pgrep -f -- "$BASE" || true
        find /proc -maxdepth 2 -path '/proc/[0-9]*/cwd' -lname "$BASE*" 2>/dev/null | cut -d/ -f3
    } | sort -u
)
for pid in "${leftover[@]}"; do
    echo "LEFTOVER $pid $(tr '\0' ' ' 2>/dev/null < "/proc/$pid/cmdline" || true)"
done

rm -rf -- "$BASE"
[[ ! -e $BASE ]] && echo "SCRATCH_REMOVED=yes"
echo "LEFTOVER_PROCS=${#leftover[@]}"
```
