# Quick task 261119-h5n: pin fallow 3.44.0 and fix the degraded fallow audit

Fallow 3.44.0 reports the workspace diagnostic `production-excluded-file-imported`
(`degrades_analysis: true`): production code under `features/` and `scripts/` imports
`test/e2e/_rpc.ts` and `test/platform/isolated-pi-home.ts`, which the production pattern
`**/test/**` excludes. The `fallow-audit` job fails on a degraded analysis.

Production mode for dead code stays on. `production.ignore: ["features/**", "scripts/**"]`
was considered and rejected: it would stop the dead-code gate from checking the cucumber
harness and the scripts.

## Task 1: pin fallow

- files: `package.json`, `package-lock.json`
- action: set `"fallow": "3.44.0"`, run `npm install`.
- verify: `npx fallow --version` prints 3.44.0.

  `test/platform/isolated-pi-home.ts` -> `scripts/isolated-pi-home.mjs` (a test-run preload,
