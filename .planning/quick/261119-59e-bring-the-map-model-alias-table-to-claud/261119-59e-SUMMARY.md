With Pi 1.5.0 temporarily installed (`--no-save`, restored afterwards; the installed-version gate printed `nested=0` again), "A Glob hook rewrites the search pattern" failed with the same `fd is not available and could not be downloaded`. Not fixed; it needs `fd` on PATH or a sandbox that allows the cleanup.
