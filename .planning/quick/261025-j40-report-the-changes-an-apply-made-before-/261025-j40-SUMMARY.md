# Quick task 261025-j40 summary

try. On a throw, `reportScopePasses` sends the migration notice, the cascade,
the post-commit warnings and the MCP config notices for what committed, then
the error is rethrown. A throw before anything committed sends nothing, and
never the apply-empty advisory.

  precedes the `internal-error` result.

  read-only pending block.
