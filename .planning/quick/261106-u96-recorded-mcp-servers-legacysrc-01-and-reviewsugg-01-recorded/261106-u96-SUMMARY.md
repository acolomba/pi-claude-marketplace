# Quick 261106-u96: Recorded MCP servers -- one source constructor, a neutral refusal error, and the unreadable reason

carries the plugin record its marketplace record lists, so every read of a
record's MCP servers takes one source. The containment check refuses a
source whose locations are not those of the scope its marketplace record
names. The unreadable arm says why, and the built-in registration step reads
that reason in place of a second containment walk.

## Questionable choices

| # | Choice | Alternatives | Why questionable | Severity |
| - | ------ | ------------ | ---------------- | -------- |
| 1 | The constructor takes the caller's `ScopedLocations` as "the scope" | Take a `Scope` plus cwd and call `locationsFor` inside | The caller can still pass the wrong scope's locations. Task 3's scope check catches that instead of the type. | low |
| 2 | The source carries the record, and readers take the source alone | Keep the record argument and check identity at run time | Readers can no longer take a different record from the one listed; `recordDegradeBaselineReader` still receives a port record and uses it only for the basis | low |
| 3 | The constructor throws a plain `Error` for an unlisted plugin | Return `undefined` | No production input reaches the throw. A caller that gets the pairing wrong fails loudly. | low |
| 4 | The scope agreement lives in `owningRoot`, so a mismatch reads as `uncontained`; the constructor does not throw | Throw in the constructor | The refusal shows only on the debug channel. A user sees the stored verdict, not an error. | low |
| 5 | The marketplace name comes from the record's `name`, not the `state.marketplaces` key | Pass the key separately | A hand-edited state where key and name differ uses `name`. `sourceCloneDir` still guards the path (T-u96-06). | low |
| 6 | The degrade-baseline port and info's `readServers` port keep their shapes | Make the ports take a source | The port's `record` argument is the same object as the source's record, but the type does not enforce that | low |
| 7 | `ComposeInstalledListRowOptions.marketplace` replaces five members | Keep the members and build the record inside | Callers must hold the whole marketplace record. `list-flow` and `edge-deps` already do. | low |
| 8 | The type keeps the name `LegacyServersSource` | `RecordedServersSource` | The name says "legacy", but stored records use the source too | low |
| 9 | The error is renamed `RecordedServersUnreadableError`, and its message says `cannot read` | Keep the old name | Debug-log readers who grep for `cannot re-resolve` lose their match | low |
| 10 | The reason union lives in the domain module, which lists all six members | Keep the reasons in the orchestrator | The domain module now names orchestrator refusal reasons | low |
