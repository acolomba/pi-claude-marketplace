<sanitizer_spec>
The port of `k6n` (npm), `E6n` (bun) and `wct`/`J4n` (download link). Message texts are verbatim, except where marked (UC) for an uncertain choice. In every message, `cut(x)` means the first 120 characters of `x` (UC: upstream's `Ve(x,120)` form was not confirmed).

**Shared checks**

- **npmName(n):** replace A-Z with lowercase, then require no `..`, no `//`, and a match of the scoped or unscoped pattern from finding 2.
- **rangeOrTag(s):** `s` must not end in `.tgz`, `.tar.gz` or `.tar` (case-insensitive), and `semver.validRange(s) !== null` or the dist-tag pattern matches.
- **registrySpec(spec):** `spec` must be a string. When it starts with `npm:` and the rest has an `@` at index 1 or later, take the name before the last `@` and the range after it: `npmName(name)` and `rangeOrTag(range)`. Otherwise: `rangeOrTag(spec)`. This is the same as upstream's `/^npm:(.+)@([^@]*)$/`. Write it with string methods.
- **exactVersion(v):** a string with `semver.parse(v) !== null`.
- **readLists(object, fields, label):** for each field present, the value must be a plain object, else `<label> has an unreadable <field> list`. Every `[name, spec]` must pass `npmName(name)` and `registrySpec(spec)`, else `<label> has a dependency that is not a registry package and version range: <cut(name)>`. Return the present fields as they are.
- **Field sets:** ALL = dependencies, devDependencies, optionalDependencies, peerDependencies. ENTRY = the same without devDependencies.
- **rootDependencies(root, manifest, lockfileName):**
  1. `lock = readLists(root, ALL, "its <lockfileName>")`
  2. `pkg = readLists(manifest, ALL, "its package.json")`, then drop from `pkg.dependencies` every name in `pkg.optionalDependencies`. For `bun.lock`, drop them from `pkg.devDependencies` too.
  3. For each ALL field, compare the entries of `lock` and `pkg`, sorted by name in code-unit order. A missing field is empty. On any difference: `its package.json and <lockfileName> list different dependencies`.
  4. Result: `lock`, plus `peerDependenciesMeta: normalizePeerMeta(manifest.peerDependenciesMeta)` when that is a plain object.
- **normalizePeerMeta(meta):** keep each `[name, value]` where `npmName(name)` holds and `value` is a plain object, as `{ optional: value.optional === true }`.
- **integrity(value, label, hasLink):**
  - `""` gives `<label> has no integrity hash for its download link` when there is a link, else `<label> has an empty integrity hash`.
  - A non-string, or a space-separated token that does not match `^(sha512|sha384|sha256|sha1)-[A-Za-z0-9+/]+={0,2}$`, gives `<label> has an unreadable integrity hash`.
- **binPath(p):** not empty, does not start with `/`, contains no `\` and no `:`, and has no `..` segment when split on `/`.
- **binName(n):** not `""`, `.` or `..`, and contains no `\`, `/` or `:`.
- **bin(value, label):** a binPath string, or a plain object in which every `[name, target]` has `binName(name)` and a string target that passes `binPath`. Else `<label> has a bin link that points outside its package or has an invalid command name`.
- **optionalPeers(value, label):** an array of strings, else `<label> has an unreadable optionalPeers list`. The first entry that fails `npmName` gives `<label> has an optional peer that is not a registry package: <cut(name)>`.

**Download link** (`J4n`). The first rule that fails gives `<label> has a download link that <reason>`, where `manager` is `npm` or `bun`. A link that is not a string has the reason `is not text`.

1. The link does not match `^https?://` (case-insensitive), or `URL.canParse` fails: `is not an http or https link`.
2. It contains `#`, whitespace (`\s`), a backslash, or a control character: `contains a "#", whitespace, a backslash or a control character`.
3. Take the URL hostname, remove one trailing `.` (UC), then remove every leading `www.`. If the result is a forge host: `is on GitHub, GitLab, Bitbucket or SourceHut, where <manager> may fetch it as a git repository and run its setup script`. Exception: on gitlab.com, a path that starts with `/api/v4/` and contains `/-/` passes this rule.
4. The pathname starts with `//`: `starts its path with "//"`.
5. The protocol is `http:` and the origin is not the registry origin (an undefined registry origin never matches): `is an unencrypted http link on a host other than your npm registry, so <manager> could send your saved registry token to it in the clear`.

**npm** (`k6n`). The input `lockfileName` is the source name, `package-lock.json` or `npm-shrinkwrap.json`.

1. If `JSON.parse` fails: `its <lockfileName> is not valid JSON`. If the result is not a plain object: `its <lockfileName> is not a JSON object`.
2. `lockfileVersion` not 2 or 3: `its <lockfileName> is in an old format; regenerate it with npm 7 or later`.
3. `manifest.overrides` is defined: `its package.json sets overrides, which this install does not apply`.
4. `packages` or `packages[""]` is not a plain object: `its <lockfileName> has no packages section with the plugin in it`.
5. `w = rootDependencies(packages[""], manifest, lockfileName)`.
6. Check each other entry in order, with E = `its <lockfileName> entry "<cut(key)>"`:
   1. The key must start with `node_modules/`, and every part of the rest, split on `/node_modules/`, must pass npmName. Else `E is not a package in node_modules`.
   2. The value must be a plain object, else `E is not an object`.
   3. `link` or `inBundle` defined: `E is a folder link or a bundled copy`.
   4. `version` must pass exactVersion, else `E has no exact version`.
   5. `name`, when defined, must be a string that passes npmName, else `E has a name that is not an npm package name`.
   6. `resolved`, when defined, goes through the download-link check. Then a missing `integrity` gives `E has no integrity hash for its download link`.
   7. `integrity`, when defined: `integrity(value, E, resolved !== undefined)`.
   8. `readLists(entry, ENTRY, E)`.
   9. Each of `dev`, `optional`, `devOptional`, `peer` that is `true` is kept as `true`.
   10. `os`, `cpu` and `libc`, when defined, must be arrays of strings, else `E has an unreadable <field> list`.
   11. `bin`, when defined: `bin(value, E)`.
   12. `peerDependenciesMeta`, when it is a plain object: normalizePeerMeta.

   A rewritten entry keeps only these fields, in this order: version, name, resolved, integrity, the three lists, the four flags, os, cpu, libc, bin, peerDependenciesMeta. Everything else is dropped, for example `license`, `engines` and `hasInstallScript`.
7. Result:
   - packageJson `{ name: "plugin-dependencies", version: "0.0.0", ...w }`
   - lockfile `{ name: "plugin-dependencies", version: "0.0.0", lockfileVersion: 3, requires: true, packages: { "": { name: "plugin-dependencies", version: "0.0.0", ...w }, ...entries } }`
   - packageCount = the number of entries, without `""`
   - work-dir lockfile name `package-lock.json`, also for an npm-shrinkwrap.json source

**bun** (`E6n`). Here `lockfileName` is `bun.lock`.

1. The text has a comment, or the comment-free, trailing-comma-free text does not parse to a plain object: `its bun.lock is not valid JSON`.
2. `lockfileVersion` not 0, 1 or 2: `its bun.lock is in a format this extension does not read` (UC: upstream says "this version of Claude Code").
3. `patchedDependencies` defined in the lockfile or the manifest: `it patches its dependencies (patchedDependencies), which this install does not apply`.
4. `workspaces` must be a plain object whose only key is `""`, with a plain object as its value. Else `its bun.lock does not list the plugin as its only workspace`.
5. `packages` must be a plain object, else `its bun.lock lists no packages`.
6. `D = rootDependencies(workspaces[""], manifest, "bun.lock")`. `V` = `D` without `peerDependenciesMeta`. When `workspaces[""].optionalPeers` is defined: `V.optionalPeers = optionalPeers(value, "its bun.lock")`.
7. Check each entry, with E = `its bun.lock entry "<cut(key)>"`:
   1. Split the key on `/` and join each part that starts with `@` to the part after it. Every joined part must pass npmName, else `E is not a package path`.
   2. The value must be an array of length 4, else `E is not a registry package`.
   3. `[ident, resolved, meta, integrity]`: `ident` is a string whose last `@` is at index 1 or later, the part before it passes npmName, and the part after it passes exactVersion. Else `E is not a registry package at an exact version`.
   4. When `resolved !== ""`: the download-link check, with manager `bun`.
   5. `meta` must be a plain object, else `E has unreadable metadata`.
   6. The kept meta is: readLists(meta, ENTRY, E); `os`/`cpu`/`libc` as a string or an array of strings (else `E has an unreadable <field> list`); `optionalPeers` through optionalPeers(value, E); `bin` through bin(value, E); `binDir` as a binPath string (else `E has a bin folder outside its package`).
   7. The rewritten entry is `[ident, resolved, keptMeta, integrity(integrity, E, resolved !== "")]`.
8. Result:
   - packageJson `{ name: "plugin-dependencies", version: "0.0.0", ...D }`
   - lockfile `{ lockfileVersion, configVersion (only when it is a number), workspaces: { "": { name: "plugin-dependencies", ...V } }, packages }`
   - packageCount = the number of packages
   - work-dir lockfile name `bun.lock`
