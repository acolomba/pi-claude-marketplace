This rule applies to `.github/workflows/ci.yml` and `.pre-commit-config.yaml` (Task 2):

- Before editing a file, save `git diff HEAD -- <file>` to `tmp/u7n/ci.operator.diff` or `tmp/u7n/precommit-config.operator.diff`. Then edit the working tree.
- If the saved diff is empty, stage the file with `git add`.
- If the saved diff is not empty, never stage, revert, or rewrite the operator's lines. Write `git show HEAD:<file>` to `tmp/u7n/<name>.head`, make the same edits to that copy, and stage only the copy: `git update-index --cacheinfo 100644,<blob>,<file>`, where `<blob>` is the output of `git hash-object -w tmp/u7n/<name>.head`.
- After staging, `git diff --cached -- <file>` shows only this task's lines, and `git diff -- <file>` still shows the operator's lines.
