<objective>
Close the loop the milestone exists for: a plugin the user hand-added to
`claude-plugins.json` as a bare `"p@mp": {}`, whose manifest says
`defaultEnabled: false`, is installed disabled by the next `/reload` AND has
`enabled: false` written into the entry it was declared in — so the reload after
that plans nothing instead of pushing `acc.enable`.

Two facts make this narrow rather than a widening of the write-back skip. The
stamp fires only when the install actually landed disabled, which already
requires the caller's opt-in and an absent `enabled` key. And the file it targets
is the one the declaration lives in, read off `PlannedPluginInstall.configSource`
— a seam the planner has populated since it was written and nothing has ever
read.

Purpose: without the stamp, the next `/reload` reads absent-as-enabled, finds the
record disabled, and pushes `acc.enable` — the exact silent re-enable this
milestone closes. Proving the resulting fixed point at the planner is the next
phase's job; putting the state where the planner looks is this one's.
Output: the narrow stamp inside install's existing lock, the reconcile wiring
that selects the declaring file, the truthful cascade outcome, and the tests that
distinguish a base declaration from a local one.
</objective>
