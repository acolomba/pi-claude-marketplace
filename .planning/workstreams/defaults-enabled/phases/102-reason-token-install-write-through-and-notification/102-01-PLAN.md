<objective>
Land the phase's spine end to end: a plugin whose resolved `defaultEnabled` is
`false` installs, is immediately disabled by the same primitives the `disable`
verb uses, is written through to `claude-plugins.json`, and is reported as
`◍ <plugin> v<version> (disabled) {installs disabled}` at informational
severity with a hint naming the remedy.

The closed-set amendment is indivisible with the rest by construction. Adding
`installs disabled` to `REASONS` without a topic home makes `_UncoveredReason`
non-`never`, a TS2344 error at `npm run typecheck`; adding `"disabled"` to
`INSTALL_STATUSES` without a render arm is a TS2741 error at the
`as const satisfies` site. The phase cannot half-land, so it lands whole.

Purpose: DFEN-04 is the milestone's first observable behavior change, and OUT-01
is the vocabulary it needs to explain itself. Composing the disable half from
`cascadeUnstagePlugin` + `toDisabledRecord` (never from `setPluginEnabled`)
makes the terminal state byte-identical to `install` followed by `disable` by
construction rather than by careful re-implementation.
Output: the four-site closed-set amendment, the render-layer hint pair, install's
`disabled` arm, the materialize-then-disable composition inside the existing
lock, the write-back patch's first field, and one end-to-end test.
</objective>
