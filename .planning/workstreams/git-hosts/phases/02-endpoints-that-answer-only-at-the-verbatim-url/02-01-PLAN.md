<objective>
Derive the wire URL per source kind instead of decorating every clone URL, and prove it end-to-end on
the `marketplace add` path — the case PR #153 actually reported.

Purpose: `addGitClonedInGuard` today sends `<cloneUrl>.git` for every host. A smart-HTTP server that
answers only at the path the user typed 404s that request. Claude Code appends `.git` only for a
`github.com` `owner/repo` path, so the unconditional append is the divergence and removing it is the
whole fix (D-2-01). No retry, no fallback, no status gate.

Output: `networkCloneUrl(source)` beside `canonicalCloneUrl`, a decoration-stripping sibling in
`domain/source.ts` that stops short of the `.git` strip, the marketplace add seam wired to it, and
both add suites asserting the sent URL by value against a git port that admits only the verbatim
form.
</objective>
