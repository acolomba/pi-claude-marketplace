Pin the two behaviors that shift as a consequence of moving the supported-kind boundary, so a
reviewer meeting them reads them as intended rather than as accidental.

Purpose: admitting a kind changes what "the supported set grew" means. Two existing mechanisms
notice: the load-time reconcile backfill re-materializes a partially-installed record whose set
grew, and `update` on a disabled record rewrites a compatibility pin that now differs. Neither is
edited by this phase. Both are correct, both are one-time, and neither is currently asserted for
this kind.

Output: three backfill cases and one update case, all extending existing files.

   re-resolved one produces no churn — which is what makes the self-heal one-time rather than
