Append seven cases to `tests/domain/resolver-strict.test.ts`, all driving `resolveStrict` against an
in-memory context — no tmpdir, no memfs. Every case narrows with `if (r.state === "installable")`
before reading `componentPaths`, because the resolved value is a discriminated union and reading the
member on an unnarrowed value is a typecheck error. Every `assert.equal(r.state, ...)` carries
`r.notes.join(" / ")` in its failure message so a red run is self-diagnosing. Title each test with
its `WFLW-02` or `WFLW-03` anchor and no planning references.

1. Manifest string form: the entry declares nothing, the manifest declares `workflows: "wf"`, and no
   convention directory exists. Assert `installable` and `componentPaths.workflows` deep-equals
   `["wf"]`, and that `supported` includes `"workflows"`.
2. Manifest array form with dedup: the manifest declares `workflows: ["a", "b", "a"]`. Assert
   `componentPaths.workflows` deep-equals `["a", "b"]` — first-wins dedup collapses the repeat and
   preserves declaration order.
3. Declared-equals-convention adjacency: the entry declares `workflows: "workflows"` AND
   `<pluginRoot>/workflows` exists on disk. Assert `componentPaths.workflows` deep-equals
   `["workflows"]` and has length exactly 1 — the two axes merge on an exactly-equal path rather
   than producing two identical elements.
4. Union ordering: the entry declares `workflows: "custom"` AND `<pluginRoot>/workflows` exists.
   Assert `componentPaths.workflows` deep-equals `["custom", "workflows"]` — declared first,
   convention appended, never sorted.
5. Declared-but-absent: the entry declares `workflows: "nope"` and nothing else exists beyond the
   plugin root. Assert `installable`, `componentPaths.workflows` deep-equals `["nope"]`, and
   `r.notes` is EMPTY. Path validation is shape-only and never stats; this is the same treatment
   skills, commands and agents already get, and the assertion on the empty notes array is the load-
   bearing half — it is what distinguishes "accepted with no note" from "accepted with a warning".
6. Escaping path parity: the entry declares a `workflows` path that climbs out of the plugin root.
   Assert the resolution is `unavailable` and that a note was produced. Then assert parity: the same
   escaping string declared under `skills` on an otherwise identical fixture produces the same state
   and a note of the same shape. Parity is the point — no workflows-specific containment logic
   exists or should.
7. Empty convention directory: `<pluginRoot>` and `<pluginRoot>/workflows` exist and the directory
   has no entries in the fixture map. Assert `installable`, `supported` includes `"workflows"`, and
   `componentPaths.workflows` deep-equals `["workflows"]`. The directory existing is the signal;
   emptiness surfaces downstream as zero enumerated names, not as absence.

Add one assertion inside case 2 or 4 covering the encoding edge: declare two paths that differ only
in Unicode normalization form and assert BOTH survive as distinct elements. Dedup goes through a
`Set<string>` keyed on the raw declared string with no normalization step, so this pins the existing
comparator rather than introducing an expectation the code does not meet. State that rationale in
the assertion message.
