<objective>
Open the load-time scan to the population it was closed to, and give a convergence a
row a user can read.

Purpose: the population whose install already works is exactly the population that never
converges. One early return is what closes it. Widening it silently would trade one
defect for another — a plugin gaining commands on a reload nobody asked for, with a row
byte-identical to a fresh install.

Output: the widened scan proven end to end on one path, a new closed-set reason token
with all five of its derivations moved together, and the two published backfill catalog
states brought back to byte-truth.
</objective>
