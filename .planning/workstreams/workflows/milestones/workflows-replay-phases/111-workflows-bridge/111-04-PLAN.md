| Boundary | Description |
|----------|-------------|
| recorded reconcile version -> load-time re-materialization | a version comparison decides whether persisted install records are re-resolved on the next load |

| plugin fixture script -> the bridge under test | the integration fixture's body is third-party-shaped script text driven through the real admission rule |
