<objective>
Name the workflow staging trees the sweeper keeps forever, and close the phase.

Purpose: the sweeper deliberately spares an aged staging tree whose displaced directory still holds
envelopes, because those bytes are the only surviving copy of the user's previous workflow scripts.
Nothing then removes that tree and nothing names it. It sits outside every scope root, so uninstall and a
reload cannot reach it, and both sweep call sites discard the sweep's return inside a bare catch. On the
crash path there is not even a failure to attach a leak line to. Kept forever and undiscoverable is better
than a silent expiry on a recovery copy, but it is not a finished state.

Output: a read-only sibling scan sharing the sweep's retention rule, an advisory line on both arms of the
one read surface that is not plugin-scoped, two paired catalog states, and the phase's own green gate.
</objective>
