<objective>
Create the live-UAT driver that replaces a source read with a measurement, and prove
it can fail.

Purpose: the compatibility doc's `agent()` claim is the one that decides whether a
workflow script copied from Claude Code degrades or dies, and it is stated today at
source-read grade. Nothing in this repository can drive the host engine, because the
engine is deliberately in no dependency manifest. A standalone driver outside
`npm run check`, pointed at a scratch install, is the only shape that can.

The hazard is not that the driver fails. It is that it passes having measured nothing:
the failure inducer is an ABSENCE of credentials, so a machine that has them lets the
call succeed and the canary goes green on a machine where it proved nothing. That is
this milestone's signature defect, shipped four times already. The measurement
precondition is therefore the load-bearing assertion here, and it is proven to fire.

Output: `tests/live-uat/workflow-agent-failure-canary.mjs`, a recorded green run naming
the engine version it observed, two recorded red runs, and a README that tells the next
operator how to reproduce all three.
</objective>
