<objective>
Replace a refuted source read with the measurement that overturned it, at the grade the
measurement actually holds.

Purpose: this document is the contract a plugin author reads before copying a workflow
script from Claude Code, and its `agent()` section currently tells them the opposite of
what the engine does. It says every failure branch throws and that a fan-out script may
therefore die where upstream would degrade. Driven at run time, the ordinary failure
resolves to `null` on both engines and the run completes. A reader acting on the current
text would rewrite a working script to defend against a failure mode that is not there,
and would remain unwarned about the narrower one that is.

Output: a section that states the measured split, names the driver and the version that
produced it, gives the honest practical consequence, and publishes any census figure only
with the provenance and the counting rule that make it checkable.
</objective>
