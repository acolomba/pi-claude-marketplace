Make every removal path take workflow envelopes away, and make the record stop naming envelopes that
are already gone.

Purpose: the envelopes live outside every scope root, so nothing else will ever find them. Three of the
four verbs the criterion names inherit the removal from one edit to the cascade primitive; the part that
does NOT come free is the two record folds, which read the dropped bundle structurally and keep
compiling while silently ignoring a new axis. That is the defect class this project has shipped
repeatedly, so both folds get an explicit test rather than a compiler.

Output: a sixth cascade slot with a typed per-name failure, a `workflows` axis on the dropped bundle
populated on both returns, both folds subtracting it, and behavioral pins on all four verbs.
</objective>

|----------|-------------|
