<objective>
Sweep orphaned workflow staging trees, and correct every comment and document that still states the old
bridge count.

Purpose: the staging root is created before the write loop and removed only by a successful commit or an
explicit abort. A crash, a kill signal, or the deliberate retention path a failed restore takes leaves it
behind holding verbatim third-party executable JavaScript. It lives under the home directory and not
under any scope root, so it is invisible to uninstall and to a reload, and it accumulates for the life of
the machine. This plan owns the ledger and therefore owns the only view of which trees are live -- and
because nothing persists a staging identifier, an age bound is that whole view rather than a refinement
of one.

Output: one fs-only sweeper module with its mirrored owner test, one exported age constant, two swallowed
call sites, and the count corrections.
</objective>
