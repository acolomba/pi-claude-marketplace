<objective>
Pin LIFE-04 with per-kind regression coverage: a manifest-absent installed plugin stays fully
uninstallable through its existing installation record, with every owned resource and the plugin
record removed through the normal uninstall path.

The behavior already holds — `orchestrators/plugin/uninstall.ts` imports no manifest module and
no resolver — so this plan is characterization, not repair. D-98-12 chose per-kind isolation over
fixture economy so that when one resource kind regresses, exactly one case goes red and names it.

Purpose: LIFE-04 is one of the eight requirements this milestone carries as coverage debt; the
existing `seedFullPlugin` seeds only four of the five kinds (hooks is absent) and the seeded
mcp.json entry is never asserted removed.
Output: an extended seed factory and six isolated cases in the existing uninstall suite.

Tracer exemption: this plan adds no production behavior — it characterizes a path that already
ships end-to-end. A tracer slice would restate the first per-kind case with no new information,
so Task 1 (the seed extension the other cases depend on) leads instead.
</objective>
