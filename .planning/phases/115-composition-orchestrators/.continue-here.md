## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Proof that cannot fail | Six instances: an expected value built by calling the production classifier under test; a regex alternation matching two different error classes; an expected notification interpolated from the actual error; type-level negatives attached to nothing because a multi-line `satisfies` reports on its closing line; an exhaustiveness alarm silently lost when unreachable arms were deleted; two guards whose deletion left the suite green. | blocking | Plant the violation, confirm RED, revert. Record the plant in the summary. |
| `git add -A` in a shared checkout | The operator keeps unrelated modified and untracked files here and edits them concurrently. | blocking | Stage explicit paths only. Never `-A`, never `.`. |
| `pre-commit run --all-files` | Pulls mdformat, markdownlint, and the texthooks fixers over every tracked Markdown file and rewrites planning and operator docs a `.ts` change cannot affect. | blocking | Use `--files` with explicit paths. The TypeScript hooks call whole-repo npm scripts anyway, so scope is not lost. |
| Trusting a piped `fallow` tail | `fallow health` and `fallow dupes` print `✗`-prefixed summary lines even on success. | advisory | Check the exit code, never the output text. |
| Shell variable word-splitting | This shell does not word-split. `git add $FILES` passes one argument and dies with a pathspec error. | advisory | Pass explicit paths. |
| Test-boundary helpers as methods | Declaring them as methods on the returned type fires `@typescript-eslint/unbound-method` at every destructuring site (115-04 hit 11). | advisory | Use arrow properties: `readonly clonedUrls: () => readonly string[]`. |
