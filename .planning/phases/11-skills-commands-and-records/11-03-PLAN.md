<!-- Upstream, Claude Code 2.1.323, quoted verbatim in 11-RESEARCH.md evidence records E1 and E2. -->

Quoted form (`z_s`): at the start of the text, or after whitespace or one of the four marks, `@`,
a double quote, one or more characters that are not a double quote, a double quote. A value that
ends ` (agent)` is dropped.
Unquoted form (`R3n`): the text is split on whitespace. In a token, the `@` is its first
character or follows one of the four marks. The path is the rest of the token with its trailing
characters outside `[A-Za-z0-9_]` cut (`DNt`); at least one character must remain. A result that
starts with a double quote is dropped, because the quoted form owns it.
Line range (`sls`): `^([^#]+)(?:#L(\d+)(?:-(\d+))?)?(?:#[^#]*)?$`; the end defaults to the start;
a second `#` part is ignored.
Repeats are removed. Upstream lists quoted mentions before unquoted ones; this module uses the
order of first appearance in the text (assumption A3 of the research).
Truncation note (E2): "Note: The file <name> was too large and has been truncated to the first
<N> lines. No need to mention the truncation. Use <Read tool name> to read more of the file if
you need."
Upstream masks no code: the mask is this project's rule (D-PG11-03).
