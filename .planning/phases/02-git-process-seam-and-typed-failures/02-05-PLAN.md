<objective>
Make a missing git visible where the user meets it: `platform/git.ts`'s four
network verbs locate git before isomorphic-git runs, so a git-source
`marketplace add` or plugin install with no usable git fails with
`{git missing}` and the requirement text, while path-source and hosted
marketplaces keep working. Pin each case, and the credential-lookup change of
plan 02-03, with cucumber scenarios that fail without the change.

Purpose: SG-PRC-06 and ROADMAP success criterion 5. The product still clones
with isomorphic-git, which needs no git binary, so the gate is what makes the
message appear (RESEARCH F2); the transport swap later raises the same error
from the same place. AGENTS.md requires a scenario for each user-visible
change, and the hardened credential environment is one (orchestrator note).

Output: the gate and its unit cases, `usePiWithoutGit()` and its step, two
`without-git` features, the world-rules entry, and two credential scenarios
with their fixture.
</objective>
