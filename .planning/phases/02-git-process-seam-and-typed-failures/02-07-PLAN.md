## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a cloned repository's config to git's ssh launch | a repository could name its own ssh command |
| the remote to the user's terminal | a remote could make git or ssh ask for a password, passphrase, or host-key answer |
| a hung remote to Pi's process | a remote that never answers keeps git and its helpers running |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-32 | Elevation of privilege | a repository's own `core.sshCommand` | high | mitigate | `GIT_SSH_COMMAND` composed from the user's global and system config outranks every config scope; the real-git marker case |
