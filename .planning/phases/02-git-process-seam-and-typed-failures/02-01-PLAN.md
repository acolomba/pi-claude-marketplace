<objective>
Extract the D-PL9-15/18/19 launcher from `platform/package-manager.ts` into a
new, spawn-injected `platform/process-run.ts` (moved, not copied), then give it
the three things a git process needs: stdin input followed by end-of-file, a
tail capture of stderr, and a parameterized Windows PATH lookup.

timeout that kills the whole process group) for every git launch rest on one
launcher, shared with the package manager so `fallow dupes` stays clean
(RESEARCH Pattern 1, CONTEXT [Seam and gates]: "a timeout that kills the whole
process group (shared with the D-PL9-15/19 launcher)"). The git module of plan
02-03 is its second consumer.

Output: `platform/process-run.ts` and its test module, a thinner
`platform/package-manager.ts`, and `test/platform/process-fake.ts`.
