<objective>
Give a git failure its typed form and its closed-set reason before any code
raises one: the `git missing` reason token (D-SG-07, orchestrator answer 1),
the `GitCommandError` class with its closed `GitFailure` union, the
`instanceof` rung of `classifyGitFailure` that maps every kind to a reason,
and the `marketplace add` row that keeps the requirement text visible.

Purpose: SG-PRC-05 (a typed error with a kind, narrowed by `instanceof`) and
SG-PRC-06 (a clear message naming the requirement). Every surface that already
reads the D-PL7-01 ladder (`marketplace add`, `update`, install, `apply`,
`import`, `fetch`, the autoupdate pass) gets the reason through it, and the
transport swap of a later phase keeps each scenario's reason because each kind
already has one. The git process module (plan 02-03) and the git-required gate
(plan 02-05) raise these errors.

Output: the token across the closed set, `GitFailure` and `GitCommandError`,
the classifier rung, the add row, and the D-SG-07 record in PROJECT.md.
</objective>
