network calls in `platform/git.ts` send their bytes to the configured base while every clone keeps
its canonical github.com identity. The phase's tracer runs first: one github.com clone goes to the
base, end to end through real isomorphic-git and the mocked HTTP transport, and records the
canonical origin.

stays github.com) and D-02 (refreshes never send the recorded origin's host). Proving it on a real
clone first catches a wrong placement before the auth and verb work builds on it.
Output: `shared/github-base-url.ts`, `InvalidGitHubBaseUrlError`, the four rewritten platform
calls with the D-10 cause tail, the seam's pair test, and the shared test helper that sets the
variable.
