<objective>
Re-point six architecture gates at the target registry and give each one a visitation proof, so
none of them can address a target that stopped resolving while still reporting success.

Purpose: `D-07-05` says a gate composes nothing locally, and criterion 4 exists because a literal
that lives inside a gate file is invisible to a scan that reads one place. These six carry 46 of
the 60 remaining repo-relative production path literals under `tests/architecture/**`. The work is
mechanical, which is exactly why it is worth doing in one bounded pass rather than incidentally.

Output: six gates whose targets come from `gate-targets.ts`, each asserting its group or its walk
is non-empty, with every existing assertion and failure message preserved byte-for-byte apart from
the target source.
</objective>
