<objective>
Close the two named production-unowned-export instances and gate the class with a pinned census
measured by the tool the repository already runs.

Purpose: `DCORE-030` and `ORA-F32` are one defect with two instances — an export whose only consumer
is a test — and gating one while leaving the other is the split that lets a class survive. The
class is larger than the two: the measured census is 91 unowned exports under `extensions/` and 11
under `scripts/`, many of them legitimate design. A must-be-zero gate cannot ship green, and
`D-07-18` forecloses an allow-list. `D-07-19` as amended resolves this with a pinned set: an
allow-list forgives named entries silently and forever, while a pinned set fails on any change in
either direction and forces a conscious diff.

Output: two exports unexported with their owner tests still complete, and a census gate asserting
deep equality against a committed list.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-44 | Tampering | `fallow` subprocess invocation | high | mitigate | The command is spawned with a fixed argument array and no shell, so no flag or path can be word-split or reinterpreted. The exit status and stderr are read and surfaced; a failed invocation fails the gate rather than parsing an empty payload. `--production` is passed per invocation, so `.fallowrc.json` is never written, and the gate asserts that file is unmodified. |
| T-07-45 | Repudiation | a census that passes on an empty result | high | mitigate | The parsed set is asserted non-empty before the deep comparison, so a broken invocation cannot deep-equal an accidentally-empty pin and report success. |
| T-07-46 | Repudiation | a length pin absorbing a swap | high | mitigate | The comparison is a deep equality against a sorted committed list, and both directions are observed: an added export and a deleted pin entry each make the gate fail, with the output recorded. |
| T-07-47 | Information disclosure | narrowed module surface | low | accept | Unexporting two symbols narrows reach; it exposes nothing new. Coverage is re-proved through the public surface, and an unreachable branch is recorded rather than papered over with a restored export or a coverage directive. |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | Not applicable by construction: this plan installs no package. Fallow 3.20.0 is already a dependency and self-verified its signature during research. |
</threat_model>
