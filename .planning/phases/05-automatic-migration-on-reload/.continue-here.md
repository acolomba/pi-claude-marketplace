## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Worktree isolation for executors | Agent worktrees have no `node_modules`, so executors there cannot pass the commit hook or run `npm run check`; `worktree.base-check` returns `shouldDegrade: false` here, so nothing degrades automatically. | advisory | Before every executor/reviewer/fixer dispatch run `node .claude/gsd-core/bin/gsd-tools.cjs query dispatch-isolation --raw --phase NN --plan NN-MM --force-isolation none`, check `.gsd/dispatch-isolation-sentinel.json`, and keep the `[gsd:dispatch phase=… plan=…]` tag matching. |
| init.manager phase misread | `query init.manager` reports archived phase dirs as executed/stale for phases 1, 2, 5-7. | advisory | Trust `query init.phase-op N`. |
| Stale IDE diagnostics | The harness shows TypeScript errors on files the commit hook type-checked clean. | advisory | Trust `npm run typecheck`. |
| zsh shell traps | zsh expands `=word` and does not word-split `$VAR`. | advisory | Avoid leading `=` in echo; use explicit literal paths or `${=VAR}`. |
