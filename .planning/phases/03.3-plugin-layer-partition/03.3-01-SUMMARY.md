## Regression guards (pass before and after)

- `WR-09: an orchestrated uninstall of a plugin only the local layer declares is not refused` catches a layer rule applied in orchestrated mode (reconcile would then fail to converge on a hand-edited local layer).
- `LAYER-04: a plugin that is not installed reports not installed whatever the other layer declares` catches a verdict placed before the record checks (it would turn `{not installed}` into `{plugin declared locally}`).
- Edge rows `acts on the local layer when the scope-target flag appears <placement>` (x3), `preservation leaves the scope-target flag selecting the local layer`, `honors the scope flag and the scope-target flag together` catch a handler that drops `--local` (the command would then be refused) or `--scope` (a different scope's record would go).

- `pluginLayerVerdict` prototype case catches an `in`/indexing membership read instead of an own-key read.
