`commands`, `agents`, or `workflows` path replaces the conventional folder, a
declared `skills` path adds to `skills/`, and a staging verb warns when a
declaration leaves an existing folder unread.

that fails without it; Phases 3, 4, and 7 pin their own kind.

`commands/` loses the folder's commands on its next install or update, as
upstream does, and the user is told.

the two staging paths (the install ledger and the update swap), the lenient
