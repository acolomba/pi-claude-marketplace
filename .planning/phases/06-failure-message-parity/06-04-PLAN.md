Claude Code. `{N}` is `Math.round(timeoutMs / 1000)`, and `{unit}` is `second` when `{N}` is 1
and `seconds` otherwise (D-SG-13). The leaf names its interpolated values `host`, `label`,
`seconds`, `unit`, and `code`, which the AUTH-09 scan of Task 1 allows.

`remote.url` holds no `://`, else there is none, which gives the `<host>` rows. `{label}` is
`GitHub` when `remote.gitHub` is true; otherwise the WHATWG `host` of `remote.url` (with a
non-default port) when it holds `://` and parses; otherwise its scp host by
`^(?:[^@/]*@)?([^@:/]+):`; otherwise `your git host`. `{host}` in the HTTPS row follows the same
rule, with `this host` in place of `your git host`. The `network` check runs on the stderr with
every line that starts with `remote: ` removed, as `classifyGitExit` reads it (WR-01), so a
server cannot pick the remedy. Pi's own anchored kinds decide the class; the remedy follows the
kind (CONTEXT, trigger precedence).
