## Redaction rules this plan locks (D-SG-35)

`redactCredentials` keeps its existing four rules and order, and adds these. Every new pattern is
linear: an anchored literal prefix, one bounded character class, no nested or adjacent
overlapping quantifiers, so `sonarjs/slow-regex` and `sonarjs/regex-complexity` stay quiet.

| Rule | Replaces | Keeps |
|---|---|---|
| encoded userinfo | the text between `scheme://` and the last `%40` before the authority's first `/`, `?`, or `#` | `scheme://` and `%40` (`scheme://***%40host/`) |
| query values | inside each `scheme://` token (upstream `Cn`: `[a-z][a-z0-9+.-]{0,31}://` then `[^\s'"\x60<>]+`), the non-empty value of every `?name=value` and `&name=value` | `?`, `&`, the name, `=` |
| fragment pairs | inside the same token, the non-empty value of a `#name=value` pair | `#`, the name; a bare `#stable` or `#v1` stays whole (url sources use `#<ref>`) |
| Authorization Basic | the value after `Authorization:` then `Basic`, any case, any length | the header and scheme words |
| Basic token | `Basic` then 20 or more of `[A-Za-z0-9+/=._~-]` (upstream `http-auth-scheme`) | `Basic realm="..."` prose |
| provider tokens | each fixed-prefix row of the 2.1.332 table in 06-RESEARCH.md "Fixed-prefix provider rules", one module-level `readonly RegExp[]`, each replaced by `***` | everything around the token |

The provider table holds: aws-access-token, gcp-api-key, google-oauth-client-secret, both
digitalocean rows, the three anthropic rows, openai-api-key, huggingface-access-token, both
supabase rows, the eleven gitlab prefixes (`glpat-`, `gldt-`, `glrt-`, `gloas-`, `glptt-`,
`glagent-`, `glimt-`, `glsoat-`, `glcbt-`, `glft-`, `glffct-`), the five slack rows,
npm-access-token, pypi-upload-token, sendgrid, databricks, pulumi, postman, both grafana rows,
sentry, stripe, and both shopify rows. It leaves out hashicorp-tf, whose shape has no fixed
prefix, and the GitHub rows, which the existing rule covers. Upstream's trailing boundary
`(?:[\x60'"\s;]|\\[nr]|$)` becomes a lookahead or a `\b`, never a consumed character.

`redactUrlSpellings(text, urls)` ports upstream `mn` and `i3e`: a URL with a `scheme://` and with
userinfo, a query, or a fragment has the spellings `[url, url less its userinfo up to the first
"@", url less its userinfo up to the last "@" before the authority's first "/"]`, deduplicated and
replaced longest first. Each spelling becomes the URL's safe form: WHATWG `new URL(url)` with
`username`, `password`, `search`, and `hash` cleared, read back as `href`, or `[redacted URL]`
when `URL.canParse` refuses it. A URL with none of the three has no spellings, and an scp
address (`git@host:path`) has none either.

`redactShownText(text, urls = [])` is the one pass for a shown stderr and, from the next plan, a
debug line: it splits on `\n` and runs `redactAbsolutePaths(redactCredentials(redactUrlSpellings(line, urls)))`
on each line, then joins with `\n`. It runs per line because `redactAbsolutePaths`'s quoted-path
rule redacts the whole rest of a text after a quoted absolute path when a later line holds a
slash: measured during planning, `Cloning into '/home/u/.pi/agent/pi-claude-marketplace/sources-staging/9b2f0c1e'...`
followed by `fatal: repository 'https://127.0.0.1:4443/acme/tools.git/' not found` became
`Cloning into '[redacted path]` as one text, and stays both lines, with the path cut to
`'9b2f0c1e'`, when each line runs alone.
