# Phase 03.4 Plan 04: Unreadable dependency cause without load errors Summary

**When a marketplace manifest fails to load, the `{unreadable}` dependency cause now reads `cannot read the dependencies of <plugin>@<marketplace>` and carries none of the load error's text. The fixed reasons the extension writes stay. The change sits in the one builder in `dependency-index.ts`.**
