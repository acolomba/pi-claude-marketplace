## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Restoring planted RED with `git checkout --` over uncommitted edits | An executor wiped its own uncommitted edits this way (3.3-03) | blocking | RED against old code runs in a scratch worktree (`git worktree add --detach <scratchpad>/wt-X HEAD`, removed afterwards); never copy old files over edits |
| zsh word splitting | `$VAR` file lists pass one arg in zsh, breaking `git add`/`commit` | advisory | Use arrays (`F=(...)`, `"${F[@]}"`) or literal paths |
| Commit title length | gitlint rejects titles over 72 chars | advisory | Keep titles ≤72; nothing commits on a failed hook, so retry without --amend |
| Stale LSP diagnostics | Editor errors on `.ts` (e.g. old `configJsonPath`) are stale | advisory | Trust `npx tsc --noEmit` |
