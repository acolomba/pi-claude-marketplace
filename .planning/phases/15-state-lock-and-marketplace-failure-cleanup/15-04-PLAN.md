<objective>
Prove that a failed `marketplace add` leaves nothing behind and can be retried (FLR-03), and
that `marketplace remove` deletes the plugin clones only its plugins used, while it keeps one
another marketplace's plugin still uses (FLR-04). Both behaviors were measured correct, so this
plan adds scenarios and the one phase-local step D-10 asks for (D-09, D-10, D-11, D-12).

Purpose: without these scenarios, a regression that leaves a partial checkout, a stale record,
or an orphaned clone would pass the suite.
Output: one step module, four failed-add scenarios, and two remove scenarios.
</objective>
