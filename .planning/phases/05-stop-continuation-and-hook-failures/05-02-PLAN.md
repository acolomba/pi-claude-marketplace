<objective>
Show the user one notice for each synchronous hook that fails without blocking.

Purpose: Today a hook that exits 1, or that cannot start, leaves only a debug line, so a plugin author and a user see nothing. Claude Code 2.1.323 shows a `<hook name> hook error` notice with the first line of the hook's stderr, and it shows a start failure once.
Output: a failure carrier on the hook result, the notice texts, the notices on the composite and tool-result events, the once-only set in the hooks runtime, and three scenarios in features/hook/failures.feature.
</objective>
