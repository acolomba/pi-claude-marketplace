<objective>
Run `Stop` hooks on Pi's `agent_before_settle` event, so that a blocking `Stop` hook continues the run it ended.

Purpose: Today the bridge runs `Stop` after the run has settled and sends a follow-up message that starts a new run for each block. Claude Code continues the same run. Pi's boundary event lets an extension append one hidden message and ask for one more model call, and research measured that it behaves the same in the terminal, print, json, and rpc modes on Pi 1.5.0 and 1.5.2.
Output: the boundary handler in extensions/pi-claude-marketplace/bridges/hooks/settle.ts, its registration, the runtime operations it needs, the rewake mark at the wake site, a harness probe for run starts, and the Stop scenarios on the new path. The probe and the regression guard for a rewake land first, in a commit of their own, on the unchanged production tree.
</objective>
