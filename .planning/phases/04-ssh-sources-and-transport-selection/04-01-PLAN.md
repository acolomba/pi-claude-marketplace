<objective>
Give Pi upstream's git address forms (D-SG-17, SG-SSH-01). A port of Claude Code's
validator `iTs` gates every git address. The source parser gains the scp
`user@host:path` arm, the `http://` git arm, and the URL-scheme SSH arms. The add command
line keeps refusing `ssh://`, `git+ssh://`, `ssh+git://`, and `git://` with upstream's
`Invalid marketplace source format...` text, while config, apply, and import accept the
SSH forms. A git-subdir `url` goes through the same validator, which closes 03-SECURITY
finding F-2. The cucumber harness gets its first SSH steps on the existing stand-in.

Purpose: a user who authenticates git over SSH can add a marketplace or install a plugin
from an SSH address (issue #325, ROADMAP success criterion 1).
Output: `domain/git-url.ts`, the new source arms, the add command-line form, the import
`git` kind, two new feature files, the ssh step module, and the F-5 harness guard.
