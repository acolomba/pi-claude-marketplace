<objective>
Make `marketplace add` of a GitHub `owner/repo` source pick its transport as Claude Code
does (SG-SSH-02, SG-SSH-03; 04-EVIDENCE Q18 and "Progress lines and errors"): upstream's
`ssh -T` probe from the one spawn site, SSH first only on `configured`, HTTPS first
otherwise, a retry with the other transport, and one both-failed error. CLAUDE_CODE_PLUGIN_PREFER_HTTPS
and the GitHub base override give one HTTPS attempt and no probe (D-SG-24, D-SG-21/OQ-2).
`CLAUDE_CODE_REMOTE` is not read (capability gap, D-SG-24). The runner records the D-SG-22
note on a collector; 04-07 attaches it to rows.

Purpose: a user with an SSH key adds a private `owner/repo` marketplace over SSH (issue #325).
Output: the probe launch and verb, the `GitHubSshOps` port, the pure plan, the runner, the
add seam wrap, the stand-in's consistent refusals, the transport scenarios, and the
re-baselined Device Flow scenarios.
