<objective>
Make the release-tag reads use SSH by default for GitHub `owner/repo` sources, as upstream's
`zmt` does, unless `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` or the base override forces HTTPS
(D-SG-20, D-SG-21, SG-SSH-03, SG-SSH-04). Both reads change: a constrained dependency's own
tag list (D-03-03) and a path-source dependency's marketplace tag list (D-SG-09).

Purpose: parity with upstream's constrained installs; the accepted consequence for a user
with no key is the TAGS-02 current-copy fallback.
Output: `tagReadUrl`, the two probes using it with the chosen URL as the memo key, and the
tag-read scenarios.
</objective>
