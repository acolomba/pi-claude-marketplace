| Path | Where the note goes |
|---|---|
| update and reinstall `skipped`, `partially-upgradable`, `manual recovery` (#133) | on the row, by its `<plugin>@<marketplace>`, as the other update and reinstall rows read it (04-15) |

| Row | Input | Scenario |
|---|---|---|
| update `(skipped) {up-to-date}` | the cached clones are deleted; the update re-clones at the same commit | Task 1 |

| reinstall `(skipped) {dependents constrain}` | a dependent's range holds the repository's new 2.0.0 revision, which the reinstall re-clones first | Task 2 |
| reinstall `(manual recovery)` | none: no feature file shows a manual-recovery row for any source, and the restore failure it needs has no harness fault. The unit cases prove the row; the SUMMARY records the reason, and 04-26 carries it into the D-SG-22 outcome | unit only |
