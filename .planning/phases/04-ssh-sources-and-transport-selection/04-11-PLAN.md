<objective>
Give `plugin update`, `reinstall`, and the dependency moves an update makes the install's
transport choice (D-SG-19, OQ-4): one context per command root, threaded beside `authMemo`
to every clone and `ls-remote` these commands run through the update preflight seam. The
update runner's converge entry takes a context too, for 04-17's apply.

This is the first half of the update-family transport work, split by call path: these
commands reach clone-cache through the update preflight. 04-12 does the direct callers
(`fetch`, `info --fetch`), `enable` (D-SG-19, extended by the maintainer on 2026-11-25), and
then makes the clone-cache transport required, which can compile only once every caller
passes one.

Purpose: a user with no SSH key keeps working HTTPS updates (D-SG-19's reason), and a user
with a key updates over SSH.
Output: the update and reinstall contexts, the moves and the converge entry threaded, the
ref resolution on the plan's attempts, and the update-family transport scenarios. Their
rows' notes are 04-15's.
</objective>
