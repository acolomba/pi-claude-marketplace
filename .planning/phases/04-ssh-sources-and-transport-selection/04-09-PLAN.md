<objective>
Move every clone refresh onto an attempt list (CONTEXT [Identity]; 04-RESEARCH §A3, §E,
OQ-4, OQ-5): `refreshCloneBySwap` takes attempts instead of one URL; `marketplace update`,
the autoupdate pass, and the PUP-2 sync build them from the declared source with the
marketplace path's probe rule; plugin mirrors use the caller's transport. The recorded
origin no longer picks the URL.

Purpose: a refresh follows the same transport choice as the add, so a user whose
marketplace was added over SSH keeps refreshing over SSH, and a no-key user keeps HTTPS.
Output: the list-based swap, its three callers, and the refresh scenarios. The refresh
rows' notes are 04-13's.
</objective>
