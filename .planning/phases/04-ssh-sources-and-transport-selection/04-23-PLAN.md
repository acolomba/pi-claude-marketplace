## Placement (CONTEXT Claude's Discretion: "how the transport note sits in the notification")

The note sits on each plugin row of the cascade's marketplace block, carried on the outcome that
`beginPluginUpdateRun`'s `PluginUpdateFn` returns (04-17's `CloneNoted` / `carriedClone`
pattern), so `orchestrators/marketplace/` reads no plugin collector. Measured 2026-11-26: the
cascade's dependency rows ride as the seam returns them (`marketplace/update.ts` spreads
`o.dependencyRows`), so the seam notes them by key and `marketplace/update.ts` needs no change;
the plugin row is composed by `marketplace/update.messaging.ts::outcomeToCascadePluginMessage`.

difference is a regression to fix in the code.
