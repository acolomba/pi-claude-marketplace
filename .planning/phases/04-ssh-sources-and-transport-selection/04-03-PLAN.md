<objective>
Fold every GitHub spelling of a repository into one identity, as upstream's `Ort` does
(D-SG-23, SG-SSH-06), and make the GitHub base override cover the SSH spellings (D-SG-21).
The fold lives in `shared/github-base-url.ts`, beside the only `github.com` literals,
because `platform/git.ts::runRemote` and the insteadOf pairs need it and `.fallowrc.json`
lets `shared/` and `platform/` import only each other (a reversible relocation of CONTEXT
[Identity]'s "port Ort into domain/clone-key.ts"; the domain keeps the comparisons that
use it). The comparisons that use it: leftover recognition, planned-versus-recorded
source, reserved names, mirror seeding, and the credential host.

Purpose: an SSH clone is the same source as its HTTPS form and is never refused as stale
(ROADMAP success criterion 4), and every GitHub address form reaches the mirror under the
base override.
Output: `gitHubAddressOf`, per-URL pairs and wire URLs, the folded comparisons, and their
scenarios.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-09 | Spoofing | lookalike GitHub spellings steering a comparison | medium | mitigate | `Mle`'s refusals (brackets, backslash in the authority, non-ASCII or control characters, scp `@` after `:`) make such an address fold to nothing; the fold changes identity only, never the wire URL outside the base override |
| T-04-10 | Tampering | a base holding `=` breaking the insteadOf key | high | mitigate | GHB-03's refusal stays before any pair is built; the pair key is `url.<base>/.insteadOf` with the prefix as the value |
| T-04-11 | Tampering | folding cache keys | high | mitigate | `canonicalCloneUrl`, `pluginCloneKey`, `pluginMirrorKey` unchanged; the invariant row pins the github-kind key |
| T-04-12 | Repudiation | two records merging silently | low | accept | the fold runs only in comparisons; two records that fold to one make `recordedSourceAction` find two matches and run a fresh add (04-RESEARCH §R) |
| T-04-SC | Tampering | npm installs | high | mitigate | no package is added |
</threat_model>
