<objective>
Add the `autoapply` setting (AAP-01..03, 30-CONTEXT.md D-01..D-12). Off, a load is
phase 29's read-only load. On, the load runs the `apply` step itself before resource
discovery, so a fresh checkout or a pulled config change takes effect in the session
that loads it.

Purpose: a user who opts in gets the desired state on load without typing `apply` or
`/reload`; everyone else keeps phase 29's read-only load.

Output: the schema field, the precedence helper, the load branch, the silent empty
apply at load, owner tests at 100% direct coverage, `features/plugin/autoapply.feature`,
and the docs (README.md, README.es.md, AGENTS.md network policy, CHANGELOG).
</objective>
