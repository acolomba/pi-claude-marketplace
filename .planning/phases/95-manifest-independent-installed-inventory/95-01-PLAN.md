<objective>
Make the `/claude:plugin list` inventory tell the truth about installed records
whose marketplace manifest no longer lists them, without flattening the partial
or disabled states that already survive manifest absence.

Purpose: a plugin installed on disk and recorded in `state.json` is installed,
full stop. Today the list renders it as a bare `(installed)` row with no hint
that its marketplace no longer declares it, so a user cannot tell a healthy
install from an orphaned one. INV-01 adds the `{not in manifest}` brace; INV-02
prepends the same reason to the degraded row; BOUND-03 makes sure the brace is
never emitted about a manifest the system failed to read.

Output: a new characterization suite pinning the pre-change behavior, plus three
production edits in two files — the `ScopedManifest` threading, the row-builder
reason stamping, and the render-map pass-through.

Requirement mapping: INV-01 (Task 2), INV-02 (Task 1 pin + Task 3 change),
INV-03 (Task 1), INV-04 (Task 1), BOUND-03 (Task 2).
</objective>
