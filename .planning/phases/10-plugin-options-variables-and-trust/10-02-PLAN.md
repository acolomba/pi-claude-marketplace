Option schema (E1): `{type: enum(string|number|boolean|directory|file), title: string, description: string, required?: boolean, default?: string | number | boolean | string[], multiple?: boolean, sensitive?: boolean, min?: number, max?: number, options?: string[]}`, strict.
`options` rules (E1): at least one value; each value 1 to 64 characters, equal to its trimmed form, with no control, invisible, or bidirectional-formatting character; no value repeated in any letter case; only for a field of type `string` that is neither `multiple` nor `sensitive`; a field with `options` needs a `default` among them, or `required: true`.
Key (E1): `/^[A-Za-z_]\w*$/`.
Reference (E2): `/\$\{user_config\.([^}]+)\}/g`; the key is any run without `}`.
Lookup (E2): own-property only. Value text (E2): `String(value)`.
Default map for MCP (E3, `Jgt`): skip an option with `required` and no default; otherwise `default ?? ""`.
Hook variable (E5): `key.replace(/[^A-Za-z0-9_]/g, "_").toUpperCase()` after the prefix `CLAUDE_PLUGIN_OPTION_`.
