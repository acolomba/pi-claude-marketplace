- **The built-in encoder takes the text form.** `BUILTIN_FIELD_ENCODER` asks the walk for the
  option's value as text, in place of the "no option pass" it stated in plan 10-17. When no
  encoder states "no option pass" any more, remove that form from the encoder's member.

  field scenarios stay in `features/mcp-server/options.feature` and become `@mcp` where the
  result is the same under both implementations; a result that differs stays a pair.
- **The home-path case has two lines.** The verdict blocks the server first; Pi's own home
  check in `builtin-entry.ts` now sees the resolved text and refuses it too. The guard of
  Task 2 is shown able to fail with both lines off.
