## Planner decisions

- **The block is in `builtinServerConfig`.** It returns `undefined` when `mcpOptionBlock`
  blocks the declared server under the context's options, so every caller of the built-in
  entry is safe. The registration step logs the option keys for such a server in place of
  its general line; it asks the verdict for them. Neither the built-in entry nor the step
  branches on the verdict's reason, because plan 10-15 adds a reason in the same wave: the
  log prints the reason and the keys as the verdict gives them.
- **The options go on `McpSubstitutionContext`, required.** Both producers state them: the
  adapter stage from its input, the registration step from `recordedOptionsOf` of the record
  through the options function of plan 10-09, which gives `undefined` when the record
  declares none. The adapter encoder does not read the member yet; plan 10-17 does.
- **A feature file of its own.** `features/mcp-server/builtin-options.feature`,
  `Feature: MCP server builtin options`, tagged `@builtin-only` as
  `builtin-values.feature` is, because the registry probe exists only under that profile.
  Plan 10-15 changes `features/mcp-server/options.feature` in the same wave.
