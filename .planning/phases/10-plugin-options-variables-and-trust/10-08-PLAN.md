<objective>
Export every plugin option that has a default to the plugin's hooks as
`CLAUDE_PLUGIN_OPTION_<KEY>`, from the option schema on the install record.

Purpose: PG-CORE-03 under D-PG10-10, D-PG10-15, D-PG10-19, and D-PG10-23. Plan 10-07 put the
declared schema on the record. This plan adds the one function that reads it back, which
validates it again because a project record is a file a repository can commit, and gives it
its first consumer: the hooks hydrate that runs at every load. Both spawn lanes build their
environment in one function, so one edit there reaches every hook. Under D-PG10-19 (pending
maintainer review), a declared default counts as a saved value here, which is more than
Claude Code 2.1.323 does for hooks.

Output: the record reader, the options on the hooks routing carriers, the hook environment,
and two scenarios.
</objective>

## Planner decisions

- **The reader lives in `persistence/state-io.ts`.** `recordedOptionsOf(record)` returns
  `ResolvedOptions`. `bridges/hooks` and `orchestrators` both reach it, and `domain` stays
  pure. It lands here, with its first consumer, because an export that no production module
  imports fails the commit hook.
- **The carriers take the resolved options as a required member.** A fixture or a producer
  that has no options passes `resolveOptions(undefined)` explicitly. So 13 hook test files
  take one member each in the same commit: the type check runs in the commit hook, and a
  narrower commit does not compile. The type check's output is the list of files to change.
- **This plan feeds the load-time producer only.** A load builds each cache entry from the
  record, and that is the path a user reaches with `/reload` or a new session. The
  install-time producer has no option input in this plan: the entry it caches holds
  `resolveOptions(undefined)`, as for a plugin that declares none. Plan 10-16 gives that
  producer its input and changes its four call sites and their nine caller tests. The two
  halves are separate plans because together they change more than 40 files.
