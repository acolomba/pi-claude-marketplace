## Planner decisions

- **The function and the options come from plan 10-09.** Each stager calls
  `substituteClaudeContent` with the options member of its input, and each hub passes the
  options function's result for `resolveOptions` of the resolution's `declaredUserConfig`.
  This plan adds no second content function and no second rule for "declares none".
- **New feature files.** `features/slash-command/options.feature` and
  `features/agent/options.feature`, each `Feature: <Function> options`.
- **Why this plan is 26 files.** The option member of each staging input is required, so
  five test files that build an input take one member each beside the owner tests: the two
  type tests, the target check, and the two grant conformance tests. Commands and agents are
  one task each, with one commit and one scenario each.
