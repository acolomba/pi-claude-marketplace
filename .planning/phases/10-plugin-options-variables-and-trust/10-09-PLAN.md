## Planner decisions

- **Two functions in `shared/vars.ts`, one pass each.** `substituteClaudeVars(content, vars)`
  keeps its signature and behavior for the hooks bridge. A new exported
  `substituteClaudeContent(content, vars, options)` adds the option references to the same
  alternation for content. Its `options` parameter is required and is either a structural
  value declared in `shared/vars.ts` (a values map and a sensitive set) or `undefined` for a
  plugin that declares no `userConfig`. `ResolvedOptions` of `domain/user-config.ts` satisfies
  that structure; `shared/` imports nothing from `domain/`.
- **One options function in `domain/user-config.ts`.** It takes resolved options and gives
  them back when the plugin declares `userConfig`, and `undefined` when it does not
  (D-PG10-21). Both ledger hubs call it here; plans 10-12, 10-13, 10-14, and 10-18 call it for the
  MCP stage, the built-in registration, and the command and agent stagers. It is in `domain/`
  because `orchestrators/plugin/`, `orchestrators/reconcile/`, and `orchestrators/mcp/` all
  reach `domain/`, and the rule it holds is a rule of options, not of one command.
- **Tracer on the install path.** Task 1 feeds the stager from the install ledger, which
  install, enable, import, and the install cascade use. The staging input's member is
  required, so `update-swap.ts` states `undefined` in Task 1; Task 2 gives the update and
  reinstall path its options, with its own red scenario.
- **New feature file.** `features/skill/options.feature`, `Feature: Skill options`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a plugin's option values to files the model reads | A staged skill file reaches the model's context. |
| a staged body to the invocation-time passes | Text written at staging is read again by the argument and context-command passes when the user invokes the skill. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
