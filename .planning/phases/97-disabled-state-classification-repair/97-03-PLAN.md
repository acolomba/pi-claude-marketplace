<objective>
Make `enable` and `disable` behave correctly on a disabled partially-installed
record. The ENBL-05 collapse already inverts both branches at the single equality
test; the enable half needs one further edit, because `runEnableBranch` was
written when a disabled record was fully installable by definition and passes no
partial gate to the install ledger.

Purpose: without the gate, the collapse makes `enable` fall through to the ledger
and then fail with a shape error — ENBL-07 would be silently unmet behind a green
predicate test.

Output: a partial-capable enable branch plus three byte-locked behavior tests
(re-materialization, the manifest-absent boundary, disable idempotency).
</objective>
