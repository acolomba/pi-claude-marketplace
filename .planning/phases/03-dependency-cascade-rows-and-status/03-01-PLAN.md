<objective>
Bound the catalog `version` string that a hold cause and a dependency move
refusal interpolate, at render, to the 64 UTF-16 code units Claude Code keeps
for a version (CAS-07 / VERSTR-01, D-PL3-12, D-PL3-16). The cut helper this
plan adds in `domain/dependency-range.ts` is the one helper D-PL3-09 names;
plan 03-04 reuses it for the 120-unit directory pin cut.

Purpose: a marketplace-controlled version string can no longer flood the
line-oriented `{dependents constrain}` row or a `cannot move:` refusal.
Output: `truncateForRefusal` + `MAX_REFUSAL_VERSION_CHARS`, the two call sites,
their unit cases, and one `update.feature` scenario that fails without the cut.
</objective>
