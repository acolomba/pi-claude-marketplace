<objective>
Refuse `install` of a root plugin whose `<plugin>@<marketplace>` id breaks the
token rule with Claude Code's own verdict, in Claude Code's order: look the root
up first; an unlisted root keeps the not-found verdict, and a listed root is
refused `{invalid manifest}` with the invalid-id cause (CAS-02 / ROOTKEY-01,
D-PL3-04, D-PL3-05, D-PL3-14). Record D-PL3-17 as a known limit.

Purpose: the root of an install is nobody's dependency, so the misleading
`declares an unusable dependency (root: ...)` cause goes away for it.
Output: a root-specific closure arm, its cause, the exported escape helper, the
updated integration pin, two `install.feature` scenarios, and a catalog state.
</objective>
