# Plan 08-02: Hook output matches upstream

**Retroactive record.** The security audit left T-05-33 open: a hook's
stdout was cut at 1 MB, so a large deny failed open. The user asked what
Claude Code does and chose "match upstream fully" (DC-42).

3. Apply a failed hook's own JSON block or deny with its reason.
