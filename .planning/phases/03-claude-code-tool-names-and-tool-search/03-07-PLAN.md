<objective>
Let a plugin agent's `tools:` and `disallowedTools:` entries that name the plugin's own MCP tools in Claude form reach the delivered tools through pi-subagents' `mcp:` entries.

Purpose: ANAME-02 for agents (D-03-15, D-03-19). Today every `mcp__` token is dropped, so an agent that lists its plugin's MCP tools launches without them. The delivered names are Claude's (plan 03-01), and pi-subagents selects a server by its exact adapter key and a tool by its raw MCP name. Because pi-subagents runs MCP tools only in background children, a mapped agent needs `async: true` launches; this plan warns and documents, and never injects the flag.

Output: the grant mapping in convert.ts, the written-server set threaded from three orchestrators, the README text, one commit.
</objective>
