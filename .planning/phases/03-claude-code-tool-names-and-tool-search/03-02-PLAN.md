<objective>
Let a plugin's hook matchers name its own MCP tools by server, as Claude Code documents (`mcp__<server>__.*`), and prove that the literal and `if:` forms already fire on the names Phase 3 delivers.

Purpose: ANAME-02 for hooks (D-03-14, D-03-21). Today `mcp__<server>__.*` is dropped as a regex, so the plugin reports `{unsupported hooks}` and the hook never runs. The plugin's tools reach Pi as `mcp__plugin_<plugin>_<server>__<tool>` (plan 03-01), which is exactly the name Claude's hook matchers expect.

Output: a server-prefix alternative on the parsed matcher, the dispatch arm, proof tests, the hooks compatibility doc rows, one commit.
</objective>
