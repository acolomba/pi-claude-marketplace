<objective>
Decide, for each carried field, whether the plugin or the user owns it: a field the plugin's translated entry sets is the plugin's on update and reinstall, and write-back gives the user their own stub value back.

Purpose: the Phase 2 hand-off (02-CONTEXT deferred idea, ROADMAP Phase 3 note) under ANAME-07 (D-03-04, D-03-05, D-03-06). ANAME-07 writes `requestTimeoutMs` from the manifest, but AFILE-06 carries that field forward, so without this plan a plugin's later timeout change never takes effect and a dropped timeout lingers as if the user set it. Claude Code gives the plugin's timeout and no user override, so the plugin wins.

Output: `pluginSetFields` on the marker, the carry-forward, write-back and notice rules, the catalog prose, one commit.
</objective>
