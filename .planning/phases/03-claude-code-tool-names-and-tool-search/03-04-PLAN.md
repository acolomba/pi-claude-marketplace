<objective>
Make a Claude MCP feature that pi-mcp-adapter cannot honor follow the house partial-install pattern, and make a server config that Claude Code's own schema rejects a structural defect.

Purpose: ANAME-07's partial half and ANAME-03's length arm (D-03-10, D-03-17, D-03-18, D-03-20). Today a `ws` server or a per-tool `always_deny` policy is written as if it worked, and the adapter silently ignores what it cannot run. After this plan a normal install refuses with `{unsupported mcp}` and the `--partial` hint, `--partial` leaves the affected servers out, and an invalid server config resolves `unavailable` with `{malformed mcp}`. The measurement found no Pi name-length limit, so no length check is added (D-03-17).

Output: `classifyMcpServer` in the shared domain table, the resolver wiring, the `unsupported mcp` reason, the note arms on both surfaces, the catalog amendment, one commit.
</objective>
