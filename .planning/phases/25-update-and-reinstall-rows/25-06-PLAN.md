<objective>
UPR-04: `reinstall` and `update` of a plugin that is not installed fail with
`{not installed}`, as `uninstall` does and as Claude Code does (D-14, upstream
evidence D-02: upstream's update returns `failureCode: "not_installed"` after
checking the install record before the marketplace entry, and its reinstall is
uninstall plus install, which fails at the uninstall step). Orchestrated callers
keep their silence (D-15).

a severity flip on a skip row -- while `uninstall` renders `(failed)`, and an
`update` of a never-installed plugin the manifest dropped reads
`failed {not in manifest}`.

Output: the reinstall pre-runner failure, update's triage verdict, the shared
cross-scope signal as a `failed` row, backfill's benign converge, two scenario
changes, and the catalog states that show these rows.
</objective>
