## Edge assumptions

- This row creates `runtime.ts` and its mirrored owner. Later outline rows intentionally do not modify that file, so its contract must cover routing, pending, settle, and async lifecycle operations named by research.
- Routing/generation/pending operations become production-used in this plan. Settle and async operations are committed as the fixed downstream contract consumed by Plans 05-10 and 05-11, not as test customization.
- Existing callers cannot all migrate in this row because the outline serializes shared files. One private production transition instance may preserve signatures until explicit runtime propagation lands.
- Plans 05-09, 05-10, and 05-11 migrate registration, dispatch/settle, and async consumers. Plans 05-28 through 05-30 migrate reset callers. Plan 05-31 removes the transition and reset exports.
- Pi has no proven callback-disposal API. Generation invalidation on the same runtime remains the stale-callback mechanism.

<threat_model>

## Trust Boundaries

| Boundary                                           | Description                                                                                                |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Extension lifecycle to runtime instance            | A wrong lifetime can leak routes, context, settle state, children, or PID ordering across extension loads. |
| Runtime operation to private mutable state         | Callers require behavior without write authority over internal maps, arrays, counters, or entries.         |
| Transition delegates to current production callers | A hidden optional/default selection can create multiple lifetimes or make the new runtime test-only.       |

## STRIDE Threat Register

| Threat ID | Category                           | Component                     | Severity | Disposition | Mitigation Plan                                                                                    |
| --------- | ---------------------------------- | ----------------------------- | -------- | ----------- | -------------------------------------------------------------------------------------------------- |
| T-05-23   | Tampering / Information disclosure | runtime isolation             | high     | mitigate    | Keep all substate in factory closures and prove two instances cannot observe or clear one another. |
| T-05-24   | Tampering                          | raw-state authority           | high     | mitigate    | Expose behavior operations and readonly values only; reject mutable container or counter access.   |
| T-05-25   | Tampering / Denial of service      | production transition binding | high     | mitigate    | Use one eager non-optional production-used binding and assign exact migration/removal plans.       |
| T-05-26   | Repudiation                        | routing order and generation  | medium   | mitigate    | Preserve exact epoch, map/bucket insertion, enumeration, and pending-context assertions.           |

ASVS Level 1: all high-severity lifecycle and state-authority threats block completion. This plan changes only in-memory ownership and introduces no package or persisted schema.
