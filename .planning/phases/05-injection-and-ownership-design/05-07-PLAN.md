## Edge assumptions

- Plugin-index cache files remain cross-process artifacts. Only in-memory ownership changes.
- `GetPluginIndexOptions.now` remains the narrow deterministic TTL control; it does not become a general dependencies object.
- Marketplace-name memory and its fresh census are assigned to Plan 05-08. Do not remove them in this plan.
- Plan 05-12 constructs the final extension-owned cache and deletes the production transition. Plans 05-19 through 05-25 bind invalidators. Plans 05-30 and 05-31 migrate reset callers and delete the legacy reset.
- `edge/register.ts` cannot receive the final extension-root instance until Plan 05-12 modifies root/type files. It must use the one eager production transition value here, never an optional or per-keystroke cache.

<threat_model>

## Trust Boundaries

| Boundary                                   | Description                                                                                                   |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| Registered command to completion provider  | The callback must use the cache selected by production composition, not a hidden or per-keystroke lifetime.   |
| Persisted cache file to in-memory rows     | Malformed, stale, poisoned, or schema-incompatible bytes require validation before they influence candidates. |
| Cache instance to readers and invalidators | A second instance can leak state across lifecycles or leave stale rows visible after mutation.                |

| T-05-27   | Tampering / Information disclosure | cache ownership            | high     | mitigate    | Keep maps in factory closures, expose no raw state/reset, and prove two-instance isolation.               |
| T-05-28   | Tampering                          | persisted schema and rows  | high     | mitigate    | Preserve TypeBox validation, schema 6, complete serialized rows, and rebuild behavior.                    |
| T-05-29   | Tampering / Denial of service      | freshness and poison       | medium   | mitigate    | Preserve exact TTL boundary, poison discriminator/bytes, and original non-soft thrown values.             |
| T-05-30   | Tampering                          | transition and propagation | high     | mitigate    | Use one required production-used transition and pass it through every read branch; Plan 05-12 removes it. |

ASVS Level 1: cache isolation, persisted-input integrity, and production identity are high-severity blocking threats. This plan adds no package or external service.
