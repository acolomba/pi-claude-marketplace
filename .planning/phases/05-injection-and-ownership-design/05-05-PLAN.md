## Edge assumptions

- Plans 05-03 and 05-04 completed first. Their summaries define the final port and runtime identifiers that this plan must reuse.
- The extension factory owns the runtime lifetime. A command, import, reconcile, backfill, or autoupdate caller must not construct another runtime.
- Pi provides no verified unregister or disposal contract. This plan preserves generation invalidation and does not add disposal behavior (D-05-04, D-05-06).
- Hook cache changes remain at their existing transaction points. Failed or rolled-back mutations must not expose routing state that disagrees with persisted state.
- applyReconcile can accept or close over the runtime and the 05-03 state reader. It must continue to call real child orchestrators directly (D-05-02).
- bootstrapClaudePlugin does not need a runtime solely to satisfy its composition test. Its real addMarketplace and autoupdate flow remains unchanged (D-05-02).
- Persisted PID tables intentionally outlive in-memory children. This plan changes no PID-table source or test file.
- Phase 6 owns the named large-module splits and global-patch removal. Runtime-bound port shapes must remain movable without performing those changes (D-05-09).
