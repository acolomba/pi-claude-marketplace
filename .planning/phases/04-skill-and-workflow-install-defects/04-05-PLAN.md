<objective>
Say at install and at update that a workflow does not keep the tool restriction of a plugin agent it runs.

Purpose: Claude Code keeps an agent definition's `tools` and `disallowedTools` when a workflow uses the agent as an `agentType`. The workflow engine passes no tool list to Pi for the child session, so a read-only plugin agent holds `read`, `bash`, `edit`, and `write` in a workflow (spike S4, engine 3.15.1, Pi 1.5.2). This project cannot change the engine, so it discloses the gap. The divergence is licensed by that Pi capability gap (D-PG4-11).
Output: the literal `agentType` reader in extensions/pi-claude-marketplace/domain/workflow-script.ts, the join in extensions/pi-claude-marketplace/orchestrators/plugin/discover-names.ts, the two delivery sites, their owner cases, and features/workflow/agent-restrictions.feature.
</objective>
