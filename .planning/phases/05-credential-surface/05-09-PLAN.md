## Design

- `authBundleFor(cloneUrl: string, kind: "github" | "url" | "git-subdir"): GitAuthBundle` returns
  `{ kind: "stored-credential", credentialOps: DEFAULT_CREDENTIAL_OPS, host: hostFromCloneUrl(cloneUrl, kind) }`
  until 05-10 shrinks the bundle. `hostFromCloneUrl` already binds the override host for a github
  source and for any GitHub spelling (`gitHubAddressOf`), the URL host with its port otherwise,
  and the scp host for an scp address, which is what the builders bound. If `auth-host.test.ts`
  shows a source for which the two differ, keep the builders' host and record the case.
- The marketplace tag probe's optional auth context becomes `withHostBundle?: true`: present, its
  listing carries `authBundleFor(canonicalCloneUrl(source), source.kind)`; absent, it carries
  none, which is the research's "no bundle" path (a refused credential stays a plain
  `GitCommandError` there, and its wording is Phase 6's).
- `UpdateConstraintOptions.auth` becomes `notification?`, the context whose presence keeps the
  stage-one tag query and the listing's bundle, exactly as the auth context's presence did.
- `makeUpdateCloneProbe` gives both arms `authBundleFor`: since 05-06 the no-notification arm
  (D-3-04) and the notification arm return the same bundle.
- A builder is deleted in the commit that removes its last caller. The Running checks and the
  compile-edge rule of 05-04-PLAN.md apply.
