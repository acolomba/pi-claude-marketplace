<objective>
Remove the GitHub and GitLab OAuth Device Flow (D-SG-27). `orchestrators/auth-host.ts` builds a
stored-credential bundle for every host, so git authenticates only with what the machine holds;
the Device Flow engine, the provider registry, and the prompt helper are deleted with their tests;
the rule pack, `NETWORK_SEAMS`, and the leak registry shrink with them; and the scenarios that
expected a sign-in are replaced by scenarios that fail on the tree before this plan.

Purpose: SG-AUTH-01, SG-AUTH-02, and SG-AUTH-03 become true for users. This is the one
behavior change of the phase; it cannot split further, because the auth-host change, the engine
deletion (fallow fails on an export with no production caller), the prompt helper deletion, the
leak gate (it asserts every registry entry resolves), and the scenarios that change with the
behavior must land together.
Output: the Device Flow arm gone, ten files deleted, the D-SG-27 scenarios, the OQ1 row update.
</objective>
