- MSEL-02 says "runs `/reload` or starts Pi again"; the switch scenario restarts Pi in each leg, because a companion's install or removal changes the loaded extensions, which Pi reads at start. A `/reload` after turning built-in MCP on in the settings is the same load path (lifecycle.feature shows a new session registering again).
