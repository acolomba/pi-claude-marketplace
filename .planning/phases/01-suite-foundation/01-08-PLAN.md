## Trust Boundaries

| Boundary | Description |
|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-19 | Information disclosure | git plugin manifest entries (a source that reaches the public network) | high | mitigate | url and git-subdir entries are built from `host.repositoryUrl`, which names 127.0.0.1 and the run's port; github entries are `acme/<name>` shorthands that Pi sends to the loopback host through the GitHub base override; Pi runs with PI_OFFLINE; the request-log steps state every request a seed makes |
| T-01-20 | Tampering | fixture git commands (a git config or HOME of the developer changing a fixture, or a fixture writing into this repository) | medium | mitigate | Every fixture git runs through `runGit` with the hermetic environment (no system config, an empty global config, a scratch HOME, DRV-03); work trees live under the sandbox HOME; the repository plugin path refuses absolute paths and `..` |
