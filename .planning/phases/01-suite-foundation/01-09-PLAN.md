## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-22 | Tampering | claude-code-settings step (a write to the developer's real `~/.claude/settings.json`) | high | mitigate | The path is built from `this.tokens.home` or `this.tokens.projectDir`, the sandbox HOME and project, never from the home directory of the process that runs the suite; the write uses flag wx and a release removes the file; Pi itself sees HOME as the sandbox HOME |
| T-01-23 | Information disclosure | import seed (a settings source that reaches the network) | medium | mitigate | The seed's marketplace is a directory source under `{home}`; Pi runs with PI_OFFLINE and the GitHub base override at the loopback host |
| T-01-24 | Tampering | marketplaces config writer (a write outside the scope root) | low | mitigate | The path comes from `layerConfigPath`, which allows only the base and local configs under `this.scopeRoot(scope)`; the step reads the file back |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package |
