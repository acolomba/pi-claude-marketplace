<objective>
Make a new session's own payloads reach the steps, and teach the row steps the session's payload
kind. The driver reads the payloads of a new session through Pi's RPC `get_entries`, the session
`When` keeps them as the last results, the row steps read `reconcile-applied-cascade`, and a new
step states a session's results row by row. The six existing scenarios whose new session reports a
reconcile result gain the comparison they now need (CONTEXT: decisions after research), and a seed in
`features/plugin/reconcile.feature` proves the path end to end. Both tasks land in one commit, so no
commit leaves an existing scenario failing, and the ROADMAP's file-ownership note names the two
"untouched" feature files this plan edits.

Purpose: success criterion 2 (a scenario that leaves the rows of any emitted payload uncompared
fails) must cover new sessions too; Phases 11 and 15 compare reconcile reports.
Output: the extended driver, a shared result-rows library, world support for session results, the
session results step, six updated scenarios, one seed, the updated skill text, and the amended
ROADMAP note.
</objective>
