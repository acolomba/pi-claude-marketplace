## Trust Boundaries
| Boundary | Description |
|---|---|
| device-flow request → OAuth HTTP endpoint | Authorization data crosses a remote boundary in production. |
| queued response → polling state | Mutable fake/adapter state determines token delivery order. |
| test replacement → global fetch/wait state | Test doubles can contaminate later cases. |
## STRIDE Threat Register (ASVS L1)
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-108-12-01 | Information Disclosure | device code/token responses | high | mitigate | Synthetic values only, whole results without logging, and no live HTTP. |
| T-108-12-02 | Tampering | HTTP request encoding | high | mitigate | Exact method/URL/header/body assertions through the public flow. |
| T-108-12-03 | Denial of Service | polling wait/status loop | high | mitigate | Injected wait plus pending/slow-down/terminal/cancellation cases; no real timer. |
| T-108-12-04 | Tampering | global fetch/mock state | high | mitigate | Test-context replacement and case-local restoration required for every case (D-19). |
| T-108-12-05 | Tampering | fake/production contract | high | mitigate | Same registrar for both participants and exact one-failure planted defect (D-06, D-13). |
