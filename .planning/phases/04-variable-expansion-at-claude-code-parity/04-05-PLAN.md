## Flagged assumptions

- D-04-11 "unset" follows Claude's missing rule (unset and no `:-` default); a variable that is unset but has a default is not listed, because Claude reports no error for it.
- D-04-11 "withheld" rule (Claude's Discretion, 04-RESEARCH Open Question 7): every deny-listed reference in `url`/`headers`, plus plain-list references set now.
- A builtin value never contributes a name to the info lists; at install, a builtin path that itself holds `${…}` is re-scanned (plan 04-01), which info does not mirror. Such install paths are not expected in practice.
