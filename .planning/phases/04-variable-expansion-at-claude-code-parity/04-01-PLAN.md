<objective>
Write plugin MCP entries with Claude Code 2.1.291's variable rule, encoded so pi-mcp-adapter's own second expansion outputs what Claude would.

Purpose: AVAR-01, AVAR-02 and AVAR-03 (escape half). Today `bridges/mcp/substitute.ts` walks the whole entry, replaces three builtins and leaves everything else for the adapter, which then expands `$env:`, `{env:}`, `${…}` and runs a leading `!` as a shell. After this plan the bridge translates first (closed table), then expands only Claude's five fields with Claude's rule (D-04-01, D-04-02), and encodes the result for the adapter with split tokens, the boundary guard and `!!` (D-04-03, D-04-04, D-04-19). Plan 04-02 proves the rule through the real install operation and turns the report into the missing-variable warning (D-04-10). The deny-list arm is plan 04-03. The process-level `CLAUDE_PROJECT_DIR` and the stdio-env injection change are plan 04-05, so this plan keeps today's injected env set.

The two pure modules ship with their wiring because the commit hook runs fallow's production dead-code check, which reports a module that only tests import.

Output: two pure modules, the five-field walk with its per-server report, the injected-environment seam on the stage, the shared case table, paired unit tests at 100% direct coverage, one commit.
