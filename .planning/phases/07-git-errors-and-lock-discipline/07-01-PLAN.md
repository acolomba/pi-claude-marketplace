<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git host -> extension | HTTP status codes and error shapes from a remote host the user does not control are classified into closed-set reason tokens |
| extension -> user output | the `{status} on {url}` frame is rendered into the cause line of a notification (text or JSON mode) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information disclosure | classifyGitFailure frame (remote URL in a cause line) | medium | mitigate | The frame only ever travels as an Error message in a cause chain; `shared/errors.ts::serializeCauseChain`, the single cause serializer for every output mode, applies `redactCredentials` to every link, so userinfo in a URL is redacted. The plan adds no other path that prints the frame. Verified: `grep -n "redactCredentials(linkMessage" extensions/pi-claude-marketplace/shared/errors.ts` finds the call. |
| T-07-02 | Repudiation | wrapper rules (wrong reason misleads the user's next action) | low | mitigate | Each wrapper is one call with a fixed rule pinned by one test row; the foreign callers' own test suites and the install/add scenarios run unchanged (Task 1 verify). |
| T-07-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs or upgrades no package (RESEARCH.md Package Legitimacy Audit: none); package.json and package-lock.json are not in files_modified. |
</threat_model>
