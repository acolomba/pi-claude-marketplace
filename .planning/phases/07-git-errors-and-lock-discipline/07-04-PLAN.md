<objective>
Let a reinstall at a tag ref read the tag from the warm mirror instead of the
network (GLK-08, LCORCH-01 b5, D-PL7-10).

Purpose: a mirror cloned for a tag holds `refs/tags/<ref>` and no
`refs/remotes/origin/<ref>` (isomorphic-git writes the fetched tag ref, and the
refspec never translates a tag), so `resolveFetchedRefOffline` misses today and
the reinstall refreshes over the network even though the commit is local.
Output: a local tag fallback in `clone-cache.ts`, unit cases, and a cucumber
scenario that fails without the change.
</objective>
