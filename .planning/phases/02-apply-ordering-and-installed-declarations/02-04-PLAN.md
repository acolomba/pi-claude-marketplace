<objective>
Tighten installed-copy containment (RCN-08, LCORCH-01 b6): admit a record's installed
copy only under the single clone root that owns it, keyed on `resolvedSha` (D-PL2-12 as
amended), and refuse a symlinked manifest inside the copy (D-PL2-13).

Purpose: the read today accepts a copy under either root, so a record whose
`resolvedSource` points into the other owner's tree is read; and the manifest file
itself is opened through `stat`/`readFile`, which follow symlinks below the plugin root.
Output: `installedCopyOwnerRoot`, the single `ownerRoot` option, the manifest-candidate
check, and unit cases for each refusal.
</objective>
