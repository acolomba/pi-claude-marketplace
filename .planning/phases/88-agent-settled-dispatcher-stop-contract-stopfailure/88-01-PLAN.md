<assumption_delta_decision>
Phase 87 split admission (`BUCKET_A_EVENTS`, 10) from dispatchable
(`DISPATCHABLE_EVENTS`, 8). Phase 88 completes the promote by folding
Stop/StopFailure INTO the dispatchable domain.

- Noun now primary: the admitted bucket-A event union (`BucketAEvent`, 10);
  `DispatchableEvent` is a derived subset.
- Decision: promote-completion — extend `DISPATCHABLE_EVENTS` to 10; KEEP the
  subset machinery (the `DISPATCHABLE_EVENTS` tuple, `DispatchableEvent` type,
  and the translator/dispatch tables keyed on it) rather than collapsing it
  back into `BucketAEvent`, because future bucket-D promotions reuse the same
  two-step admission-then-dispatch pattern. The `isDispatchableEvent` guard +
  `DISPATCHABLE_MEMBERS` (the Phase-87 defensive belt) may be simplified now
  that every admitted event is dispatchable, but the subset type itself stays.
- Invariant preserved: `DISPATCHABLE_EVENTS ... as const satisfies readonly BucketAEvent[]`
  remains — every dispatchable event is an admitted event, compile-time.
</assumption_delta_decision>
