**First, the owner.** Rewrite `tests/edge/args.test.ts` in the G1 pure-function shape: four imports,
a flat sequence of `test()` bodies, no `describe()`, no fixture, no context. `parseArgs` is the only
runtime export; `ParsedArgs` is a type. Copy the file skeleton of

Cover, each with a hand-authored whole-value expectation:

- Positionals in input order with no flag: `"official alpha"` yields
  `{ positional: ["official", "alpha"] }`. Assert the whole object so the **absence** of a `scope`
  key is part of the promise.
- Scope present: `{ positional: [...], scope: "user" }` and the same for `"project"`.
- Position independence: a row table driving `--scope user` leading, trailing, and between two
  positionals, each row asserting the identical whole value. One marked body, several runtime cases.
- Tokenizer, single quotes: `'alpha beta'` becomes one token `alpha beta`.
- Tokenizer, double quotes: `"alpha beta"` becomes one token.
- Tokenizer, the other quote inside a quoted run: a single quote inside a double-quoted run is
  ordinary text and does not toggle, and the mirror case.
- Tokenizer, no backslash escape: a backslash before a space does not join the tokens; it survives
  as an ordinary character.
- Tokenizer, runs of spaces collapse: leading, trailing, and repeated interior spaces produce no
  empty tokens.
- Empty argument vector: `parseArgs("")` yields `{ positional: [] }` with no `scope` key.
- Bare verb with no operand: a single token yields a one-element positional list.
- Unterminated quote: an opening quote with no closer still flushes the trailing `current` buffer
  into a token — state that outcome, do not leave it unasserted.
- `--scope` with no value: `--scope` as the final token throws. Assert with `assert.throws` and a
  predicate that checks the error is an `Error` and its `message` equals the hand-written string
  `--scope requires a value: "user" or "project".` Use the combined `// act &amp; assert` marker for
  this single expression.
- `--scope` with an empty double-quoted value: `--scope ""` discards the value token entirely in the
  tokenizer, so it reaches the same missing-value throw. Prove that outcome explicitly rather than
  assuming it.
- `--scope` with an unrecognised value: `--scope bogus` throws with message
  `Invalid --scope value: "bogus". Must be "user" or "project".`
- Last `--scope` wins: two `--scope` pairs yield the second value.

Case titles state public behavior and may cite a durable requirement or decision ID; they may not
cite a plan, phase, wave, or task. Every runtime case carries separate lowercase `// arrange`,
`// act`, `// assert` phases in that order, blank-line separated; the combined marker is reserved
for a single throwing expression. Name values after their production role — `parsedArgs`,
`expectedArgs` — never a bare placeholder. Use no double assertion through `unknown`, no broad
partial cast, and no module replacement or loader hook.
