## Commit recipe (operator-approved 2026-09-02)

```bash
TH=$(find "${PRE_COMMIT_HOME:-$HOME/.cache/pre-commit}" -type f -name trufflehog -perm -u+x | head -1)
"$TH" filesystem <explicit literal paths> --results=verified,unknown --fail
npm exec -- prettier --check <explicit literal paths>
SKIP=trufflehog,npm-format-check pre-commit run --files <explicit literal paths>
```

`SKIP=` is widened to exactly those two hooks. `trufflehog` because this linked worktree breaks its
git-mode scan (the filesystem route above is the real check); `npm-format-check` because it runs the
repo-wide `format:check` that fails on the operator's untracked files (the per-file `prettier --check`
restores that coverage). This supersedes the earlier "do not extend SKIP beyond trufflehog".
