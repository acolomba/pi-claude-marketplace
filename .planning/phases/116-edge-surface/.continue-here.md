  Phases 114 and 115 passed while asserting nothing, and the Phase 115 code review found four
  more gates that had been deleted and replaced with a compile-time guarantee TypeScript does
  not make. Structural mitigation: for every non-obvious proof, plant a violation, confirm the

  short-circuits there, so `test` and `test:integration` NEVER RUN. Structural mitigation: run
  `npm run typecheck`, `npm run lint`, `npm run fallow`, `npm test`, and
  `npm run test:integration` SEPARATELY, and check exit codes. Do NOT "fix" this by touching
  those untracked files — they are operator-owned and out of scope.

  `/home/acolomba/pi-claude-marketplace/.git/hooks`, which contains no `pre-commit` file, so
  `git commit` runs NOTHING and a successful commit is not evidence hooks passed. Structural
  mitigation: run `pre-commit run --files <explicit paths>` manually before every commit. Never

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Proof that cannot fail | Eleven instances across Phases 114-115: an expected value built by calling the production function under test; a regex alternation matching two different error classes; an expected notification interpolated from the actual error; type-level negatives attached to nothing because a multi-line `satisfies` reports on its CLOSING line; an exhaustiveness alarm lost when unreachable arms were deleted; and four `void`-returning switches whose missing arms compiled clean. | blocking | Plant the violation, confirm RED, revert. Record the plant in the summary. |
| `git add -A` in a shared checkout | The operator keeps unrelated modified and untracked files here and edits them concurrently: `.claude/settings.json`, `.codex/config.toml`, `.claude/CLAUDE.md`, `.codegraph/`, `.mcp.json`, `.planning/agent-history.json`, `.planning/milestone.lock`, `.planning/research/.cache/`, `.planning/state.json`, `AGENTS.md`, `a.out`. | blocking | Stage explicit paths only, drawn from the plan's `files_modified`. Never `-A`, never `.`. Do not touch, revert, or clean those files. |
| `pre-commit run --all-files` | Rewrites every tracked Markdown file, including operator and planning docs unrelated to the change. | blocking | Use `--files` with explicit paths. The TypeScript hooks call whole-repo npm scripts anyway, so repo-wide checking is not lost by narrowing. |
| Testing what a gate already enforces | Enumerating a type's members to catch an unused one cannot work: a test observes shape, usage belongs to the call graph, and coverage is blind because an unused member has no read site. Forbidden by D-116-12. | blocking | Before writing a case, name the failure it catches and the gate that would miss it. See `.claude/rules/typescript-unit-testing.md` § Patterns. |
| Trusting a piped `fallow` tail | `fallow health` and `fallow dupes` print `✗`-prefixed summary lines even on success. | advisory | Check the exit code, never the output text. |
| Shell variable word-splitting | This shell does not word-split. `git add $FILES` passes one argument and dies with a pathspec error. Backticks inside `git commit -m` EXECUTE. | advisory | Pass explicit paths. Use `git commit -F <file>` when the message needs backticks. |
| Test-boundary helpers as methods | Declaring them as methods on the returned type fires `@typescript-eslint/unbound-method` at every destructuring site (115-04 hit 11). | advisory | Use arrow properties: `readonly clonedUrls: () => readonly string[]`. |
| Trusting a GSD write to planning files | `state.begin-phase` mangled STATE.md this milestone: it left an orphaned tail line from a multi-line sentence and split a wrapped paragraph into a stray ordered-list item. | advisory | Diff every GSD write to STATE.md or ROADMAP.md before trusting it, and repair by hand. |
