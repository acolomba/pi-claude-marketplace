<objective>
Add an SSH stand-in that answers both git's SSH transport and an `ssh` probe
launch with scripted answers and no real network, and put it first on every
cucumber Pi's PATH.

Purpose: SG-HRN-03 and every CONTEXT decision under [SSH stand-in]: a stub
named `ssh` first on PATH (not an ssh-command override variable, which upstream
reads as its probe-skip signal), the answers it gives, always installed, a Node
script behind an absolute-path wrapper. RESEARCH Pattern 4 and experiments X5
and X8 measured the argv git 2.43 hands the stub, the `GIT_PROTOCOL` it
passes, and the kill through an `exec` wrapper. The orchestrator's answer to
RESEARCH Open Question 4 (reuse `HttpsGitHost.repositoriesRoot`, added by plan
01-06) decides where the stand-in serves from.

Output: `features/lib/ssh-git-host/{launch,stub,host}.ts`, the run's lifecycle
of the stand-in, the stub-first PATH of every cucumber Pi, and
`test/architecture/ssh-git-host.test.ts`.
</objective>
