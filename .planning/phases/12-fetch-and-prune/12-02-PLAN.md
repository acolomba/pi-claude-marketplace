Append (titles are suggestions):

1. "Pruning a scope uninstalls a dependency that no installed plugin needs"
   (PRN-01): `tools` offers `app` 1.0.0 -> `lib`, `lib` 1.2.0; install app;
   uninstall app; `prune --scope project` -> cascade / info / true; row `tools |
   project | lib@tools | lib | uninstalled | dependency pruned | project |
   1.2.0`; then `the project scope has no installed plugins`.
2. "Pruning a git-source dependency removes its clone" (PRN-01): `ghp` 1.0.0
   unpinned github in `gits`, `app` -> `ghp` (with-dependencies table, then the
   git-repositories table); install app; uninstall app; `prune --scope project`
   -> cascade / info / true; row `gits | project | ghp@gits | ghp | uninstalled
   | dependency pruned | project | {ghp revision 1}`; the project scope holds
   no git clones.
3. "Previewing a prune lists the dependency it would uninstall and removes
   nothing" (PRN-02): same state as 1; `prune --scope project --dry-run` ->
   cascade / info / false; row `tools | project | lib@tools | lib | will
   uninstall | dependency pruned | project`; the installation record of the
   project scope holds `lib@tools | 1.2.0 | true`.
4. "Pruning keeps a dependency that an installed plugin still needs" (PRN-03):
   install app only; `prune --scope project` -> prune-empty / info / false /
   scope project.
5. "Pruning keeps a plugin the user installed by name" (PRN-03, D-01): install
   lib, install app, uninstall app; `prune --scope project` -> prune-empty /
   info / false / scope project.
