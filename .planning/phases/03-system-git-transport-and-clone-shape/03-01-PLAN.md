<objective>
Give the git process module the two request features the transport needs, and
give the failure classifier the two details the transport reads. A request can
now carry Pi-owned `-c` pairs (the `insteadOf` key of D-SG-16 and the one-shot
credential helper of D-SG-14 ride this field later), and `for-each-ref` joins
the closed verb set (the local tag list of D-SG-09). An https auth failure says
whether no credential was found or a credential was refused, and the protocol
v0 refusal of an unadvertised SHA reads as a missing commit.

Purpose: SG-TRN-01, SG-TRN-02, and SG-TRN-07 groundwork. Nothing user-visible
changes: no production caller sets `config` or runs `for-each-ref` yet, and every
https-auth detail still maps to `authentication required`. The new request field
is read by the module itself and the new verb is a union member, so no new
export appears and `fallow dead-code` stays green.

Output: the request field, the verb row, the two classifier rows, the reshaped
`GitFailure` union, and real-git proofs.
</objective>
