<objective>
Move the local `GitOps` verbs onto system git and give `GitOps` its final local
shape: `resolveRef` and `resolveRemoteRef` answer `undefined` for an absent ref,
`checkout` can drop the keys an `isomorphic-git` clone carries before a copy is
checked out (D-SG-11), and a `fetchCommit` member fetches one commit with the
upstream `--unshallow` fallback. Add the `CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS`
reader that every system-git request uses (D-SG-13), and replace the
`isomorphic-git` name matchers with `instanceof GitCommandError` checks.

Purpose: SG-TRN-01 (local verbs), SG-TRN-05 (the reader), SG-MIG-01 (old
clones: the copy step is the whole migration, because under D-SG-10 nothing
checks out into a live clone once the swap lands). No request row changes:
the local verbs send nothing, and `fetchCommit` has no production caller until
the pin ladder.

Interim, accepted: until the re-clone swap replaces D-14, the D-14 refresh
runs an `isomorphic-git` fetch and then this plan's system-git checkout in the
live clone. `checkout -f` writes the target tree as `isomorphic-git` did
(a plain `checkout <branch>` after the ref moved leaves the old files,
measured on git 2.43.0). In that window a clone made by `isomorphic-git` with
`core.symlinks=false` writes a new symlink as a file; the swap removes the
window before the milestone ships.

Why this plan runs over 15 files: a new or reshaped `GitOps` member changes the
interface, its fake, its contract, and every full `GitOps` literal in one commit,
and five test files outside the platform tests hold such a literal; moving a
member to another plan repeats that lockstep edit.

Output: the reader, the reshaped `GitOps`, the system-git local verbs and
`fetchCommit`, the fake and contract on `GitCommandError`, and real-git proofs.
</objective>
