<objective>
Prepare the tests for the transport removal and give the injection proofs a
door that system git uses: decouple the remaining full `GitOps` literals and
call records from the D-14 members, replace the two fabricated `isomorphic-git`
HTTP errors with system-git errors, and re-anchor the four edge "network door"
counters on the git process.

Purpose: SG-TRN-01. The removal plan (03-15) deletes the D-14 members and the
`isomorphic-git` dependency; it can do so within its file budget only when no
other test names those members or imports the package. The edge counters count
`https.request`, which a git child process never calls, so under system git
they prove nothing (03-RESEARCH Pitfall 10); a trap on the default git process
and the injected port's own record replace them.

Out of scope (carried to the close phase, SG-CLS-01): the 14 other edge tests
whose `https.request` trap is documented as a hermeticity device, not a proof,
keep it; only their comments, which say the git transport opens `https.request`
through `simple-get`, are stale. 03-16's output lists them.

Output: the fake's reader, eight reworked test files, and the re-anchored
proofs.
</objective>
