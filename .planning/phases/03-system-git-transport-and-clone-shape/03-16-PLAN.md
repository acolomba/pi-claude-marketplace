<objective>
Remove what the `isomorphic-git` transport left behind: the classifier rungs
that read its errors, `CrossOriginChallengeError`, which only its redirect
client threw, and the comments that still describe it.

Purpose: SG-TRN-01's removal list in 03-RESEARCH ("isomorphic-git rungs in
`classifyGitFailure` ... Keep the `GitCommandError` arm,
`PinnedCommitMissingError`, `StoredCredentialRejectedError`,
`HostedManifestFetchError`"). These pieces were still referenced after the
transport removal (03-15), so no gate reported them; they are dead logic and
stale text that would mislead the SSH, credential, and failure-message phases.
The test comments that still describe `isomorphic-git` (14 edge tests with a
`simple-get` note) are carried to the close phase (SG-CLS-01); this plan lists
them.

Output: a classifier and an error set for system git only, and comments that
describe the tree.
</objective>
