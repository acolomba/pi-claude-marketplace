<objective>
Build the network request path of the system-git transport and move the two
`ls-remote` verbs onto it: the `insteadOf` key of D-SG-16 on every remote
request, the timeout and abort signal, the GHB-01 cause, the Device Flow retry
of D-SG-14 with its one-shot credential helper, and the GAUTH-04 mapping of a
refused stored credential. Point the Device Flow scenarios' Pi at the CONNECT
proxy, so a system-git request in them can only reach the stand-in.

Purpose: SG-TRN-01 (the remote verbs, first slice) and SG-TRN-07 (the base URL
as `insteadOf`). `ls-remote` sends the same `GET` and `POST` as the
`isomorphic-git` ref listing, so the request tables keep their rows; cause
chains of `ls-remote` failures change once, here. `fetchCommit` from the
local-verbs plan takes the same path; the clone and the pin ladder follow in
the transport swap.

Output: the request path, the one-shot helper module, the builder, the two
verbs on system git, the proxy profile, and the re-baselined cause chains.
</objective>
