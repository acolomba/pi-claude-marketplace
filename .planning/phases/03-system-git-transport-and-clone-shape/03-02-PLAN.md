<objective>
Refuse a malformed commit pin and a ref that starts with `-` while the source is
parsed, before any git command can run, with Claude Code's wording for each
refusal. Today an abbreviated sha is silently dropped and the plugin installs
unpinned over the network; upstream refuses it.

Purpose: SG-TRN-02's input refusals (CONTEXT "[SHA pins]", decided autonomously:
"Before git runs, `domain/` refuses a SHA that is not 40 or 64 hex digits
(lower-cased first...) and a ref that starts with `-`"). The refusal reuses the
parser's `unknown` source arm, so `marketplace add` reports it as
`{unsupported source}` through `parseAddableSource`, and an install reports it
through the resolver's unsupported-source rejection. Both paths stop before any
git command, on the current transport and on system git alike.

Output: the parser refusals, their unit rows, and cucumber scenarios that fail
without the change (today the abbreviated pin installs and the host is asked).
</objective>
