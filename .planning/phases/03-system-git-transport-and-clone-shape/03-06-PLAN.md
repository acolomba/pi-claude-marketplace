<objective>
Swap the clone onto system git and give pinned plugins upstream's SHA-pin
ladder, then re-baseline every request table and cause chain that a clone
writes, once.

Purpose: SG-TRN-01 (the last remote verb that `isomorphic-git` still runs for
installs), SG-TRN-02 (clone shape and pin ladder), SG-TRN-07 (the base URL now
rides the clone as `insteadOf`, and the origin reset after a clone goes away).

replaces it, so `marketplace update` and mirror refresh tables keep their rows
here and change once, there (orchestrator decision 2).

Why this plan runs over 15 files: each wave must pass `npm run check`, and a
clone row cannot change in one wave and its table in another. The code change
is three files; the rest are table and cause-chain edits by one rule table.

Output: system-git clone, the ladder, and the re-baselined features.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| marketplace-controlled URL, ref, and SHA to the clone argv | a manifest names what git clones and checks out |
| the remote's served objects to the installed tree | a server could serve a commit other than the pin |
| a cloned repository's `.gitmodules` to git | submodules would fetch from more hosts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-17 | Elevation of privilege | `clone` argv | high | mitigate | the domain refusal of dash-led refs and short SHAs runs first; `--branch=<ref>` is one argv word; the URL and directory follow `--end-of-options` (the operand rule) |
| T-03-18 | Tampering | the pinned checkout | high | mitigate | after the checkout, `resolveRef HEAD` must equal the lower-cased pin, else `pin-mismatch` and the staging tree is removed before promotion |
| T-03-19 | Tampering | submodules of a cloned repository | medium | mitigate | `--no-recurse-submodules` on every clone and the existing `submodule.recurse=false` pair |
| T-03-20 | Information disclosure | a test clone reaching the real github.com | high | mitigate | the ladder's fetch and every clone carry the `insteadOf` pair; the Device Flow profile goes through the refusing proxy; the routing tables prove each tunnel |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | no install task; no dependency file in `files_modified` |
</threat_model>
