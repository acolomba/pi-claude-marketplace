client, the `isomorphic-git` callback module, and the `isomorphic-git`
dependency, and turn the rule pack's chokepoint into a total ban, so the

`platform/git-auth-callbacks.ts` are gone"). The earlier plans moved every
caller and every test off these surfaces (03-09, 03-12, 03-13); what remains
is a deletion that fallow forces into one commit, because the commit hook runs
`npm run fallow`, and an export the deleted client alone used (the callback
builder, `TooManyRedirectsError`, the dependency) is a finding the moment the
client goes. Orchestrator decision 1: the dependency leaves `package.json`
entirely, because no test still needs it.

Why this plan lists 16 paths: the transport commit must hold every file that
the deletion turns into a fallow or typecheck finding. The `GitOps` members
leave in an earlier commit of their own (Task 1), which needs the vocabulary
guard because the last `writeRef` call goes with `forceUpdateRef`.

Output: one transport, the deleted modules and dependency, and the re-aimed
gates.
</objective>
